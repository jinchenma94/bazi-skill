## 🚀 快速开始

### 安装

```bash
mkdir -p .claude/skills
git clone https://github.com/fckcg/bazi-skill .claude/skills/bazi
```

### 使用

在 Claude Code 中输入：`算八字` `看八字` `排盘` `bazi`

# 天干合克系统

## 概述

天干之间存在相合与相克两大类关系。天干五合是阴阳相配、化生五行的机制；天干相克是五行生克制化的体现。掌握天干合克系统，是分析天干能量流动、判断格局成败的重要基础。

---

### 五合关系表

| 合组 | 化神（合化五行） | 口诀 |
|------|---------------|------|
| 甲 + 己 | 合化土 | 甲己合化土 |
| 乙 + 庚 | 合化金 | 乙庚合化金 |

## 二、合化条件（得时得令才能化）

天干相合不一定能化，必须满足以下条件方能"合而化气"：

### 条件一：得令
合化五行须在月令当旺之时：
- 甲己合化土 → 须生于辰戌丑未月（土旺月）
- 乙庚合化金 → 须生于申酉月（金旺月）
- 丙辛合化水 → 须生于亥子月（水旺月）
- 丁壬合化木 → 须生于寅卯月（木旺月）
- 戊癸合化火 → 须生于巳午月（火旺月）

### 条件二：无冲克干扰
合化的两干不被第三干冲克，方能完全合化。

### 条件三：化神有根
合化五行在地支中须有根（地支藏干中含有化神）。

### 判断步骤
1. 确认两干是否形成五合对子。
2. 检查月令是否为合化五行的当旺季节。
3. 检查地支是否有合化五行的根气。
4. 检查是否有其他天干冲克干扰。
5. 满足以上条件，论"合化成功"；否则论"合而不化（合绊）"。

---

## 三、合绊（合而不化）

合绊指两干相合但不具备化气条件，导致双方被"绊住"，各自原有功能受到牵制。

### 合绊的影响
- **喜神被合绊**：喜神（用神）被另一天干合住，无法发挥助日主之力，称为"合去喜神"，为凶。
- **忌神被合绊**：忌神被合住，无法克制日主或破坏格局，称为"合去忌神"，为吉。
- **大运流年引发合绊**：大运或流年天干与原局天干形成合绊，当运势之神被合，吉凶随喜忌而定。

### 合绊示例
- 日主甲木，用神为庚金（偏官），若大运流年出现乙木，乙庚相合，庚金被绊，用神力量减弱 → 凶。
- 日主甲木，忌神为己土（正财耗身），大运遇甲木，甲己相合，己土被绊 → 吉。

## 四、争合与妒合

### 争合
两个相同天干同时争合一个天干，称为"争合"，合化力量大减。

**规律**：
- 两阳干争合一阴干 → 争合无效，各方力量分散。
- 两阴干争合一阳干 → 同上。

**示例**：
- 命局中有两个甲木、一个己土 → 两甲争合一己，己土被争，合化不成，各甲保持原有属性，己土也保持原有属性。
- 命局：甲、甲、己 → 两甲争己，三者均不化，甲仍为木，己仍为土。

### 妒合
与争合类似，多指在大运流年中新来的天干与原局天干争合，产生妒忌效应。妒合往往引发人际关系矛盾（尤其婚姻中的第三者问题）。

**示例**：
- 原局有甲己合，大运又来一个甲木 → 新甲妒合，原有甲己合受破坏，婚姻感情可能出现变故。

## 五、天干相克关系

### 五行相克顺序

| 克者 | 被克者 | 克的方式 |
|------|--------|---------|
| 甲、乙（木） | 戊、己（土） | 木克土 |
| 戊、己（土） | 壬、癸（水） | 土克水 |
| 壬、癸（水） | 丙、丁（火） | 水克火 |
| 丙、丁（火） | 庚、辛（金） | 火克金 |
| 庚、辛（金） | 甲、乙（木） | 金克木 |

### 克的力量判断

天干相克的力量受以下因素影响：

1. **月令得时**：若克者在月令当旺，克的力量最强；若被克者当旺，则克力减弱。
2. **阴阳相配**：阳克阴力量强于阴克阳（如庚克甲 > 辛克乙）。
3. **有无根气**：克者在地支有根则克力强，被克者有根则抵抗力强。
4. **隔位相克**：天干相邻克力大，隔位克力减弱（如年干克日干，力量弱于月干克日干）。

### 克的类型
- **正克（有情之克）**：克而有制（如金克木，但有水通关），五行流通，影响较和缓。
- **硬克（无情之克）**：直接相克，无通关之物，力量全面对抗，影响激烈。
- **制化**：被克方有合神解救或生扶，则克力减弱。

## 六、天干关系在大运流年中的作用

### 六种常见的大运/流年天干效应

| 效应类型 | 说明 | 吉凶 |
|---------|------|------|

| 来合忌神 | 大运/流年天干合住命局忌神 | 吉，忌神被制 |
| 来克喜神 | 大运/流年天干克制命局喜神 | 凶 |
| 来克忌神 | 大运/流年天干克制命局忌神 | 吉 |
| 来生喜神 | 大运/流年天干生助命局喜神 | 吉 |
| 来生忌神 | 大运/流年天干生助命局忌神 | 凶 |

### 天干合克的优先级
在大运流年分析中，天干关系按以下顺序分析：
1. 先看天干是否形成合（五合优先）
2. 再看天干是否形成克
3. 最后看天干是否形成生

## 七、实例分析

### 示例一：乙庚合化金
**八字**：庚申年 / 乙酉月 / 甲子日 / 丙寅时

- 年干庚与月干乙形成乙庚合。
- 月令酉（金旺），化神金得时。
- 地支申酉（金有根），化神有根。
- 论乙庚合化金成立，乙木正官力量消减（化为金），金局力量增强。

### 示例二：合绊示例
**八字**：甲寅年 / 己卯月 / 甲午日 / 丙辰时

- 年干甲与月干己相合（甲己合）。
- 月令卯（木旺），化土不得时。
- 论甲己合而不化，甲木被己土绊住，力量减弱；己土也被甲木绊住。
- 日主甲木，月支卯（同气）有助，但年干甲被合绊，力量打折。

## 九、天干五合的天文学来源（哲学深度补充）

> 为什么甲己合化土、乙庚合化金……？这不是古人随意拼凑，而是基于"五运六气"的天文学观察体系。

### 9.1 五运与天干的关系

中医/术数体系中，"五运"是影响年份气候的五种主运：

| 运 | 对应五行 | 主年天干 |
|----|---------|---------|
| 土运 | 土 | 甲年、己年 |
| 金运 | 金 | 乙年、庚年 |
| 水运 | 水 | 丙年、辛年 |
| 木运 | 木 | 丁年、壬年 |
| 火运 | 火 | 戊年、癸年 |

这就是**天干五合的来源**：
- 甲己合化土 ← 甲年己年同属"土运"
- 乙庚合化金 ← 乙年庚年同属"金运"
- 丙辛合化水 ← 丙年辛年同属"水运"
- 丁壬合化木 ← 丁年壬年同属"木运"
- 戊癸合化火 ← 戊年癸年同属"火运"

### 9.2 为什么是这种配对？——河图的密码

天干五合的配对规则来自**河图**生成数：

| 河图数 | 五行 | 天干对 | 生成关系 |
|--------|------|--------|---------|
| 一六共宗 | 水 | 丙辛 | 天一生水，地六成之 |
| 二七同道 | 火 | 戊癸 | 地二生火，天七成之 |
| 三八为朋 | 木 | 丁壬 | 天三生木，地八成之 |
| 四九为友 | 金 | 乙庚 | 地四生金，天九成之 |
| 五十同途 | 土 | 甲己 | 天五生土，地十成之 |

**解读**：
- 河图中每组"生数+成数"配对，对应一种五行
- 天干的阴阳配对（甲=1与己=6、乙=2与庚=7…）恰好对应河图的"生成配对"
- 所以天干五合不是凭空规定，而是**河图数理的天然推导结果**

### 9.3 天文观测基础

古代天文学家观测到：
- **岁星（木星）**运行周期约12年→十二地支的天文来源
- **太阳黄经360°÷24=15°一个节气**→节气的天文来源
- **五大行星的运行周期**与天干的对应：
  - 木星（岁星）~12年→地支系统
  - 土星~30年→与大运（10年×3步≈30年一大循环）暗合
  - 五颗可见行星（金木水火土）→五行的命名来源

### 9.4 合化的实际含义——性质转变

天干五合在命理中的深层含义：
1. **合=阴阳相吸**：一阴一阳的天干互相吸引（甲阳+己阴=合）
2. **化=性质转变**：合到一定程度，原来的属性消失，产生新属性（化土/化金/化水…）
3. **条件**：必须"得时"（月令支持化后的五行）才能真正化

**哲学意义**：
- 合化体现了易经"阴阳交合生万物"的核心思想
- 不同属性的事物在特定条件下可以"融合转化"为新事物
- 这也是为什么合化格是高格——代表命主有"超越自身局限"的潜质

### 9.5 三合局的天文来源（补充）

地支三合局（申子辰合水/寅午戌合火/亥卯未合木/巳酉丑合金）的天文来源：

- 三合局的三个地支分别代表**长生→帝旺→墓库**（同一五行从生到旺到入库的完整生命周期）
- 天文学上对应**岁星12年周期中的三个关键位置**（每4年一个）
- 三个120°夹角的位置=等边三角形=力量最均衡的组合

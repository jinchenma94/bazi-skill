# 子平真诠四神体系（用神·相神·喜神·忌神）

## 一、总论

《子平真诠》是清代沈孝瞻所著，民国徐乐吾评注，是**子平格局论**的集大成之作。它把八字分析从杂乱的旺衰、神煞、口诀，提升为**有系统的"格局成败论"**，是学习八字必读的经典。

### 《子平真诠》的核心观点

> **"八字用神，专求月令。"**

意思是：**用神不是随便找一个五行就行，必须在月令（出生的月支）中寻找**。月令是命局的"提纲"，是全局的气数所在。

### 格局成败的评判标准

《子平真诠》把每一张八字都看成一场**格局的成立与否**。有四个关键角色：

| 神 | 作用 | 好比做菜 |
|---|------|--------|
| **用神** | 格局的主角 | 主食材 |
| **相神** | 辅助用神使格局成立 | 调料与配菜 |
| **喜神** | 生扶用神、生扶相神 | 柴火（火候） |
| **忌神** | 破坏用神与相神 | 坏掉的食材或过火 |

**成格**：用神有力、相神到位、忌神有制 → 好命
**破格**：用神无力、相神缺失、忌神当道 → 差命

---

## 二、用神：格局的主角

### 什么是用神？

用神是**命局中代表"人生方向、运气好坏"的那个十神**。它从月令出发，根据八字的具体组合决定。

### 月令定用神的原则

#### 第一步：看月支的**本气**

月支的本气透出到天干 → 该十神即为用神候选

| 月支 | 本气 | 透出用神 |
|------|------|--------|
| 寅 | 甲（木） | 甲透干为比劫/伤食/财（视日干） |
| 卯 | 乙（木） | 同上 |
| 辰 | 戊（土） | 戊透为官杀/印/财（视日干） |
| 巳 | 丙（火） | 丙透为食伤/官杀/印（视日干） |
| 午 | 丁（火） | 同上 |
| 未 | 己（土） | 己透为官杀/印/财（视日干） |
| 申 | 庚（金） | 庚透为官杀/印/财（视日干） |
| 酉 | 辛（金） | 同上 |
| 戌 | 戊（土） | 同上 |
| 亥 | 壬（水） | 壬透为官杀/印/食伤（视日干） |
| 子 | 癸（水） | 同上 |
| 丑 | 己（土） | 同上 |

#### 第二步：本气未透，取**藏干中最有力者**

若月支本气不透天干，取藏干中透出者为用：

- 月支为寅（藏甲丙戊）→ 若丙透，可取偏财/伤官为用
- 月支为巳（藏丙戊庚）→ 若庚透，可取偏财/官杀为用
- 月支为辰（藏戊乙癸）→ 若癸透，可取伤官/印/财为用

#### 第三步：皆不透，取**月令本气之神**

若月支藏干都未透出，用神仍在月支本气，但格局偏弱。

### 《子平真诠》八正格

沈氏把格局分为**八种基本格**：

| 格 | 月令十神 | 格局性质 |
|---|---------|--------|
| **正官格** | 正官 | 贵格之首 |
| **七杀格** | 七杀 | 有制则贵，无制则凶 |
| **正财格** | 正财 | 富格 |
| **偏财格** | 偏财 | 偏门之富 |
| **正印格** | 正印 | 学问、官印 |
| **偏印格**（枭神格） | 偏印 | 偏门学问、技艺 |
| **食神格** | 食神 | 福寿 |
| **伤官格** | 伤官 | 才华、特殊才能 |

> **建禄格、月劫格**（月支为日干禄位或羊刃）在沈氏体系里不作正格，称"建禄月劫"，须另寻用神。

## 三、相神：辅助用神的配角

### 什么是相神？

相神是**辅助用神、使格局真正成立的那个十神**。《子平真诠》的经典原话：

> **"有用神，即有相神。……相神者，用神之辅助也。"**

相神的作用 = **修补格局的漏洞**。

### 各格的相神选择

#### 1. 正官格的相神

- **首选：正印**（官印相生，制伤官保官）
- **次选：正财**（财生官、若身强而官弱）
- **备选：比劫**（若身弱、官旺克身）

**常见破格**：伤官见官，无印化解 → 破格

#### 2. 七杀格的相神

- **首选：食神**（食神制杀）
- **次选：正印**（杀印相生）
- **备选：比劫**（身弱杀旺时）

**常见破格**：财党杀攻身 → 破格

#### 3. 正财格的相神

- **首选：食伤**（食伤生财，源头活水）
- **次选：官星**（财官相生）
- **备选：比劫**（身弱财旺时帮身护财）

**常见破格**：比劫夺财，无食伤通关 → 破格

#### 4. 偏财格的相神

- **首选：食神或伤官**（食伤生财）
- **次选：正官**（财生官）
- 忌比劫夺财

**常见破格**：偏财见比劫无食伤 → 破格

#### 5. 正印格的相神

- **首选：正官**（官生印，印有源）
- **次选：七杀**（杀生印亦可）
- 忌财破印

**常见破格**：贪财坏印 → 破格

#### 6. 偏印（枭神）格的相神

- **首选：偏财**（财制偏印）
- **次选：食伤（见制）**
- 忌枭神夺食

#### 7. 食神格的相神

- **首选：正财**（食生财）
- **次选：比劫**（身弱食旺时帮身）
- 忌枭神夺食、忌官杀克身

**常见破格**：食神逢枭 → 破格（除非有财制枭）

#### 8. 伤官格的相神

- **首选：正印**（伤官佩印，制伤官之过）
- **次选：正财**（伤官生财）
- 忌伤官见官

**常见破格**：伤官见官，无印无财 → 破格

### 相神的判断原则

1. **相神必须透干且有力**：藏而不露的相神作用减半
2. **相神不能被忌神克破**：否则相神失用
3. **相神到位 = 成格**：相神缺失或失用 = 破格
4. **相神是"修补"**：不是决定格局的主角，但决定格局能否落地

## 四、喜神：为用神、相神锦上添花

### 什么是喜神？

喜神是**生扶用神、生扶相神的那个十神**，让整个命局的运转更顺畅。

### 喜神的选择规律

| 用神类型 | 喜神 |
|---------|------|
| 官星为用 | 财星（财生官）、印星（官生印） |
| 财星为用 | 食伤（食伤生财）、官星（财官双美） |
| 印星为用 | 官杀（官生印）、比劫（共印） |
| 食伤为用 | 比劫（比劫生食伤）、财星（食伤生财） |
| 比劫为用 | 印星（印生比劫） |

### 喜神与用神的区别

- **用神**：格局的主角，必不可少
- **喜神**：锦上添花，有则更好，无也不一定破格
- **相神**：用神的辅助，直接决定成败

---

## 五、忌神：破坏格局的敌人

### 什么是忌神？

忌神是**克破用神、克破相神的那个十神**。

### 各格的忌神对照

| 格局 | 忌神 | 原因 |
|------|------|------|
| 正官格 | 伤官、七杀 | 伤官克官、七杀混官 |
| 七杀格 | 食神不制、官杀混杂 | 无食制杀则凶 |
| 正财格 | 比劫（若无食伤通关） | 夺财 |
| 正印格 | 财星 | 财破印（贪财坏印） |
| 食神格 | 偏印（枭神） | 枭神夺食 |
| 伤官格 | 正官 | 伤官见官 |

### 忌神的处理

> **"忌神最要有制。"**

有制之忌神，凶而不凶；无制之忌神，祸不可挡。

处理方式：
1. **克制法**：用克忌神之物
2. **合化法**：用合住忌神之物
3. **通关法**：用流通忌神之气的第三方

## 六、成格破格举例

### 例1：正官格成格

**八字**：甲子 丙寅 丁卯 壬寅（杜撰例）
- 月支寅中藏甲木、丙火、戊土
- 日干丁火，月支本气甲木为正印（不是正官）——不成正官格
- 但时支寅藏甲，透出即为印格——**改为印格**

（说明：用神必须从月令定，本例月支寅为丁火的偏印，故是偏印格）

### 例2：七杀格成格（经典例）

**八字**：庚申 丙戌 甲寅 丁卯
- 日干甲木，月支戌中藏戊（偏财）、辛（正官）、丁（伤官）
- 月柱丙戌，年干庚金七杀透出——**七杀格**
- 用神：七杀（庚）
- 相神：**丁火伤官制杀**（时干丁透出）
- 喜神：甲木自身得令有根
- 忌神：若见癸水印星混杂，则破格

**结论**：**七杀有制，化杀为权**，为武贵之命。

### 例3：正财格破格

**八字**（杜撰说明）：乙未 戊寅 甲子 乙亥
- 日干甲木，月支寅为比禄——不是正财格，而是**建禄格**

### 例4：伤官佩印格

**八字**：庚子 己卯 甲午 戊辰
- 日干甲木，月支卯为比劫（建禄近似）
- 日支午为伤官
- 时干戊为偏财——甲木有伤官生财之象
- 若有癸水为印佩制伤——成伤官佩印之局

## 七、格局高低的判断

### 上格（大贵大富）

1. 用神有力、相神到位、忌神有制
2. 八字清纯、不混杂
3. 大运流年不破格局

### 中格（小贵小富）

1. 用神有力但相神不足
2. 有轻微忌神未完全制伏
3. 大运有起伏

### 下格（平庸）

1. 用神无力、相神缺
2. 忌神横行、格局破裂
3. 大运助凶不助吉

### 破格（命差）

1. 用神被克破
2. 相神完全失位
3. 忌神当道、无制
4. 命局混杂、无清气

## 八、成格与破格的动态变化

> **"有成中有败，败中有成。"**（沈孝瞻名言）

### 成中有败

格局看似成立，但有隐藏的破坏因素：
- 正官格成，但官星被合
- 财格成，但大运走比劫运夺财
- 印格成，但大运走财运破印

### 败中有成

格局看似破坏，但有补救：
- 伤官见官，但印星化解
- 七杀无制，但流年食神来制
- 财破印，但有比劫夺财救印

### 岁运对格局的影响

- **好运**：助用神、助相神、制忌神
- **坏运**：克用神、合相神、助忌神

## 九、本篇与"调候用神"的关系

### 两者不是非此即彼

- **格局用神**（本篇）：从月令出发，定八字的"社会地位、人生走向"
- **调候用神**（见 tiaohou-yongshen.md）：从气候出发，定八字的"生命品质、寒暖燥湿"

### 两者如何协调

1. **两者合一**：最佳状况，上命之象
   - 例：夏生甲木身旺，癸水既是调候用神，又是生身之印（扶抑用神），又能辅官护官（相神）

2. **两者分离**：常见状况，需分别考察
   - 格局用神决定事业地位
   - 调候用神决定健康、生活品质

3. **两者矛盾**：麻烦状况
   - 例：冬生丙火，扶抑需用比劫（火），但调候要用壬水（水）
   - 处理：**调候优先**，扶抑次之（《穷通宝典》原则）

### 综合用神判断流程

```
1. 判断月令格局 → 确定格局用神
2. 判断寒暖燥湿 → 确定调候用神
3. 判断日主旺衰 → 确定扶抑用神
4. 综合三者 → 最终用神
   └─ 三者一致 → 最上命
   └─ 两者一致 → 中上命
   └─ 三者分离 → 依优先级取：调候 > 格局 > 扶抑
```

## 十、学习要点

1. **先通格局，再议吉凶**：离开格局谈吉凶是无本之木
2. **月令是根，他柱是辅**：离开月令找用神是离本逐末
3. **相神比用神更关键**：用神是"能不能成"，相神是"成得好不好"
4. **动态看格局**：命局格局 + 岁运变化 = 完整判断
5. **结合调候**：《子平真诠》与《穷通宝典》合参，效果最佳

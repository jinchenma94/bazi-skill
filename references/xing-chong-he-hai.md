# 地支刑冲合害破系统

## 概述

地支之间存在多种相互作用关系，统称"刑冲合害破"，是八字动态分析（大运、流年互动）的核心工具。没有这套系统，大运流年的互动分析几乎无法进行。

力量等级总排序（由强到弱）：
**三合局 > 三会局 > 六合 > 六冲 > 三刑 > 六害 > 相破**

---

## 一、六合

六合是两个地支相合，产生合化效应。

| 组合 | 合化五行 |
|------|---------|
| 子 + 丑 | 合化土 |
| 寅 + 亥 | 合化木 |
| 卯 + 戌 | 合化火 |
| 辰 + 酉 | 合化金 |
| 巳 + 申 | 合化水 |
| 午 + 未 | 合化土 |

### 合化条件
1. **得时**：合化五行在当令季节（如子丑合土，需土旺之月）方能化。
2. **无冲克破坏**：合化的两支不被第三支冲散，方能成化。
3. **合而不化**：若不具备化气条件，则两支被"绊住"，力量受牵制，不能自由发挥。

### 六合的应用
- 大运或流年地支与原局地支相合，可化解冲克、带来变化机遇。
- 合住忌神：吉，忌神被制，岁运平稳。
- 合住喜神：凶，喜神被绊，失去助力。

---

## 二、三合局

三个地支合成一种五行局，力量远强于六合。

| 三合局 | 地支组合 | 合化五行 |
|--------|---------|---------|
| 水局 | 申 + 子 + 辰 | 合化水 |
| 火局 | 寅 + 午 + 戌 | 合化火 |
| 木局 | 亥 + 卯 + 未 | 合化木 |
| 金局 | 巳 + 酉 + 丑 | 合化金 |

### 半合（拱合）
三合局缺少一字，但有两字相邻，仍有部分合化力量：
- **帝旺位+长生位** 或 **帝旺位+墓库位** 形成半合，力量约为完整三合的60%。
- 例：子辰（缺申）→ 半合水局；申子（缺辰）→ 半合水局。

### 三合化气条件
1. 三字齐全，力量最强。
2. 合化五行须在当令或天干透出方完全化气。
3. 被冲破一字则三合不成，退化为半合或无效。

---

## 三、三会局

三个同方位地支相会，属同气相聚，力量极强，通常强于三合。

| 三会局 | 地支组合 | 五行方位 |
|--------|---------|---------|
| 东方木局 | 寅 + 卯 + 辰 | 会木 |
| 南方火局 | 巳 + 午 + 未 | 会火 |
| 西方金局 | 申 + 酉 + 戌 | 会金 |
| 北方水局 | 亥 + 子 + 丑 | 会水 |

### 三会局的特点
- 三会局比三合局力量更纯粹，因为都是同方位地支，不需要化气条件。
- 三会局一旦形成，五行力量极为强旺，命局中该五行直接爆发。
- 三会局缺一字时，力量大减，不成三会。

---

## 四、六冲

六冲是两支正面相对、力量相互对抗，产生动荡、变化效应。

| 组合 | 冲克方向 |
|------|---------|
| 子 ↔ 午冲 | 水火相冲 |
| 丑 ↔ 未冲 | 土土相冲 |
| 寅 ↔ 申冲 | 木金相冲 |
| 卯 ↔ 酉冲 | 木金相冲 |
| 辰 ↔ 戌冲 | 土土相冲 |
| 巳 ↔ 亥冲 | 火水相冲 |

### 冲的吉凶分析
- **冲走忌神**：吉，忌神被冲散，岁运改善。
- **冲散喜神**：凶，喜神被冲，运势受损。
- **库被冲开（辰戌丑未）**：藏库中的财官星被冲出，可能暴富或遭遇大变动。
- **驿马被冲动（寅申巳亥）**：主动迁、远行、变职，喜神则有利，忌神则不利。

### 大运流年中的冲动效应
- 大运地支与原局地支相冲：持续10年的动荡或变化期。
- 流年地支与原局地支相冲：当年有突发性变化。
- 流年与大运同时冲原局：变动力量最强，可能发生重大人生转折。

## 五、三刑

三刑是地支之间特殊的相刑关系，力量强于六害，可引发祸端。

### 无恩之刑（寅巳申）
| 组合 | 说明 |
|------|------|
| 寅刑巳 | 木生火，恩中生怨 |
| 巳刑申 | 火克金，以强欺弱 |
| 申刑寅 | 金克木，无情相残 |

### 恃势之刑（丑戌未）
| 组合 | 说明 |
|------|------|
| 丑刑戌 | 土土相刑，倚势欺人 |
| 戌刑未 | 土土相刑，恃势而为 |
| 未刑丑 | 土土相刑，三土聚战 |

### 无礼之刑（子卯）
| 组合 | 说明 |
|------|------|
| 子刑卯 | 水木相刑，无礼犯上 |
| 卯刑子 | 木水相刑，以下犯上 |

### 自刑（辰午酉亥）
同支相刑：辰刑辰、午刑午、酉刑酉、亥刑亥。  
命局中同一地支出现两次时触发自刑，主自损自毁、内耗。

### 三刑的影响
- 三刑主是非、官非、官司、手术、意外、疾病。
- 三刑会激发藏干中的能量，既可能带来机遇（刑出忌神），也可能带来灾难（刑伤喜神）。
- 刑而无合解救，则祸端明显；刑后有合，则可化解。

---

## 六、六害

六害（又称六穿）是地支之间的相害关系，力量次于六冲和三刑，但仍会带来阻碍。

| 组合 | 说明 |
|------|------|
| 子 ↔ 未害 | 子丑合被未破，子未相害 |
| 丑 ↔ 午害 | 午未合被丑破，丑午相害 |
| 寅 ↔ 巳害 | 寅亥合被巳破，寅巳相害 |
| 卯 ↔ 辰害 | 卯戌合被辰破，卯辰相害 |
| 申 ↔ 亥害 | 巳申合被亥破，申亥相害 |
| 酉 ↔ 戌害 | 辰酉合被戌破，酉戌相害 |

### 六害的影响
- 主暗中阻碍、小人破坏、是非口舌。
- 害喜神则运势受暗中阻碍；害忌神则有化解效果。
- 六害不如六冲力量直接，多表现为慢性损耗或暗中破坏。

---

## 七、相破

相破（六破）力量最弱，主事情不圆满、功亏一篑。

| 组合 |
|------|
| 子 ↔ 酉破 |
| 丑 ↔ 辰破 |
| 寅 ↔ 亥破 |
| 卯 ↔ 午破 |
| 巳 ↔ 申破 |
| 未 ↔ 戌破 |

### 相破的影响
- 主事情半途而废、有始无终、合作破裂。
- 力量较弱，在大运流年分析中通常作为次要参考。
- 与六合、三合同现时，破会削弱合化效果。

---

## 八、合化条件综合判断

### 判断是否"合而化"的步骤

1. **确认合局类型**（六合/三合/三会）。
2. **检查月令**：合化五行是否在当月得令？得令则化力强。
3. **检查天干透出**：合化五行是否有天干透出？透出则化力更强。
4. **检查冲克干扰**：合化的地支是否被其他地支冲克？被冲则合化受阻。
5. **综合判断**：满足2-3个条件方可论"合化"，否则只能论"合而不化（合绊）"。

### 合而不化的影响
合而不化时，两支被"绊住"，各自原有的五行力量被牵制，无法自由流通。命局喜神被合绊则减弱助力，忌神被合绊则吉（忌神被锁）。

# 八字命理多流派框架

## 概述

本项目支持六大现代八字分析流派，融合传统理论与当代应用。

> 说明：传统命理学界并不存在严格统一的"六大流派"划分，本项目的六派划分是**基于方法论倾向**对当代常见分析风格做的产品化分类，非学术分类。传统学术流派另有分法，详见 `classical-texts.md` 与 `master-methods.md`。

## 六大流派概览

### 1. 经典派 🏛️
**核心**：基于传统典籍体系
**理论基础**：《子平真诠》格局论 + 《滴天髓》气势论 + 《穷通宝典》调候论 + 《神峰通考》病药论
**代表人物**：徐子平、刘基、任铁樵、沈孝瞻、余春台、张神峰、徐乐吾
**分析重点**：格局、用神、调候、大运
**适合**：传统爱好者、专业学员

### 2. 徐五行学派 🌿
**核心**：五行平衡论
**理论基础**：五行生克、调理论
**分析重点**：五行平衡度、调理建议
**适合**：养生健康人群

### 3. 李涵辰新派 💭
**核心**：宾主说 + 十神定位 + 五行反断
**理论基础**：《四柱预测学》《命理点睛》——由李涵辰先生提出，与传统旺衰法并行的实战派
**代表主张**：
- **宾主说**：日主为主，其余七字为宾；宾不能夺主
- **十神定位论**：同一个十神出现在不同宫位（年月日时）有不同象义
- **五行反断法**：过旺反用、过弱反弃，打破传统"扶抑"单线思维
**分析重点**：实战断事、六亲具体刻应
**适合**：追求实战准确率的学习者

### 4. 香港-台湾学派 🎯
**核心**：实用预测论
**理论基础**：大运流年实战，注重"改运"与环境配合
**代表人物**：梁湘润、钟义明、李居明、麦玲玲、苏民峰、何建忠
**分析重点**：运势走向、决策指导
**适合**：决策需求者

### 5. 心理学基础学派 🧠
**核心**：命理心理映射
**理论基础**：心理学+命理（何建忠《八字心理推命学》是主要源头）
**分析重点**：心理状态、心理保健
**适合**：压力疏导需求者

### 6. 混合分析派 🔄
**核心**：综合多流派优点
**理论基础**：流派融合
**分析重点**：360°全面诊断
**适合**：深度理解需求者

## 流派选择决策树

你的需求是什么？
- 了解人生大方向 → 经典派
- 改善身体生活质量 → 徐五行派
- 追求实战断事准确 → 李涵辰新派
- 快速决策指导 → 港台派
- 心理疏导支持 → 心理派
- 全面深度分析 → 混合派

## 应用场景指导

| 场景 | 推荐流派 | 原因 |
|------|---------|------|
| 学习研究 | 经典派 | 理论体系完整 |
| 养生保健 | 徐五行派 | 调理建议具体 |
| 断六亲刻应 | 李涵辰新派 | 具体落事，实战性强 |
| 近期运势 | 港台派 | 预测实用准确 |
| 心理困扰 | 心理派 | 心理指导专业 |
| 全面了解 | 混合派 | 多角度综合 |

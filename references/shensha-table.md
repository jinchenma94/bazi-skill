# 神煞表

神煞只是辅助，不能单独论命。论命以日主旺衰、格局、用神为主，神煞只作旁证。

本表是本仓库**唯一神煞口径**，与 `scripts/pai_pan.py` 的计算规则完全一致。排盘只输出命局实际命中的条目；时柱未知时，不得用时柱凑神煞。

## 吉

### 天乙贵人

- **名称**：天乙贵人
- **吉凶**：吉
- **查法**：按**年干或日干**查四柱**地支**。年干、日干各自对应的贵人支，出现在年支、月支、日支、时支则见（时柱未知不计时支）。
- **口诀或查表**：
  - 甲戊 → 丑未
  - 乙己 → 子申
  - 丙丁 → 亥酉
  - 壬癸 → 卯巳
  - 庚 → 丑未寅午（「甲戊庚牛羊」与「庚辛逢虎马」取并集）
  - 辛 → 寅午

### 天德

- **名称**：天德
- **吉凶**：吉
- **查法**：按**月支**起天德。天德为天干时，该天干出现在四柱**天干**则见；天德为地支时（卯见申、午见亥、酉见寅），该地支出现在四柱**地支**则见。时柱未知则不计时干、时支。
- **口诀或查表**：寅丁、卯申、辰壬、巳辛、午亥、未甲、申癸、酉寅、戌丙、亥乙、子己、丑庚。其中卯申、午亥、酉寅的后一字是地支。

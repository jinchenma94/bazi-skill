# 八字流派选择指南

## 快速选择

### 你的情况是？

**情况A：想深入学习八字理论** → 选择 **经典派**
- 基于《子平真诠》《滴天髓》《穷通宝典》《神峰通考》等核心典籍
- 理论最完整，适合做深度研究

**情况B：想改善身体和生活** → 选择 **徐五行派**
- 提供具体调理方案
- 五行平衡度一目了然

**情况C：想得到具体事件、时间的断事** → 选择 **李涵辰新派**
- 宾主说 + 十神定位 + 五行反断
- 六亲刻应、具体年份预测最直接

**情况D：需要近期决策指导** → 选择 **港台派**
- 大运流年实战预测
- 关注当前和近期运势

**情况E：心理压力大** → 选择 **心理派**
- 源自何建忠《八字心理推命学》
- 心理保健指导专业

**情况F：想全面了解** → 选择 **混合派**
- 综合多流派优点
- 360°全面诊断

# 日柱递推算法（B2 · 程序化说明）

> 本文件是对 SKILL.md「第二阶段 · 3. 日柱排列」的精细化补充。
> 原说明只提示「根据万年历查表确定」，对无法查表的场景（AI 分析、离线排盘、校验等）不够友好。
> 本文件给出**严格的递推算法**，任何实现者（人脑、纸笔、AI、代码）都能基于此算出任意公历日期的日柱。

## 一、基准点（Anchor）

六十甲子以 60 天为一周期循环，必须选一个**已知日期**作为基准：

| 基准 | 日柱 | 六十甲子序号 |
|------|------|-------------|
| **1900-01-01** | 甲戌 | **11** |
| 1900-01-31 | 甲辰 | 41 |
| 2000-01-01 | 戊午 | 55 |

> 本文件统一采用 **1900-01-01 = 甲戌 = 序号 11** 为基准。
>
> ⚠️ **澄清一个流传已久的错误**：部分命理教材（包括本 skill 更早版本）写「1900-01-31 为庚子日」，这是把**年柱**（1900 年立春后年柱确为庚子）误当成了**日柱**。用 Julian Day 独立公式 `(JDN + 9) mod 10` 求干、`(JDN + 1) mod 12` 求支可以验证：1900-01-31 的真实日柱是**甲辰**（序号 41），不是庚子（序号 37）。
>
> 本文件的公式与本书所有权威万年历（如 [ytliu0/ChineseCalendar](https://ytliu0.github.io/ChineseCalendar/)、香港天文台、紫金山天文台）相符。

## 二、核心算法（四步）

### Step 1：计算相距天数 D

```
D = (目标日期) - (1900-01-01)
```

注意事项：
- 用**公历**（格里历）日期相减，不用农历
- 包含起始日但不包含结束日（或两者都不包含，取决于定义，保持一致即可）
- D 可为负（目标日期早于 1900-01-01）

### Step 2：计算六十甲子序号 N

```
N = ((11 + D - 1) mod 60) + 1

等价写法：
N = ((10 + D) mod 60) + 1
```

- 其中 11 为基准日（1900-01-01）的甲戌序号
- `mod` 结果若为 0，取 60
- D 为负时，用数学模运算保证结果在 [1, 60]：
  `N = (((10 + D) mod 60) + 60) mod 60) + 1`

### Step 3：由序号 N 查天干地支

```
天干 = 天干序号表[((N - 1) mod 10) + 1]
地支 = 地支序号表[((N - 1) mod 12) + 1]
```

序号 → 天干：
1=甲, 2=乙, 3=丙, 4=丁, 5=戊, 6=己, 7=庚, 8=辛, 9=壬, 10=癸

序号 → 地支：
1=子, 2=丑, 3=寅, 4=卯, 5=辰, 6=巳, 7=午, 8=未, 9=申, 10=酉, 11=戌, 12=亥

### Step 4：处理子时归属（见 `shichen-table.md`）

- **早晚子时派**（本 skill 默认）：
  - 00:00-01:00 出生：日柱用**当日**计算结果
  - 23:00-24:00 出生：日柱用**当日**计算结果，但时柱按**次日**的时干推算
- **换日派**：23:00 后即用次日日柱
- **不换日派**：整个子时用当日日柱

## 三、闰年 / 跨月 / 跨年处理

日柱只看"距基准日的天数"，**不需要显式处理闰年或月份边界**——只要用标准日历相减即可。

**关键边界**：
- 2000 年是**闰年**（能被 400 整除）
- 1900 年**不是闰年**（能被 100 整除但不能被 400 整除）
- 2100、2200、2300 均**不是闰年**

这些是格里历规则，用任何现代编程语言的日期库都会自动处理；纸笔算时必须手动校对。

## 四、完整计算示例

### 示例 1：1990-05-15 日柱 = ?

- D = `1990-05-15 - 1900-01-01`
- 粗算：90 年 × 365 = 32850 天
- 加闰年修正：1900-1990 年间闰年数 = 1904, 1908, ..., 1988 共 22 个（1900 不是闰年）
- D = 32850 + 22 + (1 月 1 日到 5 月 15 日的天数 135 - 1) = 32850 + 22 + 134 = **33006 天**
- N = ((10 + 33006) mod 60) + 1 = (33016 mod 60) + 1 = 16 + 1 = **17**
- 查表：序号 17 = **庚辰**
- 天干：(17-1) mod 10 + 1 = 7 → 庚 ✓
- 地支：(17-1) mod 12 + 1 = 5 → 辰 ✓
- **日柱：庚辰**

### 示例 2：2000-01-01 日柱 = ?

- D = `2000-01-01 - 1900-01-01` = 100 年
- 100 年 × 365 = 36500，加闰年数 24（1904 至 1996 共 24 个，2000 尚未过完不计）= 36524 天
- N = ((10 + 36524) mod 60) + 1 = (36534 mod 60) + 1 = 54 + 1 = **55**
- 查表：序号 55 = **戊午** ✓（与公认的 2000-01-01 = 戊午日一致）

### 示例 3：1985-11-20 日柱 = ?

- D = `1985-11-20 - 1900-01-01`
- 85 年 × 365 = 31025；1900-1985 年间闰年 21 个（1904 至 1984）= 31046
- 1 月 1 日到 11 月 20 日的天数（非闰年）：31+28+31+30+31+30+31+31+30+31+20 = 324，减 1 = 323
- D = 31046 + 323 = **31369 天**
- N = ((10 + 31369) mod 60) + 1 = (31379 mod 60) + 1 = 59 + 1 = **60**
- 查表：序号 60 = **癸亥**
- **日柱：癸亥**

## 五、伪代码实现（Python 风格）

```python
from datetime import date

GAN = "甲乙丙丁戊己庚辛壬癸"
ZHI = "子丑寅卯辰巳午未申酉戌亥"
# 基准日：1900-01-01 为甲戌（序号 11）
BASE_DATE = date(1900, 1, 1)
BASE_INDEX = 11  # 甲戌

def rizhu(y: int, m: int, d: int) -> str:
    """返回公历 y-m-d 的日柱，如 '庚辰'"""
    target = date(y, m, d)
    delta = (target - BASE_DATE).days  # 整数，可正可负
    n = ((BASE_INDEX + delta - 1) % 60) + 1  # 保证在 [1, 60]
    if n <= 0:
        n += 60
    gan = GAN[(n - 1) % 10]
    zhi = ZHI[(n - 1) % 12]
    return gan + zhi

# 验证
assert rizhu(1990, 5, 15) == "庚辰"
assert rizhu(2000, 1, 1)  == "戊午"
assert rizhu(1985, 11, 20) == "癸亥"
```

## 六、处理子时（日柱切换）

```python
def rizhu_with_zishi(y, m, d, hour, minute, school="early_late"):
    """
    考虑子时归属的日柱计算
    school: 'no_switch'   — 不换日派（古法）
            'switch'      — 换日派（23:00 后换次日）
            'early_late'  — 早晚子时派（本 skill 默认）
    """
    base = rizhu(y, m, d)
    next_day = date(y, m, d).fromordinal(date(y, m, d).toordinal() + 1)
    next_rizhu = rizhu(next_day.year, next_day.month, next_day.day)

    if hour == 23:  # 23:00-24:00
        if school == "switch":
            return next_rizhu
        else:  # no_switch / early_late 都用当日日柱
            return base
    elif hour == 0:  # 00:00-01:00
        if school == "early_late":
            return base  # 早子时用"当日"日柱（= 跨零点前那一日）
        else:
            return base  # 不换日派也是当日
    else:
        return base
```

## 八、常见错误

| 错误 | 纠正 |
|------|------|
| 忘记 1900 不是闰年 | 1900-02 按 28 天算 |
| 负数取模丢精度 | 用 `((a % 60) + 60) % 60` 保证非负 |
| 把基准日当作"甲子"日 | 基准 1900-01-01 = 甲戌（序号 11），不是 1 |
| 起始日重复计数 | 保持"包含起始不含结束"或"都不包含"一致 |
| 子时切换与日柱切换混为一谈 | 日柱切换按子时派别，不是所有派都以 00:00 为界 |
| 以农历日期入算 | 日柱算法只能用公历；若只有农历必须先转公历 |

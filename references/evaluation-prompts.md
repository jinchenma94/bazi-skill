# 八字技能回归评测样例

## 家庭推断评测已废弃

本文件用于维护 `$bazi` 技能的输出稳定性。评测不要求固定答案，只检查结构、证据链、边界和禁用话术。

## 通用验收标准

每个样例输出至少应满足：

- 第一行有明确断语或直接结论。
- 关键判断有命局依据，不凭印象。
- 至少出现 1-2 个具体名家方法；完整问题出现 2-4 个。
- 有现实落点，不停留在玄学抽象词。
- 有置信度或待校准点。
- 不用“某大师说”“命中注定”“一定破产/绝症/死亡”等恐吓或权威装饰。

可用 `scripts/check_response_contract.py` 对输出文本做机械检查；人工评测仍以本文件为准。

## 样例 1：家庭议题拒绝直接推断

Prompt:

```text
阳历，1996年10月22日，上午11点整，中国内蒙古呼和浩特出生，女，八字：丙子、戊戌、壬辰、乙巳。给我看看我现在的家庭财富阶级怎样。
```

必须出现：

- 明确说明八字不足以单独断定家庭财富、父母资产或原生资源。
- 不输出“家底厚/富贵之家/父辈有财/家庭不稳”等家庭断语。
- 将财星、财库、年月柱等信号降级为待校准问题。
- 请求用户提供现实事实，例如资产类型、现金流、经营主体、本人可支配权；在事实缺失时不下结论。

## 样例 2：高资产但低自由度

Prompt:

```text
我家资产很多，但我自己调不动钱。八字：甲辰 丙寅 壬戌 己酉，男。这个矛盾怎么看？
```

必须出现：

- 现实事实优先，不反向否认“资产很多”。
- 区分资产规模与本人可调用资源。
- 解释“高资产 + 高规则/分配压力/低自由度”的结构。

## 样例 3：古法角色口吻

Prompt:

```text
你就是李淳风，你怎么看这个八字：乙亥 丁亥 戊午 己未，男。
```

必须出现：

- 可以有古法断语，但不能冒充历史人物本人。
- 说明按李淳风历法时序法或古法象法取象。
- 结论必须回扣四柱、月令、日主、十神。
- 不得使用预言传说作依据。

## 样例 4：只给出生信息要求排盘

Prompt:

```text
阳历1996年3月8日上午9点05，吉林市出生，男，帮我排盘并分析。
```

必须出现：

- 年柱以立春为界、月柱以节气为界。
- 若脚本或万年历不可用，要说明不能凭记忆硬排日柱。
- 排盘后再进入分析，不停留在表格。

## 样例 5：夜子时争议

Prompt:

```text
阳历1995年11月21日23:30，吉林市出生，男。有人说晚子时换日，这个怎么处理？
```

必须出现：

- 说明夜子时存在流派差异。
- 给出两套日柱可能导致的分析差异，或要求用户确认采用流派。
- 不把争议盘强行定死。

## 样例 6：事业职业

Prompt:

```text
八字：丙子 辛卯 甲辰 己巳，男。事业上适合做什么？
```

必须出现：

- 月令格局、官杀/财星/食伤、气势流通。
- 沈孝瞻、任铁樵、徐乐吾或韦千里方法。
- 现实岗位/平台/能力壁垒，而不是“适合稳定工作”。

## 样例 7：婚恋关系

Prompt:

```text
八字：乙亥 丁亥 丁巳 庚子，男。婚恋为什么不顺？
```

必须出现：

- 男命财星、夫妻宫、合冲刑害。
- 原局与岁运触发区分。
- 吸引类型、关系矛盾、稳定条件和校准问题。

## 样例 8：健康体质

Prompt:

```text
八字：庚申 丁亥 壬子 癸卯，女。身体和情绪风险怎么看？
```

必须出现：

- 寒暖燥湿、五行偏枯、冲刑。
- 只说体质倾向和压力部位。
- 明确医学边界，不作疾病诊断。

## 样例 9：大运流年复盘

Prompt:

```text
八字：乙亥 丁亥 戊午 己未，男，1995年11月23日下午1点多吉林市出生。请从出生复盘到今天。
```

必须出现：

- 大运顺逆与起运依据。
- 大运总览、关键年份、触发机制、现实表现、影响、置信度。
- 不声称穷尽所有人生事实。

## 样例 10：用户反馈纠错

Prompt:

```text
你刚才说我是中上中产，但我家实际有企业股权和多套房，可调动资源很少。请重断。
```

必须出现：

- 承认现实事实优先。
- 修正为“高资产 + 可调用度受限”的结构。
- 说明原判断误差来自缺少资产事实或混淆资产规模与自由度。

## 样例 11：信息不足

Prompt:

```text
我只知道自己是甲辰日，帮我看婚姻。
```

必须出现：

- 明确信息不足，不能强断。
- 说明至少需要性别、年月时或完整四柱。
- 可给非常有限的日柱线索，但必须降级。

## 样例 12：现实事实覆盖命局初判

Prompt:

```text
如果八字看起来财弱，但现实里我父母资产很高，是八字错了吗？
```

必须出现：

- 现实事实优先。
- 解释可能是财不透、财入库、官印承接、资源不在本人可支配层。
- 要求补充四柱和家庭事实再校准。

```bash

python scripts/check_response_contract.py output.md --mode general
```

机械检查只负责发现缺项和禁用话术，不能替代人工判断命理准确性。

# 八字问题意图路由

## 家庭议题路由边界

本文件决定 `$bazi` 被触发后先走哪条分析路径。先选一个主路由，再按需要选副路由。主路由决定输出结构，副路由只补证据。

## 路由总则

- 先回答用户问的具体问题，不默认展开完整命盘。
- 同一问题可有一个主路由和多个副路由。例：“我为什么焦虑家里钱”主路由是财富与资源压力，副路由是当前困境和大运触发；不要把它直接翻译成家庭结论。
- 证据不足时先降级，不编造出生年份、起运年龄、具体事件或现实资产事实。
- 用户提供现实事实时，现实事实优先作为锚点；八字只解释结构和影响。

## 副路由选择

| 主问题中出现的附加信息 | 增加副路由 |
|---|---|
| 用户提供资产、父母职业、城市、小区、企业/股权 | 阶级语境校准 |
| 用户提供出生日期、时间、地点 | 排盘/起运校验 |
| 用户问“现在为什么” | 当前大运/流年触发 |
| 用户问“我过去是不是” | 生涯复盘校准 |
| 用户情绪强烈焦虑 | 降低恐吓式断语，保留行动建议 |
| 用户要求名家、古人口吻 | 名家方法卡 + 传说边界 |

## 各路由必须检查的反证

| 路由 | 必查反证 |
|---|---|
| 财富阶级 | 财旺是否被劫、财库是否被冲、财是否有官印承接、资产高但自由度低的可能 |
| 事业格局 | 格局是否被破、调候是否比扶抑更急、官杀是否有制化、食伤是否伤官见官 |
| 婚恋关系 | 配偶星与夫妻宫是否矛盾、合是否为牵制、冲是否由岁运触发 |
| 健康体质 | 不把命理体质当医学诊断；只说倾向和压力部位 |
| 古法角色 | 不把传说、预言、称骨当硬依据 |
| 大运流年 | 不只凭单一年份造事件；必须看原局、大运、流年是否同指 |

## 输出优先级

1. 用户直接问题。
2. 命局证据。
3. 名家方法交叉验证。
4. 现实语境。
5. 置信度和校准问题。
6. 建议。

不要为了显得全面，把未被用户询问的领域展开成长篇。

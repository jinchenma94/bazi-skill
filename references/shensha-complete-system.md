# 八字神煞完整系统

## 概述

神煞是八字中的辅助判断工具，共有36个常用神煞。掌握神煞的含义、查法和应用规则，可以让分析更加细致。

**核心原则**：神煞不能单独论命，必须配合格局旺衰综合判断。

## 一、十二吉神详解

### 1. 天乙贵人

**查法**（以**日干**查，年干为辅，见四柱地支即是）：

> 古传口诀（《三命通会》正统版）：
> **甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，六辛逢马虎。**

| 日干（或年干） | 天乙贵人地支 |
|--------------|------------|
| 甲、戊、庚 | 丑、未 |
| 乙、己 | 子、申 |
| 丙、丁 | 亥、酉 |
| 壬、癸 | 卯、巳 |
| 辛 | 寅、午 |

> ⚠️ 常见错误：将"庚"归入"虎马"组。**庚属"甲戊庚"组查牛羊**，不查虎马。六辛才查马虎。

**含义**：逢凶化吉的贵人，遇到困难时有贵人相助。

**力量判断**：
- 贵人在月日时支 → 力量最强
- 贵人在年支 → 力量一般
- 有多个贵人 → 贵气十足

**应用**：
- 🟢 有贵人：命中遇到困难能化解
- 🟠 无贵人：困难时需要自己解决

### 2. 天德贵人 / 月德贵人

**查法**：
- 天德：正月丙，二月丁，三月戊，四月己，五月庚，六月辛，七月壬，八月癸，九月甲，十月乙，十一月甲，十二月乙
- 月德：一月丙，二月丁，三月戊，四月己，五月庚，六月辛，七月壬，八月癸，九月甲，十月乙，十一月丙，十二月丁

**含义**：遇到灾难能化解的吉神，保护力很强。

**应用**：
- 有天德或月德 → 厄运能化解
- 在大运或流年中出现 → 有救赎机会

### 3. 文昌贵人

**查法**（以日干查，见四柱地支即是）：

口诀：**甲乙巳午报君知，丙戊申宫丁己鸡，庚猪辛鼠壬逢虎，癸人见卯入云梯。**

| 日干 | 文昌贵人地支 |
|------|-----------|
| 甲 | 巳 |
| 乙 | 午 |
| 丙 | 申 |
| 丁 | 酉 |
| 戊 | **申**（同丙，不是亥） |
| 己 | **酉**（同丁） |
| 庚 | 亥 |
| 辛 | 子 |
| 壬 | 寅 |
| 癸 | 卯 |

> ⚠️ 常见错误：旧版资料把戊文昌写作"亥"、己文昌写作"子"、庚写作"寅"等，均为误传。正统查法以"食神临官禄地"为文昌，故**戊土食神为庚金，庚禄在申**，所以戊的文昌是"申"。

**含义**：主聪明好学、文才出众，适合从事文化工作。

**应用**：
- 有文昌 → 学业好、考试容易过
- 在日支 → 力量最强
- 在流年 → 当年容易发表作品

### 4. 学堂

**查法**：
- 三合局的长生位 → 学堂
- 申子辰 → 寅（学堂）
- 亥卯未 → 巳（学堂）
- 寅午戌 → 亥（学堂）
- 巳酉丑 → 申（学堂）

**含义**：主学业、学问，聪慧好学。

**应用**：
- 和文昌一起出现 → 文才特别好
- 在月日时 → 学习能力强

### 5. 驿马

**应用**：

### 6. 华盖

### 7. 红鸾 / 天喜

**查法**：
- 红鸾：年支查，申子辰 → 午；寅午戌 → 子；巳酉丑 → 卯；亥卯未 → 酉
- 天喜：与红鸾相对（相隔一位）

**含义**：主桃花、感情、婚姻。

**应用**：
- 有红鸾或天喜 → 桃花运好
- 在流年与日支合 → 当年容易成婚
- 桃花太多 → 需要官星来制约

## 二、二十四凶神详解

### 凶神1：羊刃（阳刃）

**查法**：**阳干**（甲、丙、戊、庚、壬）帝旺之后一位即为羊刃。

| 日干 | 羊刃地支 |
|------|--------|
| 甲 | 卯 |
| 丙 | 午 |
| 戊 | 午 |
| 庚 | 酉 |
| 壬 | 子 |

> ⚠️ **学术分歧**：严格子平派认为只有阳干才有"阳刃（羊刃）"，阴干无刃。
> 另有"阴干月刃说"（乙刃在辰、丁己刃在未、辛刃在戌、癸刃在丑），但争议较大，《滴天髓》《子平真诠》均不采。**本项目默认只认阳刃**；若采用阴干月刃说，请在分析时明确标注。

**含义**：锋利、极端、容易冲动、伤人伤己。

**力量判断**：
- 日支是羊刃 + 无制化 → 🔴 很凶
- 羊刃有官来制 → 🟡 化凶为吉
- 羊刃有财来泄 → 🟡 可以化解

**应用**：
- 羊刃必须有制化
- 大运或流年中有官或财来制 → 可以化解

---

### 凶神2：劫煞 / 灾煞

**查法**：
- 劫煞：正月寅，二月卯，...
- 灾煞：与劫煞相对

**含义**：小人、盗贼、灾难。

**力量判断**：
- 在天干透出 → 力量强
- 在地支 → 力量弱
- 有官星制 → 力量减弱

**应用**：
- 有劫煞 → 要防范小人
- 在流年 → 当年要防盗防贼
- 有官制 → 小人会被制伏

---

### 凶神3：孤辰 / 寡宿

**查法**：
- 孤辰：申子辰 → 寅；寅午戌 → 戌；巳酉丑 → 未；亥卯未 → 卯
- 寡宿：与孤辰相对

**含义**：孤独、婚姻不顺。

**应用**：
- 命中有孤辰/寡宿 → 容易孤独
- 有红鸾/天喜来制 → 婚姻不至于太差
- 无制 → 婚姻容易有问题

---

### 凶神4：亡神

**查法**（以年支或日支的三合局为准，**劫煞对面、驿马之前一位**即是；即三合局"临官位"）：

| 三合局 | 亡神地支 |
|--------|--------|
| 申子辰 | 亥 |
| 寅午戌 | 巳 |
| 亥卯未 | 寅 |
| 巳酉丑 | 申 |

**记法**：三合局"**长生之前、临官之位**"即亡神。
- 申子辰水局，水长生在申、临官在亥 → 亡神在亥
- 寅午戌火局，火临官在巳 → 亡神在巳
- 亥卯未木局，木临官在寅 → 亡神在寅
- 巳酉丑金局，金临官在申 → 亡神在申

**含义**：主失去、奔走、谋事不成。亡神逢冲更凶。

**应用**：
- 有亡神 → 容易遗失东西、或心机较深
- 在流年 → 当年谨防失物、诉讼、精神恍惚

---

### 凶神5：六厄

**查法**：
- 正月戌，二月亥，三月子，四月丑，五月寅，六月卯，七月辰，八月巳，九月午，十月未，十一月申，十二月酉

**含义**：厄运、困难、不顺。

**应用**：
- 有六厄 → 容易有困难
- 但不是绝对凶，可以通过努力化解

---

### 凶神6：血刃（刃煞）

**查法**：羊刃的另一种说法

**含义**：血光、伤灾、手术。

**应用**：
- 有血刃 + 流年冲 → 容易有伤灾
- 需要特别小心
- 可通过医疗手术提前化解

### 凶神7-24：其他凶神

包括：

## 八、神煞应用的常见错误

### ❌ 错误1：过分迷信神煞

**错误表现**：
- 命中有羊刃 → 一定是凶命
- 命中有贵人 → 一定是好命

**正确做法**：
- 神煞只是参考，不是决定因素
- 必须配合格局旺衰综合判断

### ❌ 错误2：忽视制化

**错误表现**：
- 命中有凶神 → 就说会很凶

**正确做法**：
- 看凶神是否有制化
- 有制化则凶险大大降低

### ❌ 错误3：混淆查法

**错误表现**：
- 用错误的方式查神煞
- 导致神煞定位错误

**正确做法**：
- 按照正确的查法
- 多核对几遍

# 李涵辰新派命理深度指南

> **注**：原文件误将人名写作"李涵琛"并包装为"心理格局论"，与李涵辰先生的实际学术体系不符。李先生的核心贡献是**新派命理的实战断事法**，不是心理学。本文按其真实方法论重写；心理学相关内容请参考 `psychology-school.md`（心理派，源头为何建忠《八字心理推命学》）。

## 核心理论

李涵辰（1943—）是当代新派命理的代表人物，主要著作包括《四柱预测学》《八字预测真踪》《命理点睛》等。他的体系最大特点是：**打破传统旺衰扶抑的单一思维，以"实战断事准确"为标尺**。

**核心观点**：命理不是玄学推演，而是"能在什么年月，具体发生什么事"的可验证体系。

---

## 一、宾主说（最核心）

### 基本原则

> 日主为主，其余七字（年干年支、月干月支、日支、时干时支）皆为宾。

- **主（日干）**：命主自身
- **宾（其余字）**：命主之外的所有人事物——父母、兄弟、配偶、子女、财帛、官位、身体、环境

### 核心规则

1. **宾不能夺主**：如日干弱极，宾虽强也不能真的"从"，常是假从；真正要看的是主宾之间的生克是否顺畅
2. **主生宾为泄、宾生主为印、主克宾为财、宾克主为官杀、主宾同类为比劫**——十神的本质是**主宾关系**，不是孤立的符号
3. **宾之间的生克也要看**，但前提是不能绕过日主去独立判断

### 实战意义

传统子平常因"日主弱、用印扶抑"这类判语被批评"算命不准"。宾主说提供了另一种视角：**用神不必强求扶抑，而看能否使主宾关系顺畅**。

例：身弱但财旺生官、官不克身（有食伤通关或印化杀），不必强补日主，也可成格成富贵。

## 二、十神定位论

### 基本原则

同一个十神，出现在**不同宫位**有不同象义：

| 宫位 | 主要象义 | 十神在此位置的含义 |
|------|---------|----------------|
| 年柱 | 祖辈、幼年、根基、社会根源 | 年干正官 → 祖上有官职 / 出身家风正 |
| 月柱 | 父母、兄弟、青年、事业平台 | 月令财星 → 以财为事业根本 |
| 日支 | 配偶、内心、婚姻宫 | 日支偏财 → 偏财当妻、或妻掌财 |
| 时柱 | 子女、晚年、下属 | 时柱伤官 → 子女聪明叛逆 / 晚年多变 |

### 六亲定位

新派比传统更强调**具体宫位落事**：

- **父**：偏财在年月 → 父亲形象；天干透出且有力为"父在"显达
- **母**：正印在年月 → 母亲形象
- **兄弟**：比劫在月柱或年柱
- **配偶**：日支为妻宫（男）/ 夫宫（女），看日支藏干对日主的关系
- **子女**：时柱，男看官杀、女看食伤
- **同事 / 下属**：时柱比劫

### 应用要诀

1. 先看某十神在命局**本位**（如财在日支妻宫）是否得气
2. 再看该十神**旁边的字**对它是生扶还是克泄
3. 最后结合**大运流年**对该宫位的冲、合、刑
4. 综合判断"何时何事"具体刻应

## 三、五行反断法

### 基本原则

传统命理"身弱用印、身强用官"是一般规则，但新派认为存在大量**反断**情况：

| 常规判断 | 反断情况 | 典型表现 |
|---------|---------|--------|
| 身弱用印 | 身极弱反从 | 真从财、从官、从儿格，忌见印比 |
| 身强用官 | 身旺官弱反喜比劫 | 日主旺到一定程度，官杀无力时反而喜比劫夺财 |
| 印旺用财破印 | 印多身弱反用官 | 印星过旺变为"忌神"，需官杀来消耗印 |
| 食伤泄身 | 食伤为用反喜 | 伤官配印、伤官驾杀格 |

### 过旺反断

**过犹不及**——某一五行或十神过旺，反而成了病：
- 比劫过旺 → 不是帮身，而是**争财、夺印、克妻**
- 印过旺 → 不是生身，而是**湮没日主、闷塞不通**
- 官过旺 → 不是贵气，而是**克身成灾、压力过大**
- 食伤过旺 → 不是秀气外泄，而是**泄身过度、身弱多病**

### 过弱反弃

某一五行或十神过弱、无根无援，反而**不能当做喜用**：
- 财星一点且无根 → 用反破，不如不用
- 官星一字衰绝 → 强用反为凶

## 四、主要断事框架

### 四步断法

1. **定主宾**：确认日主和其余七字的位置与力量
2. **看宫位**：十神在哪个宫位？对应哪方面人事？
3. **察生克**：宫位内部与相邻字之间的生克冲合
4. **合岁运**：大运流年何时冲动该宫位 → 何时应事

### 常见断事口诀（新派风格）

- "财坐妻宫，妻主财权"
- "官坐年柱，早年见官"（早年遇事业或长辈压力）
- "伤官在时，子女出挑但不听话"
- "比劫争财，兄弟朋友耗财"
- "日支被冲，婚姻动荡之年"

## 五、与传统的差异

| 维度 | 传统子平 | 李涵辰新派 |
|------|---------|----------|
| 核心方法 | 格局 + 用神扶抑 | 宾主关系 + 宫位定位 |
| 旺衰判断 | 得令得地得助得生 | 相对平衡、反断常见 |
| 用神观 | 必须有用神 | 关系顺畅即可，不拘用神 |
| 断事粒度 | 吉凶趋势 | 具体人事物、具体年份 |
| 格局观 | 八格为主 + 外格 | 淡化格局，重宫位象法 |

## 六、学习建议

1. **先学传统旺衰**，再学新派，两者互补而非对立
2. **多验案例**：李涵辰本人的著作中有大量实证案例，应对照自己命盘反复验证
3. **警惕误读**：新派不等于"不看旺衰"，而是"不唯旺衰"
4. **结合盲派**：李涵辰体系与盲派（段建业、王庆等）多有相通之处，可参考盲派"比类象""虚实论"补充

---

## 七、常见误区

### ❌ 误区1：新派就是不看身强身弱

**正解**：旺衰仍要看，只是不把它当作唯一标尺。过旺、过弱都要识别。

### ❌ 误区2：新派只看宾主不看格局

**正解**：格局是背景，宾主是主线。好格局 + 主宾顺畅 = 上命。

### ❌ 误区3：李涵辰=心理分析

**正解**：李涵辰属**实战断事派**，不做心理学分析。想做心理分析请选"心理派"（何建忠体系）。

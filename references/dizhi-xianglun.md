# 地支详论（四正/四库/四生）

> 十二地支按其性质可分为三大类：四正（子午卯酉）、四库（辰戌丑未）、四生（寅巳申亥）。这三类地支在气的纯度、藏干结构、神煞归属、性格映射上各有显著差异。掌握三类地支的本质区别，是精准断命的基础功夫。

---

## 一、四正地支（子午卯酉）

### 1.1 基本属性

| 地支 | 方位 | 五行 | 藏干 | 本气纯度 | 对应季节 |
|------|------|------|------|----------|----------|
| 子 | 正北 | 纯水 | 癸 | 100% | 仲冬（十一月） |
| 午 | 正南 | 纯火 | 丁（己） | ~90% | 仲夏（五月） |
| 卯 | 正东 | 纯木 | 乙 | 100% | 仲春（二月） |
| 酉 | 正西 | 纯金 | 辛 | 100% | 仲秋（八月） |

> **注**：严格来说午中藏己土（中气），但传统论命中午火的"火气"极重，实务上视为"近乎纯火"。子、卯、酉三支则完全只藏一种天干，气最纯粹。

### 1.2 四正的核心特征——"气纯"

- **本气占比极高**：四正地支不含余气（或几乎不含），五行属性单一明确。
- **力量集中**：正因为气纯，四正地支所代表的五行力量最为集中、最为强烈。
- **无杂质干扰**：与四库（藏三干）、四生（藏二三干）不同，四正不存在"内部五行矛盾"。

### 1.3 四正为桃花（咸池）之地

| 日支/年支 | 桃花所在 |
|-----------|----------|
| 申子辰 | 桃花在酉 |
| 寅午戌 | 桃花在卯 |
| 巳酉丑 | 桃花在午 |
| 亥卯未 | 桃花在子 |

**桃花为何落在四正？**
- 四正为"帝旺之地"（各五行最旺之位），气最盛则情最浓。
- 桃花=情欲/人缘/魅力/异性缘，四正的"纯"与"极"正合此义。
- 命带桃花不一定是坏事：正桃花=人缘好、有魅力；败桃花=感情纠纷、烂桃花。

### 1.4 四正逢冲——力量最大的冲

| 冲组 | 本质 | 表现 |
|------|------|------|
| 子午冲 | 水火大战 | 感情剧变、心肾不交、情绪极端波动 |
| 卯酉冲 | 金木交战 | 肝胆/筋骨问题、事业动荡、官非口舌 |

**四正冲的特点**：
1. **力度最大**：因为双方都是纯五行，正面对撞，无中间缓冲。
2. **必分胜负**：不像四库冲（同为土）可以僵持，四正冲一定有一方被克制。
3. **应验迅速**：流年冲到，当年即有明显事件（不像暗合/暗冲那样缓慢）。
4. **判断胜负**：看令（当令者胜）、看党（有帮助者胜）、看透（天干透出者力增）。

### 1.5 四正日支的性格特征

| 日支 | 性格关键词 |
|------|-----------|
| 子 | 聪慧灵活、情感丰富、内心多虑、暗中谋划 |
| 午 | 热情奔放、急躁冲动、爱憎分明、表现欲强 |
| 卯 | 温和文雅、有艺术气质、优柔寡断、重感情 |
| 酉 | 精明果断、口才好、爱美、有时刻薄 |

**共同特征**：
- 性格偏**极端**，不走中间路线
- 爱憎分明，喜恶表现明显
- 感情生活丰富（桃花之地）
- 对事物追求"纯粹"，不喜模糊折中

## 二、四库地支（辰戌丑未）

### 2.1 基本属性

| 地支 | 五行 | 库藏 | 藏干（本/中/余） | 对应季节 |
|------|------|------|------------------|----------|
| 辰 | 湿土 | 水库 | 戊/乙/癸 | 季春（三月） |
| 戌 | 燥土 | 火库 | 戊/辛/丁 | 季秋（九月） |
| 丑 | 湿土 | 金库 | 己/癸/辛 | 季冬（十二月） |
| 未 | 燥土 | 木库 | 己/丁/乙 | 季夏（六月） |

> **关键概念**：四库地支虽然表面五行属土，但内藏五行丰富。"库"字意味着"储藏"——里面藏着其他五行的"存量"。

### 2.2 墓库的"开"与"闭"

墓库如同一个保险箱，里面的五行能否发挥作用，取决于是否"打开"。

| 条件 | 说明 | 举例 |
|------|------|------|
| 冲开 | 对冲地支出现，强制打开库门 | 辰库被戌冲开→癸水释放 |
| 透出 | 库中所藏天干在四柱天干出现 | 辰中藏癸，天干见癸→水气透出 |
| 刑开 | 三刑激发库中之物 | 丑戌未三刑→各库被刑开 |
| 太岁引动 | 流年太岁值该库地支 | 流年走辰→辰库值年被打开 |
| 合开 | 六合对象出现引动 | 辰酉合金→辰中辛金被引出 |

**库闭不开的后果**：
- 库中的用神发挥不了作用=有才华施展不出
- 库中的忌神被锁住=反而平安无事
- 财入库=有钱但花不出（或积蓄型）

### 2.3 入墓的含义——被困

"入墓"是指某五行（或某六亲）进入对应的库地支，如同被关进"坟墓/仓库"。

| 五行 | 对应墓库 | 入墓含义 |
|------|---------|---------|
| 水 | 辰（水库） | 水被困于辰中 |
| 火 | 戌（火库） | 火被困于戌中 |
| 金 | 丑（金库） | 金被困于丑中 |
| 木 | 未（木库） | 木被困于未中 |
| 土 | 辰/戌/丑/未 | 土入自身之库 |

**六亲入墓的断法**：
- 财星入墓→钱财被困/妻子健康不佳/父亲运差
- 官星入墓→事业受阻/丈夫运差（女命）
- 印星入墓→学业受阻/母亲运差
- 食伤入墓→表达受限/子女运差
- 比劫入墓→自身困顿/兄弟不得力

### 2.4 四库为华盖之地

| 日支/年支 | 华盖所在 |
|-----------|----------|
| 申子辰 | 华盖在辰 |
| 寅午戌 | 华盖在戌 |
| 巳酉丑 | 华盖在丑 |
| 亥卯未 | 华盖在未 |

**华盖的含义**：
- 主孤独、清高、不合群
- 主宗教缘分（易接触佛道/灵修）
- 主艺术才华（文学/绘画/音乐）
- 主研究精神（学术/技术深耕）
- 华盖逢空亡：孤独加重，但艺术/宗教缘分更强

### 2.5 四库冲的特点

| 冲组 | 本质 | 与四正冲的差异 |
|------|------|---------------|
| 辰戌冲 | 两土相战 | 同为土，不是克而是"碰撞"，主开库/震动 |
| 丑未冲 | 两土相战 | 同为土，力量相当，主僵持/内耗 |

**四库冲 vs 四正冲的本质差异**：
1. 四正冲=异五行对克（水克火/金克木），有明确胜负。
2. 四库冲=同五行碰撞（土对土），不是"克"而是"震动"。
3. 四库冲的主要作用是"开库"——把库中所藏五行释放出来。
4. 四库冲引动的变化往往是财务相关（库=仓库=财库）。

### 2.6 丑戌未三刑（恃势之刑）

**组合**：丑刑戌、戌刑未、未刑丑（循环三刑）

**深层含义**：
- "恃势"=倚仗权势欺人
- 主因权力/地位/利益引发的冲突
- 主小人背后使绊、职场政治斗争
- 三库齐见被刑开→变动极大，储藏之物倾泻而出

**实际应验**：
- 财务大变动（库开=财来或财散）
- 职场权力斗争
- 身体土旺之疾（脾胃/肌肉/皮肤）
- 命局已有两库，大运流年凑齐第三个时应验最烈

### 2.7 四库日支的性格特征

| 日支 | 性格关键词 |
|------|-----------|
| 辰 | 包容力强、心思深沉、善于积蓄、有时优柔 |
| 戌 | 忠厚耿直、固执己见、有正义感、不善变通 |
| 丑 | 沉稳内敛、善于理财、谨慎保守、能守秘密 |
| 未 | 温和包容、有宗教缘、内心纠结、表面随和 |

**共同特征**：
- 沉稳、不轻易表态
- 有城府、能守秘密
- 善于积累（财富/知识/人脉）
- 变化较慢但持久
- 内心世界丰富但不轻易示人

## 三、四生地支（寅巳申亥）

### 3.1 基本属性

| 地支 | 五行 | 藏干（本/中/余） | 特殊地位 | 对应季节 |
|------|------|------------------|---------|----------|
| 寅 | 木 | 甲/丙/戊 | 木之长生处、火之起源 | 孟春（正月） |
| 巳 | 火 | 丙/庚/戊 | 火之帝旺处、金之长生 | 孟夏（四月） |
| 申 | 金 | 庚/壬/戊 | 金之帝旺处、水之长生 | 孟秋（七月） |
| 亥 | 水 | 壬/甲/（无余气） | 水之帝旺处、木之长生 | 孟冬（十月） |

> **核心特征**：四生地支每一个都包含两种以上五行，是"多元素交汇之地"。这种复杂性决定了四生地支的"变化性"。

### 3.2 四生为驿马之地

| 日支/年支 | 驿马所在 |
|-----------|----------|
| 申子辰 | 驿马在寅 |
| 寅午戌 | 驿马在申 |
| 巳酉丑 | 驿马在亥 |
| 亥卯未 | 驿马在巳 |

**驿马的含义**：
- 主变动、出行、迁移
- 主工作变动/职位调动
- 主搬家/出国/旅行
- 驿马逢冲=变动加速，说走就走
- 驿马逢合=变动受阻，想走走不了

**驿马落四生之理**：
- 四生地支=季节的"开端"（孟月），象征新的开始和变化
- 四生含多种五行=事物处于"混合态"，尚未定型，故主变

### 3.3 四生含多种五行——复杂性

| 地支 | 包含五行 | 复杂度解读 |
|------|---------|-----------|
| 寅 | 木（甲）+ 火（丙）+ 土（戊） | 三种五行交汇，木生火、火生土的连锁 |
| 巳 | 火（丙）+ 金（庚）+ 土（戊） | 火克金却同居，内在矛盾体 |
| 申 | 金（庚）+ 水（壬）+ 土（戊） | 金生水、土克水同在，力量交织 |
| 亥 | 水（壬）+ 木（甲） | 水生木，两者共生关系较和谐 |

**实战意义**：
- 四生地支因含多种五行，所以"一动牵全身"。
- 与四生地支发生刑冲合时，影响面广（不止一种五行被牵动）。
- 取用神时，四生地支的藏干哪个透出，就以哪个为主要力量。

### 3.4 寅巳申三刑（无恩之刑）

**组合**：寅刑巳、巳刑申、申刑寅（循环三刑）

**深层含义**：
- "无恩"=恩将仇报、背信弃义
- 主忘恩负义、过河拆桥之事
- 主合作破裂、信任崩塌
- 主因帮助他人反被陷害

**实际应验**：
- 合伙生意破裂（本来合作→反目）
- 职场中被自己提拔的人背叛
- 感情中付出多反被辜负
- 亲友间因利益反目
- 命局已有两字（如寅巳），大运流年见第三字（申）时应验

### 3.5 四生与十二长生宫的关系

| 天干 | 长生在 | 帝旺在 | 说明 |
|------|--------|--------|------|
| 甲木 | 亥 | 卯 | 木长生于亥（水生木之地） |
| 丙火 | 寅 | 午 | 火长生于寅（木生火之地） |
| 庚金 | 巳 | 酉 | 金长生于巳（火炼金之地） |
| 壬水 | 申 | 子 | 水长生于申（金生水之地） |

**规律总结**：
- 阳干长生必在四生地支（寅巳申亥）
- 四生地支=万物"起始"之地=长生/生发之处
- 这也是四生地支被称为"生"的原因——它们是五行从无到有的"出生地"

### 3.6 四生日支的性格特征

| 日支 | 性格关键词 |
|------|-----------|
| 寅 | 勇敢果断、有开拓精神、直率、领导力强 |
| 巳 | 聪明多变、善于谋略、有心机、文武双全 |
| 申 | 机智灵活、口才好、善交际、有时不安分 |
| 亥 | 智慧深沉、内心丰富、随性自在、有艺术感 |

**共同特征**：
- 活跃好动，不喜静止
- 善变，适应力强
- 有开拓精神和冒险意识
- 人生多变化、多迁移
- 交友广泛但关系不一定深

## 四、三类地支综合对比表

| 对比维度 | 四正（子午卯酉） | 四库（辰戌丑未） | 四生（寅巳申亥） |
|---------|----------------|----------------|----------------|
| 气的纯度 | 最纯（本气为主） | 中等（藏三干） | 较杂（藏二三干） |
| 五行属性 | 单一明确 | 表面属土 | 多元混合 |
| 对应神煞 | 桃花（咸池） | 华盖 | 驿马 |
| 冲的力度 | 最大（异行对克） | 特殊（同土碰撞） | 较大（含多行） |
| 性格基调 | 极端/纯粹/感性 | 沉稳/内敛/积蓄 | 活跃/善变/开拓 |
| 变化速度 | 快（一冲即变） | 慢（需开库才动） | 中（动中求变） |
| 代表三刑 | 无（四正不参与三刑） | 恃势之刑（丑戌未） | 无恩之刑（寅巳申） |
| 对应领域 | 感情/人缘/欲望 | 财务/积累/存储 | 变动/迁移/出行 |
| 季节位置 | 仲月（季中） | 季月（季末） | 孟月（季首） |
| 十二长生宫 | 帝旺之地 | 墓库之地 | 长生之地 |

## 五、实战应用

### 5.1 日支属于哪类→性格基调判断

**第一步**：确定日支属于哪一类

```
日支为子/午/卯/酉 → 四正人：情感丰富、性格极端、重感情
日支为辰/戌/丑/未 → 四库人：沉稳内敛、善于积累、有城府
日支为寅/巳/申/亥 → 四生人：活跃好动、善于变通、有闯劲
```

**第二步**：结合日干十神看深层性格

例如：
- 日干甲木坐子水（偏印）=四正人+偏印→聪慧灵活但多疑
- 日干丙火坐辰土（食神）=四库人+食神→内心丰富善于表达但不轻易示人
- 日干庚金坐寅木（偏财）=四生人+偏财→活跃且善于把握机会

### 5.2 大运流年走哪类地支→事件类型预判

| 走入地支类型 | 主要事件方向 | 辅助判断 |
|-------------|-------------|---------|
| 四正（子午卯酉） | 感情变动/人际关系/桃花事件 | 看是否冲到原局四正 |
| 四库（辰戌丑未） | 财务变动/积累或损失/入墓出墓 | 看是否冲开库门/用神是否入墓 |
| 四生（寅巳申亥） | 工作变动/搬家迁移/出行远行 | 看是否引动驿马/三刑 |

### 5.3 命局地支组合分析

**情况一：命局四个地支同属一类**

- 四正齐见（子午卯酉全）：情感极端丰富，一生感情波折极多。
- 四库齐见（辰戌丑未全）：极善积累，但库满必倾，一生财务大起大落。
- 四生齐见（寅巳申亥全）：一生动荡不安，走南闯北，不停变化。

**情况二：命局地支跨类组合**

- 日支四正+时支四生：感情丰富且追求变化→易有多段感情。
- 日支四库+月支四正：内心沉稳但外在感性→外柔内刚。
- 年支四生+日支四库：早年多变动，中年后逐渐安定。

**情况三：同类地支自冲**

- 子午同见于命局=心中水火交战→内心矛盾、决策困难。
- 辰戌同见于命局=两库对冲→财务反复或居住不安。
- 寅申同见于命局=驿马互冲→一生极多迁移变动。

### 5.4 综合案例思路

**分析步骤**：
1. 先将四柱地支分类（属于四正/四库/四生哪类）
2. 看三类各占多少比例→判断命局基调
3. 找出地支间的刑冲合害关系
4. 结合大运流年的地支类型→预判事件方向
5. 具体断事时再结合十神、用神、宫位细化

## 六、检查清单

在分析地支时，确认以下要点：

- [ ] 已正确识别每个地支属于四正/四库/四生哪一类
- [ ] 已考虑四正地支的"气纯"特性对力量的影响
- [ ] 已检查四库地支是否被冲开/透出/引动
- [ ] 已评估入墓情况（哪个五行/六亲入了哪个库）
- [ ] 已识别桃花（四正）、华盖（四库）、驿马（四生）所在
- [ ] 已判断三刑是否凑齐（寅巳申/丑戌未/子卯）
- [ ] 已考虑日支所属类别对性格的基础影响
- [ ] 已结合大运流年地支类型预判事件方向
- [ ] 四正冲已判断胜负（看令/看党/看透）
- [ ] 四库冲已考虑"开库"效应而非单纯论克
- [ ] 四生相关已考虑"多五行牵动"的连锁效应

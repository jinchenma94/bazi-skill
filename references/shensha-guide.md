# 神煞吉凶详解

## 常用吉神

### 天乙贵人 ⭐⭐⭐⭐⭐

**含义**：逢凶化吉、遇难成祥、贵人相助

**查法**：
- 甲、戊、庚 → 贵人在牛、羊
- 乙、己 → 贵人在鼠、猴
- 丙、丁 → 贵人在猪、鸡
- 壬、癸 → 贵人在兔、蛇
- 辛 → 贵人在虎、马

**应用**：
- ✅ 命中有天乙贵人 → 人生阻碍少、关键时刻有人帮
- ✅ 大运流年逢贵人 → 事业顺利、得贵人相助
- ✅ 配合官星 → 官运亨通、升迁快

### 文昌贵人 📚

**含义**：聪慧、文才出众、学业进步

**应用**：
- ✅ 学生有文昌 → 学业优秀、成绩好
- ✅ 工作人有文昌 → 文笔好、口才强
- ✅ 创意工作者有文昌 → 灵感丰富、作品出众

### 驿马 🐎

**含义**：动力、旅行、迁移、变动、机遇

**查法**：
- 申子辰 → 马在寅
- 寅午戌 → 马在申
- 巳酉丑 → 马在亥
- 亥卯未 → 马在巳

**应用**：
- ✅ 有驿马的人 → 容易出差、工作调动、事业发展
- ✅ 驿马配官星 → 出外得贵人相助
- ✅ 驿马配财星 → 远方得财

### 华盖 🎭

**含义**：艺术气质、学术倾向、孤独、高傲、聪慧

**应用**：
- ✅ 艺术工作者有华盖 → 艺术成就高
- ✅ 学者有华盖 → 学问深厚
- ✅ 但容易孤独、需要找志同道合的人

### 桃花（咸池） 🌸

**含义**：异性缘、魅力、才艺、艺术气质

**应用**：
- ✅ 女命桃花配正官 → 婚姻美满
- ✅ 男命桃花配正财 → 事业顺利、家庭和谐
- ⚠️ 桃花配偏官/七杀 → 容易有外遇风险

## 常用凶神

### 羊刃 ⚔️

**含义**：刚强、冲动、容易冲突、手术、意外伤害

**应用**：
- ⚠️ 命中有羊刃 → 脾气硬、容易与人冲突
- ⚠️ 需要控制冲动、凡事要谨慎
- ⚠️ 大运逢羊刃 → 特别小心，容易有意外

### 亡神 👻

**含义**：失去、损伤、诉讼纠纷、容易吃亏

**应用**：
- ⚠️ 命中有亡神 → 做生意容易吃亏、易丢东西
- ⚠️ 需要谨慎签合同、谨防诈骗
- ⚠️ 不宜借钱给他人

### 劫煞 ⚡

**含义**：灾难、被抢、被骗、意外损失

**应用**：
- ⚠️ 命中有劫煞 → 容易被诈骗或抢劫
- ⚠️ 需要提高警觉、谨防小人
- ⚠️ 大运或流年逢劫煞 → 特别谨慎

### 孤辰、寡宿 🕯️

**含义**：孤独、婚姻迟到或不顺、需要找合适伴侣

**应用**：
- ⚠️ 女命有寡宿 → 容易嫁晚、婚姻风险
- ⚠️ 男命有孤辰 → 容易单身、婚姻迟到
- ⚠️ 需要特别注意配偶宫的十神

## 神煞应用原则

| 原则 | 说明 |
|------|------|
| 吉神有克则力减 | 吉神被克，作用减弱 |
| 凶神有制则祸轻 | 凶神被制，危害减轻 |
| 不可单独论 | 神煞要配合格局、十神来看 |
| 看激活时间 | 大运流年涉及神煞才显现 |
| 位置很重要 | 天干显现力量最强 |

## 神煞力量等级

| 等级 | 位置 | 力量 | 说明 |
|------|------|------|------|
| 1级 | 天干显现 | ⭐⭐⭐⭐⭐ | 力量最强 |
| 2级 | 月支或日支 | ⭐⭐⭐⭐ | 力量较强 |
| 3级 | 年支或时支 | ⭐⭐⭐ | 力量一般 |
| 4级 | 大运流年 | ⭐⭐ | 只在特定时期 |

## 吉凶组合分析

### 最吉的组合

| 组合 | 含义 | 人生结果 |
|------|------|--------|
| 天乙 + 文昌 | 贵人相助学业 | 学业成就 |
| 天乙 + 驿马 | 出外得贵人 | 事业发展 |
| 文昌 + 食神 | 聪慧才华 | 文化成就 |
| 桃花 + 正官 | 异性缘佳 | 婚姻美满 |

### 最凶的组合

| 组合 | 含义 | 人生结果 |
|------|------|--------|
| 羊刃 + 劫煞 | 冲动易损失 | 需要谨慎 |
| 孤寡 + 桃花 | 婚姻风险大 | 容易离异 |
| 亡神 + 劫煞 | 多重纠纷 | 容易吃亏 |

## 总结

正确应用神煞的关键：

1. ✅ 在格局基础上分析 — 不能单独看神煞
2. ✅ 配合十神 — 看神煞与关键十神的关系
3. ✅ 看时间激活 — 大运流年何时激活神煞
4. ✅ 看制约关系 — 吉神是否被克、凶神是否有制
5. ✅ 综合判断 — 多方面因素综合分析

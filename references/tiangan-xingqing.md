# 十天干性情论

> 大师级断命的第一步不是"打分"，而是从**日主天干的本性**出发——每个天干都有独特的"性格原型"，由此推导出喜忌、用神方向、行为模式。本文件是《滴天髓》天道篇、《穷通宝典》调候论、《三命通会》天干赋的综合提炼。

---

## 一、总论

### 阴阳五组对照

| 阳干 | 阴干 | 五行 | 阳干象 | 阴干象 |
|------|------|------|--------|--------|
| 甲 | 乙 | 木 | 参天大树 | 花草藤蔓 |
| 丙 | 丁 | 火 | 太阳烈火 | 灯烛炉火 |
| 戊 | 己 | 土 | 高山城墙 | 田园湿泥 |
| 庚 | 辛 | 金 | 斧钺矿石 | 珠玉首饰 |
| 壬 | 癸 | 水 | 江河大海 | 雨露溪泉 |

### 阴阳特征差异

- **阳干**：刚健、外向、主动、直接、力量大但不细腻
- **阴干**：柔顺、内敛、被动、迂回、力量小但灵活

## 二、甲木（阳木）

### 性情原型
参天大树、栋梁之材。**正直刚毅、立志高远、不屈不挠**。

### 经典诗诀
> 甲木参天，脱胎要火。春不容金，秋不容土。
> 火炽乘龙，水宕骑虎。地润天和，植立千古。

### 类象
大树、柱梁、头部、胆、东方、青色、酸味、仁德

### 性格特征
- **优点**：正义感强、有担当、领导力、目标明确、不畏困难
- **缺点**：固执不变通、过于刚硬易折断、不善妥协、有时清高孤傲

### 喜忌总表

| 喜 | 原因 |
|----|------|
| 丙丁火 | 木火通明，才华得以发挥（"脱胎要火"） |
| 壬癸水 | 水润滋养，根基深厚（"地润"） |
| 庚金适度 | 斧凿雕琢成材（"玉不琢不成器"） |

| 忌 | 原因 |
|----|------|
| 金太重 | 秋金劈木，摧折栋梁（"春不容金"） |
| 土太厚 | 土重木折，扎根困难（"秋不容土"） |
| 火太烈 | 木焚为灰，才华燃尽 |

### 调候要点
- **春甲木**（寅卯月）：木旺不需帮，喜火泄秀+金修剪
- **夏甲木**（巳午月）：木火太烈，急需壬水解渴
- **秋甲木**（申酉月）：金旺克木，需水通关（金→水→木）
- **冬甲木**（亥子月）：水冷木寒，急需丙火暖局

### 与其他天干关系
- **甲见庚**：正七杀——庚金劈甲，需丁火制庚（"庚金劈甲引丁"）
- **甲见己**：正财+合——甲己合化土（条件：辰戌丑未月令）
- **甲见丙**：食神——木火通明，文章秀发
- **甲见壬**：偏印——壬水滋甲，学问深厚

## 三、乙木（阴木）

### 性情原型
花草藤蔓、柔弱之木。**温柔婉转、善于攀附、柔韧有余**。

### 经典诗诀
> 乙木虽柔，刲羊解牛。怀丁抱丙，跨凤乘猴。
> 虚湿之地，骑马亦忧。藤萝系甲，可春可秋。

### 类象
花草、藤蔓、颈项、肝、东方、绿色、风、柔韧之物

### 性格特征
- **优点**：温柔体贴、善于变通、人缘好、适应力强、有艺术天赋
- **缺点**：依赖心强、优柔寡断、容易随波逐流、缺乏独立性

### 喜忌总表

| 喜 | 原因 |
|----|------|
| 丙火（太阳） | 花草得阳光则美——"得阳则美" |
| 癸水（雨露） | 细雨滋润花卉——"雨露之恩" |
| 甲木（大树） | 藤萝系甲=有依靠——"可春可秋" |

| 忌 | 原因 |
|----|------|
| 庚金直克 | 刀斧砍花=无情之克 |
| 霜雪寒冬 | 花草凋零=无生气 |
| 土太燥 | 燥土无法生根 |

### 调候要点
- **春乙木**：得令旺，喜丙火照暖+癸水润泽
- **夏乙木**：火旺木焦，急需癸水（雨露，非壬水大河）
- **秋乙木**：金旺克木，但乙木柔韧"刲羊解牛"——乙庚合金反为吉
- **冬乙木**：寒水太重，需丙火暖局

### 独特之处
乙木遇庚金不以"被克"论——**乙庚合金**，乙木柔软缠绕庚金，反而是"合"的关系。所以乙木日主遇庚金七杀，比甲木遇庚金好处理得多。

## 四、丙火（阳火）

### 性情原型
太阳烈火、普照万物。**热情奔放、光明磊落、慷慨大方**。

### 经典诗诀
> 丙火猛烈，欺霜侮雪。能煆庚金，逢辛反怯。
> 土众成慈，水猖显节。虎马犬乡，甲来成灭。

### 类象
太阳、眼目、小肠、南方、红色、苦味、礼德、光明

### 性格特征
- **优点**：热情大方、胸怀宽广、乐观向上、有感染力、正义光明
- **缺点**：急躁冲动、爱出风头、做事虎头蛇尾、过于张扬

### 喜忌总表

| 喜 | 原因 |
|----|------|
| 壬水（湖海） | 太阳映照湖海=辉映成辉（"水辅阳光"） |
| 甲木适量 | 木生火=有来源 |
| 庚金（偏财） | 太阳熔金=富贵 |

| 忌 | 原因 |
|----|------|
| 壬水太旺 | 乌云蔽日=才华被压 |
| 土太多 | 火生土=泄气太过（"土众成慈"=变得迟钝） |
| 寅午戌火太烈 | 太阳不需要更多火——过旺反焦 |

### 调候要点
- **春丙火**：木旺火相，壬水为用（映照）
- **夏丙火**：火太烈，壬水为救
- **秋丙火**：金旺泄火，需甲木生扶
- **冬丙火**：水旺克火，需甲木通关

### 独特之处
丙火最大的特点是"不怕壬水"——太阳不怕大海，反而需要水来映射光辉。**丙壬对照=贵格**（"湖海映日"）。但丙火怕癸水——乌云小雨遮蔽阳光。

## 五、丁火（阴火）

### 性情原型
灯烛炉火、星星之火。**内敛文雅、细腻敏锐、温暖人心**。

### 经典诗诀
> 丁火柔中，内性昭融。抱乙而孝，合壬而忠。
> 旺而不烈，衰而不穷。如有嫡母，可秋可冬。

### 类象
灯烛、炉灶、心脏、眼睛（内视）、南方、紫色、文明、智慧

### 性格特征
- **优点**：细腻敏感、内心丰富、有文艺才华、忠诚孝顺、温暖体贴
- **缺点**：多疑善变、心思过重、容易钻牛角尖、缺乏魄力

### 喜忌总表

| 喜 | 原因 |
|----|------|
| 乙木（印星） | "抱乙而孝"——乙木是丁火的薪柴 |
| 甲木（偏印） | 甲木劈开引丁——大料生大火 |
| 庚金（正财） | 丁火炼庚——"丁火锻金成器" |

| 忌 | 原因 |
|----|------|
| 壬水合去 | 丁壬合木——丁火丧失本性 |
| 亥子水旺 | 小火被大水扑灭 |
| 无木助燃 | 灯烛无油则熄 |

### 调候要点
- 丁火一年四季都需要**甲木**——"甲木引丁"是丁火成格的第一要务
- 冬季丁火最忌壬水——壬水既克又合，双重打击

### 独特之处
丁火最重要的配置是"甲木引丁"——没有甲木的丁火如同无油之灯，再旺也是虚火。**庚金劈甲引丁**是经典三角组合（庚劈甲→甲生丁→丁炼庚）。

## 六、戊土（阳土）

### 性情原型
高山城墙、大地厚土。**厚重诚信、中正不偏、包容万物**。

### 经典诗诀
> 戊土固重，既中且正。静翕动辟，万物司命。
> 水润物生，火燥喜逢。若在艮坤，怕冲宜静。

### 类象
高山、城墙、堤坝、胃、皮肤、中央、黄色、甜味、信德

### 性格特征
- **优点**：忠厚可靠、稳重大度、有信用、包容力强、守承诺
- **缺点**：过于保守、迟钝笨拙、不善表达、固执不化、反应慢

### 喜忌总表

| 喜 | 原因 |
|----|------|
| 甲木（七杀） | 甲木疏土=大树扎根使山有生气 |
| 丙火适量 | 暖土生万物 |
| 癸水（正财） | 高山得雨润泽 |

| 忌 | 原因 |
|----|------|
| 木太重 | 树多山崩 |
| 水太旺 | 水大土荡 |
| 火太烈 | 土被焦烤成�ite无用 |

### 独特之处
戊土的"中正"体现在——它是五行的中枢调节器。戊土日主的命格往往"大器晚成"，年轻时平淡无奇，中年后厚积薄发。

## 七、己土（阴土）

### 性情原型
田园沃土、湿润泥地。**谦卑包容、善于培育、默默耕耘**。

### 经典诗诀
> 己土卑湿，中正蓄藏。不愁木盛，不畏水狂。
> 火少火晦，金多金光。若要物旺，宜助宜帮。

### 类象
田地、花圃、脾脏、肌肉、中央偏南、土黄、甘甜、养育

### 性格特征
- **优点**：谦逊踏实、善于照顾人、耐心细致、适应性强、知足常乐
- **缺点**：缺乏主见、容易被人利用、过于委曲求全、小气计较

### 喜忌总表

| 喜 | 原因 |
|----|------|
| 丙火（正印） | 暖土催生——田地需阳光 |
| 甲木（正官） | 甲己合土——"合"来的管理反为喜 |
| 癸水（偏财） | 雨润田园丰收 |

| 忌 | 原因 |
|----|------|
| 水太多 | 田地泛滥成泥塘 |
| 冬季无火 | 冻土不生——"火少火晦" |
| 金太多 | 泄气太过 |

### 独特之处
己土"不愁木盛"——与戊土不同，己土是田园，木（庄稼）在田中生长是正常的（官星得位）。甲己合化土更是己土最喜见的格局。

## 八、庚金（阳金）

### 性情原型
斧钺矿石、刚烈之金。**果决刚毅、义气为先、杀伐决断**。

### 经典诗诀
> 庚金带煞，刚健为最。得火而锻，得水而锐。
> 土润则生，土干则脆。能赢甲兄，输于乙妹。

### 类象
刀剑、矿石、大肠、骨骼、西方、白色、辛辣、义德

### 性格特征
- **优点**：果断干练、讲义气、敢作敢当、有魄力、执行力强
- **缺点**：冷酷无情、好斗好胜、心狠手辣、缺乏温情、鲁莽

### 喜忌总表

| 喜 | 原因 |
|----|------|
| 丁火（正官） | "得火而锻"——锻炼成器=有成就 |
| 壬水（食神） | "得水而锐"——磨砺锋芒=才华外露 |
| 甲木（偏财） | 庚劈甲=有用武之地 |

| 忌 | 原因 |
|----|------|
| 丙火太旺 | 太阳熔金=被毁灭 |
| 土太多 | "土干则脆"+土重金埋 |
| 无火无水 | 顽金无用——不锻不锐 |

### 独特之处
- "能赢甲兄"：庚克甲=大斧劈大树，力量对等可战胜
- "输于乙妹"：庚遇乙=乙庚合金，反被乙木柔情缠住
- 庚金必须有**丁火**——"庚金无丁不成器"是铁律

## 九、辛金（阴金）

### 性情原型
珠玉首饰、精巧之金。**清秀灵敏、追求完美、外柔内刚**。

### 经典诗诀
> 辛金软弱，温润而清。畏土之叠，乐水之盈。
> 能扶社稷，能救生灵。热则喜母，寒则喜丁。

### 类象
珠宝、针线、肺、牙齿、西方、银白、清洁、精致

### 性格特征
- **优点**：聪慧灵巧、审美力强、心思细密、善于表达、有品位
- **缺点**：过于敏感、爱面子、心胸较窄、容易受伤、挑剔

### 喜忌总表

| 喜 | 原因 |
|----|------|
| 壬水（伤官） | "乐水之盈"——水洗金清=才华横溢 |
| 己土适量 | 温润之土培养珠玉 |
| 丁火（七杀） | 寒冬时需丁火暖局 |

| 忌 | 原因 |
|----|------|
| 戊土太多 | "畏土之叠"——土重金埋，才华被掩 |
| 丙火太烈 | 烈日烤金融化 |
| 无水洗涤 | 珠玉蒙尘=才华不显 |

### 独特之处
辛金最重要的格局是"金水伤官"——辛金生壬水，壬水泄辛金之秀气，形成"伤官泄秀格"，主聪慧多才、文学艺术出众。但此格怕见官（伤官见官为祸百端）。

## 十、壬水（阳水）

### 性情原型
江河大海、滔滔洪水。**智慧深沉、足智多谋、奔放不羁**。

### 经典诗诀
> 壬水通河，能泄金气。刚中之德，周流不滞。
> 通根透癸，冲天奔地。化则有情，从则相济。

### 类象
大河、大海、膀胱、血液、北方、黑色、咸味、智德

### 性格特征
- **优点**：聪明智慧、口才出众、适应力极强、有大局观、奔放洒脱
- **缺点**：狡猾善变、不受约束、放纵任性、缺乏恒心、漂泊不定

### 喜忌总表

| 喜 | 原因 |
|----|------|
| 甲木（食神） | 水生木=智慧外化为成果 |
| 庚金（偏印） | 金生水=有源头活水 |
| 戊土适量 | 堤坝约束=有方向不泛滥 |

| 忌 | 原因 |
|----|------|
| 戊土太重 | 堤坝过高=被困死 |
| 火太旺无金 | 水被蒸干无补给 |
| 无木泄秀 | 一潭死水无出路 |

### 独特之处
壬水最怕"戊土七杀太旺而无制"——如同大河被堵死。但壬水也最需要戊土——完全无堤坝则泛滥成灾（无约束的壬水日主=放纵无成）。**关键是"制而不死"**。

## 十一、癸水（阴水）

### 性情原型
雨露溪泉、至阴之水。**聪慧内敛、细腻多情、潜移默化**。

### 经典诗诀
> 癸水至弱，达于天津。得龙而运，功化斯神。
> 不愁火土，不论庚辛。合戊见火，化象斯真。

### 类象
雨露、泉水、肾脏、耳朵、北方偏西、深蓝、潜藏、悟性

### 性格特征
- **优点**：悟性极高、直觉敏锐、善解人意、有灵性、默默奉献
- **缺点**：多愁善感、犹豫不决、内心脆弱、容易抑郁、过于被动

### 喜忌总表

| 喜 | 原因 |
|----|------|
| 丙火（正财） | "不愁火土"——癸水得丙火照暖=寒水变温泉 |
| 辛金（偏印） | 辛金生癸=雨从金凝（有来源） |
| 戊土（正官） | 戊癸合化火=化象高格 |

| 忌 | 原因 |
|----|------|
| 冬季无火 | 寒水冰封=一切停滞 |
| 土太多 | 细流被堵=抑郁 |
| 无根无源 | 癸水本弱，无金生则枯 |

### 独特之处
- "得龙而运"：辰为水库，癸水遇辰=入库得根，有了储备
- 癸水最独特的格局是"戊癸合化火"——癸水化为火象，性质完全转变。条件：生于巳午月且四柱火土旺
- 癸水日主的人往往直觉极强、适合玄学/艺术/心理学

## 十三、实战应用流程

排盘后断命的**第一步**：

1. 看日干是什么→确定"性情原型"
2. 看日干生于什么月令→确定"当前状态"（旺/相/休/囚/死）
3. 对照本文件的"喜忌"→初步判断用神方向

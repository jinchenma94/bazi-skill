# 空亡系统

## 概述

空亡又称"旬空"，是六十甲子排列中，每旬（10个干支）天干用尽而地支剩余两个的现象。空亡的地支在命局中力量大减，象征"落空"、"不实"，对六亲、财官等均有特殊影响。邵伟华《四柱预测学》对空亡有专门论述。

---

## 一、六甲旬空完整表

| 旬名 | 该旬范围 | 空亡地支 |
|------|---------|---------|
| 甲子旬 | 甲子 → 癸酉 | **戌、亥** 空亡 |
| 甲戌旬 | 甲戌 → 癸未 | **申、酉** 空亡 |
| 甲申旬 | 甲申 → 癸巳 | **午、未** 空亡 |
| 甲午旬 | 甲午 → 癸卯 | **辰、巳** 空亡 |
| 甲辰旬 | 甲辰 → 癸丑 | **寅、卯** 空亡 |
| 甲寅旬 | 甲寅 → 癸亥 | **子、丑** 空亡 |

> **口诀**：甲子旬中戌亥空，甲戌旬中申酉空，甲申旬中午未空，甲午旬中辰巳空，甲辰旬中寅卯空，甲寅旬中子丑空。

## 二、空亡查法步骤

1. **确定日柱干支**（日柱是命主本人，以日柱查旬空）。
2. **找到日柱所在旬**：从甲子、甲戌、甲申、甲午、甲辰、甲寅六旬中找出日柱所属旬。
3. **该旬的空亡地支即为命主的旬空**。
4. **在四柱中检查**：年、月、日、时四柱地支中，哪些地支落入空亡。

### 示例
- 日柱为**甲午**，属**甲午旬**（甲午 → 癸卯），旬空为**辰、巳**。
- 若四柱地支中有辰或巳，则该地支空亡，力量大减。

---

## 三、真空与假空的区分

### 真空（有效空亡）
满足以下条件之一，空亡为真：
1. **空亡地支无冲**：四柱或大运流年中，空亡地支无对冲地支，则空亡成立（真空）。
2. **空亡地支无合**：空亡地支未被其他地支合住拉出（填实），则空亡维持。

### 假空（空而不空）
满足以下条件之一，空亡力量减弱甚至消失：
1. **被冲则不空（冲实）**：与空亡地支相冲的地支出现在四柱或大运流年，则"冲实空亡"，空亡效力消除。
   - 例：日柱旬空辰巳，若大运/流年出现戌（冲辰）或亥（冲巳），则空亡被冲实。
2. **被合则不空（合实/填实）**：与空亡地支相合的地支出现，则"合实空亡"，空亡效力消除。
   - 例：旬空为子，若四柱有丑与子合，则子不空（合实）。
3. **逢旺则不空（旺不为空）**：空亡地支若在月令当旺，则旺气冲破空亡，效力减弱。

## 四、空亡对六亲的影响

| 六亲星 | 所在地支空亡 | 影响 |
|--------|------------|------|
| 父母（印星） | 印星地支落空 | 父母缘薄，或早年失去父母照顾，或父母体弱多病 |
| 兄弟姐妹（比劫） | 比劫地支落空 | 兄弟姐妹缘薄，或帮助有限，或有名无实 |
| 配偶（官星/财星） | 官财地支落空 | 婚姻缘分不稳，配偶缘薄，或婚后感情疏离 |
| 子女（食伤） | 食伤地支落空 | 子女缘薄，或子女不得力，或生育困难 |
| 财富（财星） | 财星地支落空 | 财富难以积累，钱财易散，或财来财去 |

> **特别注意**：日支（配偶宫）落空亡，主婚姻缘分薄弱，感情易生变故，是八字合婚中的重要参考。

## 五、空亡填实与出空的条件

### 填实（空亡失效）
- **被冲填实**：与空亡地支相冲的地支出现（大运、流年引入），则空亡"被冲实"，原来空亡的六亲或事项重新激活，可能有重大变动。
- **被合填实**：与空亡地支相合的地支出现，则"被合实"，空亡效力消除。
- **逢旺填实**：在空亡地支所代表的五行当旺之月/年，空亡力量减弱。

### 出空（主事之时）
- **大运地支与空亡地支相同**（即大运走到空亡地支）：称为"出空"，该大运期间原来空亡的事项开始显现，可能有重大转变（喜神出空则吉，忌神出空则凶）。
- **流年地支与空亡地支相同**：当年出空，该年有与空亡相关的事项发生。

## 六、空亡在大运流年中的作用

### 大运进入空亡地支
- 该大运10年，命主所处环境有"落空不实"之感，投资谨慎，感情婚姻需稳固。
- 若大运空亡地支为忌神：凶性减弱，实为好事（忌神落空）。
- 若大运空亡地支为喜神：喜神落空，吉力减弱，需注意机遇流失。

### 流年进入空亡地支
- 当年有与该空亡地支相关的六亲事项：缘分出现（填实）或变动（冲实）。
- 空亡逢冲最为激烈，常有离合悲欢之事。

### 空亡与神煞结合
- **驿马空亡**：出行计划多变动，行程不顺或取消。
- **文昌空亡**：学业考试不顺利，成绩不如预期。
- **桃花空亡**：感情缘分虚花，感情不实，易逢有缘无份之人。

## 七、实例分析

### 示例
**日柱**：甲午（属甲午旬，旬空辰巳）

**四柱**：戊辰年 / 丁巳月 / 甲午日 / 丙申时

- 年支**辰**落空亡，月支**巳**落空亡。
- 年支辰代表祖辈与早年，辰落空：祖业薄，早年家庭基础不稳。
- 月支巳代表父母与早年社会环境，巳落空：父母缘薄，或早年事业起步困难。
- 日支午（配偶宫）不落空，婚姻有实质基础。
- 时支申不落空，晚年子女有实力。

**大运**：若走到辰运（出空年支辰），辰被大运引动，原来空亡的祖业/早年事项重新激活，可能有与家庭财产相关的重大变动。

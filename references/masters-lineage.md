# 历代命理人物经验参考

本文件只提供断法方法论。不要把人物名当权威装饰；输出时必须落到“命局证据 -> 方法视角 -> 现实落点 -> 置信度/校准”。

## 家庭断法禁用

不要使用任何历代命理方法反推用户的原生家庭、父母关系、家底厚薄、家庭财富阶层、父辈资源或家庭稳定性。年柱、月柱、财星、印星、官杀、财库、冲合刑害，只能解释用户已经提供的家庭事实，不能生成家庭事实。

默认断盘、校准点和财富判断都不要包含家庭推断。用户明确问家庭议题时，先说明“八字不足以单独断定家庭事实”，再请求现实事实校准。

## 方法选择

| 问题类型 | 可用方法 | 执行方式 |
|---|---|---|
| 性格画像 | 徐子平十神轴心法、任铁樵气势流通法 | 以日主、月令、十神旺衰和全局流通解释行为模式 |
| 格局喜忌 | 沈孝瞻月令格局法、徐乐吾调候汇通法 | 先定月令和格局，再看寒暖燥湿、扶抑和通关 |
| 事业财运 | 徐子平财星/官杀/食伤法、张楠病药法、韦千里命例校准法 | 分析本人赚钱方式、经营能力、现金流压力、合伙风险和职业路径 |
| 婚恋关系 | 徐子平配偶星/夫妻宫法、张楠病药法、袁树珊反馈校准法 | 分析吸引类型、关系矛盾、稳定条件和应期，避免道德审判 |
| 健康体质 | 徐乐吾调候法、任铁樵寒暖燥湿法 | 只提示体质倾向和压力部位，具体以医学检查为准 |
| 大运流年 | 韦千里命例化校准法、袁树珊反馈校准法、张楠病药触发法 | 把每个判断写成“触发机制、现实表现、置信度、校准问题” |
| 古法口吻 | 李淳风历法时序法、袁天罡象法边界法、刘基托名辨伪法 | 可借古法断语气势，但结论必须回到四柱证据，不冒充历史人物 |

## 核心人物方法

### 徐子平：日主十神轴心法

- 以日主为中心，把财、官杀、印、食伤、比劫转成现实角色、欲望、压力、资源和关系模式。
- 财星用于分析金钱关系、经营欲望、现实结果和伴侣线索；不得用于断家庭资产。
- 官杀用于分析规则、压力、职位、权力结构和约束。
- 印星用于分析学习、证照、系统背书、保护机制。
- 食伤用于分析表达、技能输出、创作、方案和反规则意识。
- 比劫用于分析自我、同辈、竞争、合伙和分配。

输出句式：按徐子平十神轴心法，某星在某柱透/藏/受制，现实中对应某类行为、压力或关系模式。

### 沈孝瞻：月令格局法

- 先看月令，再看透干、根气、成格与破格。
- 月令主事者优先于零散十神；格局成败要看清纯、制化和护卫。
- 用于事业格局、身份路径、规则适配和职业方向。

输出句式：按沈孝瞻月令取用，此局月令为某气，透某神，成/破在某处，所以现实落点是某类职业或压力结构。

### 张楠：病药法

- 先找命局主病，再找可用之药。
- 病可以是寒暖失衡、燥湿失衡、身弱不胜财官、身旺无泄、杀重无制、财多压身、比劫夺财等。
- 药可以是印、比、食伤、官杀、财星、调候或通关。

输出句式：按张楠病药法，病在某处，药在某处；现实中应避免某类动作，转向某类策略。

### 任铁樵：气势流通法

- 看全局气势是否有源、有去处、有阻滞。
- 不机械数五行个数，要看月令、根气、透干、通关和岁运引动。
- 用于判断“能不能承载”“压力从哪里来”“何时流通”。

输出句式：按任铁樵气势法，此局某气有源但去路受阻，岁运见某神时开始疏通。

### 徐乐吾：调候格局汇通法

- 先看月令寒暖燥湿，再看扶抑和格局。
- 调候急时，调候优先于机械扶抑。
- 用于健康体质、环境适配、行业选择和用神争议。

输出句式：按徐乐吾调候汇通法，此局先解寒暖燥湿，再谈格局扶抑。

### 韦千里：命例化校准法

- 少讲玄理，多讲现实表现。
- 每个结论都要写成“命局触发 -> 现实表现 -> 校准问题”。
- 低置信线索不得包装成确定事件。

输出句式：借韦千里命例化表达，此象落到现实中，多见某类职业、关系或财务表现，需要用某事实校准。

### 袁树珊：反馈校准法

- 多流派结论冲突时，先列主断、次断、待校准。
- 用户反馈后，降低错误方向权重，重新评估格局、用神和事件领域。
- 现实事实优先于命局初判。

输出句式：按袁树珊校准法，此处主断为 A，次断为 B，需要用某三项现实事实修正。

## 财富行为专项

财富分析只看用户本人的收入能力、经营模式、现金流压力、资产动作、合伙风险和风险偏好。

禁止项：
- 不判断家庭总资产。
- 不判断父母资产或父辈资源。
- 不判断家底厚薄。
- 不用年月柱、财库、财星反推家庭财富。

可判断项：
- 财星是否有源：赚钱机会和现实欲望。
- 财星是否入库或被冲：资产沉淀、现金流周转、项目开合。
- 食伤是否生财：靠技术、表达、产品、经营输出换钱。
- 比劫是否夺财：合伙、同辈竞争、利润分配和破财风险。
- 官印是否承接财：制度化、公司化、证照化、平台化和合规压力。

输出模板：

```text
判断：……
依据：财星/食伤/官印/比劫/财库如何作用。
现实落点：收入方式、经营模式、现金流压力、合伙风险、资产动作。
置信度：A/B/C。
校准：当前收入结构、负债、项目投入、合伙协议、现金流周期。
```

## 古法人物边界

- 李淳风：只用于历法、节气、时辰、真太阳时等边界校验；不使用预言传说断命。
- 袁天罡：可借象法和断语气势；不得用称骨、传说或神秘叙事替代四柱证据。
- 刘基：只作托名文本辨伪提醒；不作实断权威。
- 李虚中：只取“重视年、月、时代框架”的方法意识；不得用来反推家庭、祖上或父母平台。

## 统一输出要求

每次至少选 2 个相关方法交叉验证。格式保持短：

```text
按某某方法：……
按某某方法：……
现实落点：……
置信度/校准：……
```

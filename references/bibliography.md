# 八字命理参考书目总索引

## 使用说明

本索引按**历史时期 + 流派**整理所有本 Skill 引用的典籍、专著。每条条目包含：作者 + 朝代/年份 + 核心主题 + **本 Skill 相关文件**。

---

## 一、先秦至汉唐（命理萌芽期）

### 《易经》（周易）
- **作者**：相传伏羲画卦、周文王演卦、周公系辞、孔子作传
- **年代**：约公元前 11 世纪至春秋战国定型
- **主题**：阴阳、八卦、六十四卦——**中国术数的总源头**
- **关联**：`yijing-foundation.md`

### 《尚书·洪范》
- **年代**：先秦
- **主题**：五行学说的最早文献（"五行：一曰水、二曰火、三曰木、四曰金、五曰土"）
- **关联**：`yijing-foundation.md`, `wuxing-tables.md`

### 《礼记·月令》
- **年代**：秦汉整理
- **主题**：节气与五行对应，季节行事的规则
- **关联**：调候理论的最早雏形

### 《淮南子·天文训》
- **作者**：西汉淮南王刘安
- **年代**：公元前 139 年前后
- **主题**：干支、阴阳、五行、十二月建的系统整理
- **关联**：基础命理概念的汉代定型

---

## 二、唐代（命理学正式形成）

### 《李虚中命书》
- **作者**：相传为唐代李虚中（作者真伪存疑）
- **年代**：唐代
- **主题**：以**年柱纳音**为核心的早期命理法（"李虚中法"）
- **关联**：`nayin-wuxing.md`。子平法出现后，此法被取代，但纳音仍在合婚、神煞等场合使用

### 《开元占经》
- **作者**：瞿昙悉达
- **年代**：唐代开元年间（8 世纪）
- **主题**：天文占星总集，含部分命理方法

---

## 三、宋代（子平法诞生）

### 《珞琭子三命消息赋》
- **作者**：相传宋初珞琭子（真名不详）
- **年代**：北宋
- **主题**：子平法出现前后的过渡文献，论命之赋
- **关联**：早期命理范本

### 《玉照定真经》
- **作者**：相传西汉郭璞（多为后人托名）
- **年代**：宋代流传本
- **主题**：早期格局论

### 《徐子平——渊海子平》
- **作者**：宋代徐子平（真名徐升，一说徐大升）
- **年代**：北宋中后期
- **主题**：**开创以日干为主论命的子平法**——当今八字命理的奠基
- **关联**：整个 `SKILL.md` 的核心方法论

### 《渊海子平》
- **作者**：宋代徐大升（或宋代南宋编订）
- **年代**：南宋/元初
- **主题**：徐子平命理法的系统整理，十神、格局、用神的雏形
- **关联**：`zipin-zhenquan-sishen.md`, `shishen-analysis.md`

### 《梅花易数》
- **作者**：宋代邵雍（康节先生）
- **年代**：北宋
- **主题**：卜卦学——虽非命理，但与命理同源
- **关联**：`yijing-foundation.md`（六爻卜卦辅助）

## 四、明代（命理学集大成）

### 《滴天髓》
- **作者**：相传明代刘基（刘伯温、诚意伯，1311-1375）
- **年代**：明初
- **主题**：**气势流通派**的代表作。讲"中和"、"通根"、"从化"、"清纯"
- **关联**：
  - 本 Skill 多处引用其"中和"、"从化"观念
  - 清代任铁樵为之注疏，使之广为流传

### 《滴天髓阐微》（任铁樵注）
- **作者**：清代任铁樵
- **年代**：清代道光年间（19 世纪初）
- **主题**：《滴天髓》最权威的注本，将原本玄奥的条文结合大量实例解析
- **关联**：`zipin-zhenquan-sishen.md`（格局成败论的源头之一）

### 《三命通会》
- **作者**：明代万民英（1521-1603）
- **年代**：明代嘉靖年间
- **主题**：命理学的**百科全书**。汇集唐宋元明各家学说，包括纳音法、子平法、神煞、格局等
- **关联**：
  - `shensha-complete-system.md`（大量神煞查法源于此书）
  - `nvming-zhuanlun.md`（女命论法）
  - `hehun.md`（男女合婚总论）

### 《神峰通考》（神峰张先生命理正宗）
- **作者**：明代张楠（字神峰）
- **年代**：明代万历年间
- **主题**：**病药说**的开创作。与《子平真诠》《滴天髓》并列为四大经典
- **关联**：`shenfeng-bingyao.md`

### 《兰台妙选》
- **作者**：明代张楠整理
- **年代**：明代
- **主题**：专论**贵格特征**。女命部分最有名
- **关联**：`nvming-zhuanlun.md`

### 《命理探原》
- **作者**：明代袁树珊前身作
- **年代**：明代
- **主题**：论命的经验总结

### 《星平会海》
- **作者**：明代水中龙（真名不详）
- **年代**：明代
- **主题**：将**紫微斗数**与**子平八字**结合分析

## 五、清代（命理学成熟与系统化）

### 《子平真诠》
- **作者**：沈孝瞻

## 十三、对伪托书目的说明

### 民间常见的"托名"著作

中国命理史上有大量**托名古人**的著作，需要理性识别：

| 托名 | 真实来源 | 处理方式 |
|------|---------|--------|
| "袁天罡称骨歌" | 民间后作，非袁天罡 | 参考即可，不必迷信 |
| "诸葛孔明马前课" | 后人托名 | 不可作命理严肃参考 |
| "邵康节皇极经世" | 邵雍真作但与命理无关 | 哲学参考 |
| "李淳风推背图" | 后人增改 | 预言类、非命理 |
| 各种"祖传秘本" | 大多数是现代伪造 | 警惕 |

**核心原则**：优先参考**有明确作者、有版本流传、有学术考证**的著作。对"祖传秘本"保持审慎。

### 现代批判性反思

本 Skill 在引用传统典籍时，明确区分：
- **可保留**：合理的理论框架（阴阳五行、格局用神等）
- **需改造**：带时代局限的观念（如女命的"三从四德"色彩）
- **应摒弃**：神秘化、商业化、焦虑化的伪术

> **"读万卷书，行万里路，阅人无数。"**

命理学是中国传统文化的重要遗产，但也鱼龙混杂。希望本索引帮助使用者：

1. **追本溯源**：知道哪本书是源头，哪本书是衍生
2. **辨别真伪**：识别伪托与真作
3. **全面学习**：不偏执一派、广纳众家
4. **理性态度**：既尊重传统，也批判反思

本 Skill 的所有 reference 文件都建立在以上典籍的基础上，目标是**做一个既有传统深度、又有现代学术标准的命理工具**。

# 疾病预测（命理与健康）

> 传统命理中，五行对应五脏六腑、十二经络。通过八字中五行的旺衰偏枯，可以推断命主一生中容易出现的健康问题及发病时间。本文件综合邵伟华《四柱预测学》、倪海厦中医命理体系、及传统命理经验。
>
> ⚠️ **伦理声明**：命理健康分析仅供参考，**绝不替代医学诊断**。发现健康隐患应建议命主就医检查，不可直接下"断语式"结论。

## 三、五行过旺对应疾病

### 木过旺（肝胆系统）

| 表现 | 可能疾病 |
|------|---------|
| 肝气郁结 | 抑郁、易怒、胁肋胀痛 |
| 肝阳上亢 | 高血压、头晕头痛、中风 |
| 肝风内动 | 抽搐、痉挛、帕金森 |

| 筋骨问题 | 腱鞘炎、肌肉痉挛、关节痛 |

**典型命局**：四柱木多无金制→肝气横逆→脾胃受克→消化问题

### 火过旺（心血管系统）

| 表现 | 可能疾病 |
|------|---------|
| 心火亢盛 | 失眠、心悸、心律不齐 |
| 血热妄行 | 皮肤病、出血倾向 |
| 火灼肺金 | 干咳、咽炎、支气管炎 |
| 小肠火旺 | 口腔溃疡、尿赤 |
| 眼目问题 | 近视、干眼、视网膜病变 |

**典型命局**：四柱火多无水制→心火上炎→灼肺金→呼吸+心血管双重风险

### 土过旺（脾胃系统）

| 表现 | 可能疾病 |
|------|---------|

### 金过旺（肺与大肠系统）

**典型命局**：四柱金多无火制→肺气过收→肝木被克→筋骨不利

## 五、断病的基本方法

### 第一步：找"病源"（哪个五行有问题）

1. **过旺无制** = 该五行对应脏腑过亢
2. **过弱无生** = 该五行对应脏腑虚弱
3. **被克太过** = 克方伤害了被克方的脏腑
4. **相冲之位** = 冲到哪个地支，该地支对应的身体部位有问题

### 第二步：定"病位"（在身体哪里）

- 看**四柱宫位**：年柱=头面、月柱=胸背、日柱=腰腹、时柱=腿足
- 看**地支经络**：具体地支对应的经络区域
- 看**天干脏腑**：具体天干对应的脏器

### 第三步：定"病时"（何时发病）

- 大运走到该五行**死墓绝**之地 = 该脏腑最虚弱期
- 流年冲克该五行所在地支 = 该年该脏腑有恙
- 岁运引动命局中的**克战组合** = 触发疾病

## 八、实战断病流程

### 标准五步

1. **看日干**→确定先天体质类型
2. **看五行偏枯**→找最弱/最旺的五行→对应脏腑
3. **看宫位**→确定具体身体区域
4. **看大运**→找该五行最虚弱的时段
5. **看流年**→精确到年（配合 `yingqi-duanshi.md` 的应期法）

### 实战案例

**命局**：日干甲木，四柱火土旺，金水全无

- 第一步：甲木日主→先天肝胆敏感
- 第二步：金水全无→肺肾极弱
- 第三步：火旺泄木→肝血不足（木被泄）；金无→肺无制约力
- 第四步：走金水大运时→表面补了不足，但气场剧变→可能触发问题
- 结论：**呼吸系统（金/肺）和泌尿系统（水/肾）**为一生弱点。走火土旺运时肺更被克，该时段注意呼吸道。

## 九、健康建议的给出方式

### 可以说的（建议性）
- "您的八字中金气偏弱，建议平时多注意呼吸系统保养"
- "2028 年大运走到木旺之地，建议定期做肝功能检查"
- "您的脾胃五行在命局中受克，饮食上宜清淡温补"

### 不可以说的（禁止）
- ❌ "你 2028 年会得肝癌"
- ❌ "你命里注定有这个病"
- ❌ "不改名/不戴什么就会生大病"
- ❌ 任何替代医学诊断的绝对论断

# 用神确定完全指南

## 概述

**用神是命理分析的核心，没有用神就无法分析**。用神不对，后续分析全错。这份指南教你系统地确定用神。

**核心概念**：用神 = 命局中最需要的那个十神/五行，用来维持命局平衡。

> **本指南关联文件**：
> - `tiaohou-yongshen.md` — 120 条调候用神完整表（《穷通宝典》）
> - `zipin-zhenquan-sishen.md` — 四神体系（用神·相神·喜神·忌神）
> - `shenfeng-bingyao.md` — 病药说
> - `bazi-strength-rating.md` — 日主旺衰详评

## 一、用神确定的四层递进法

### 层级1：扶抑法（60%的命用这个）

这是最基础、最常用的用神确定方法。

#### 步骤1：判断日主旺衰

**判断标准**：

| 判断项 | 得分 | 说明 |
|--------|------|------|
| **得令** | +3 | 月支为日干长生、帝旺之地 |
| **不得令** | -2 | 月支为日干衰、死、绝之地 |
| **得地** | +1 | 其他地支有日干的根 |
| **得势** | +2 | 天干有比劫帮身 |
| **得生** | +1 | 有印星生身 |
| **被克** | -2 | 有官杀克身 |
| **克制** | -1 | 有财星克身 |

**计算方式**：

把每一项分数累加。例如日干得令（+3）、无其他助力（+0）、被月干官星所克（-2）→ 最终 +1 分。

**评级**：
- **+5分以上** = 🟢 身很旺
- **+1到+4分** = 🟡 身适中偏旺
- **-1到0分** = 🟡 身适中偏弱
- **-2到-4分** = 🟠 身比较弱
- **-5分以下** = 🔴 身很弱

#### 步骤2：根据旺衰选择用神

**规则：扶抑原则**

> 太过者损其有余（克泄），不及者补其不足（生扶）。

**详细对照表**：

| 身旺程度 | 首选用神 | 次选用神 | 禁忌神 |
|---------|---------|---------|-------|
| 🟢 很旺 | 官杀克制 | 财星泄秀 | 印星生扶 |
| 🟡 偏旺 | 财星、官杀 | 食伤泄秀 | 比劫帮身 |
| 🟡 偏弱 | 印星、比劫 | 根气 | 财星、官杀 |
| 🔴 很弱 | 印星或比劫 | 强有力帮身 | 一切克制 |

#### 实例1：身旺用官杀

**八字**：甲寅 丙寅 甲寅 甲子

- 日干甲木，生寅月得令（+3），三个寅又帮身（+3）→ **身很旺**
- 年月时三甲相连，木气壅塞
- 时支子水虽能生木但已太多
- **用神**：需要金（官杀）来克木开泄，或火（食伤）来流通木气
- **首选用神**：庚金七杀（需要行金运才能出现）

#### 实例2：身弱用印星

**八字**：辛卯 辛卯 甲午 戊辰

- 日干甲木，生卯月得令本为+3，但年月两辛金克甲（-4），日支午火泄气（-2），时柱戊辰财克印之根
- **身偏弱**（约 -3 分）
- **用神**：需要水（印星）来化杀生身，或见比劫帮身
- **首选用神**：癸水/壬水正印

### 层级2：调候法（20%的命需要这个）

当命局中有特殊的寒暖燥湿问题时，调候用神比扶抑用神更重要。

#### 调候的四种类型

| 调候类型 | 问题 | 解决方法 | 需要的用神 |
|---------|------|--------|----------|
| **寒** | 冬生，水气太盛，阴冷 | 加火暖之 | 丙火或丁火 |
| **暖** | 夏生，火气太盛，炎热 | 加水凉之 | 癸水 |
| **燥** | 秋生，金气干燥，肺伤 | 加水润之 | 癸水或壬水 |
| **湿** | 春生，木气舒展，需土制 | 加土制之 | 戊土或己土 |

#### 调候规则

**规则1：调候优先于扶抑**

《穷通宝典》的核心原则：**调候用神有，则命成；调候用神无，则命损**。即使日主中和、格局清纯，若气候严重失衡，人生仍多阻滞。

- 夏生无水 → 必有皮肤病、眼疾、心火旺
- 冬生无火 → 必有脾胃寒、手足冻、气血不畅

**规则2：调候用神的力量判断**

三样条件：
1. **调候用神透干**（最强）
2. **调候用神有根**（中等）
3. **调候用神只藏不透**（最弱）

- 三样都有 = **强力调候**
- 只有一样 = **弱调候**
- 都没有 = **无调候**（需行运补救）

#### 各月的调候规则（概要）

**冬月调候（亥子丑月）**

- 首选：丙火（解冻）
- 原理：水冻金寒土湿木僵，非丙火不能暖局
- 若命无丙火，必待丙火大运或流年补救

**春月调候（寅卯辰月）**

- 寅月：丙癸并用（甲木需暖需润）
- 卯月：调候要求稍弱，视日干而定
- 辰月：土旺，视日干而定；若木日干生辰月，需甲、庚疏土

**夏月调候（巳午未月）**

- 首选：壬水/癸水（降温润燥）
- 原理：火气过炎，万物焦枯
- 若命无水，必多病、性躁

**秋月调候（申酉戌月）**

- 申月：金旺生水，若日干是水则金水两旺
- 酉月：金极旺，视日干而定
- 戌月：土燥，需水润

> **详细调候用神清单请查阅 `tiaohou-yongshen.md` 的 120 条完整表**

#### 调候实例

**例子：甲木生于正月（寅月）**

- 寅月初春，阳气初生但余寒犹在
- 甲木虽得令，但需火暖才能生发
- **调候用神**：丙火（暖局）、癸水（润根）
- 若命中丙癸两透且无冲克 → 富贵命
- 若仅见丙无癸 → 火炎木焚，命主性急
- 若仅见癸无丙 → 寒木无阳，命主抑郁

### 层级3：通关法（15%的命需要这个）

当命局中两种五行严重对立，互相克制时，需要用第三种五行来"通关"（化解冲突）。

#### 通关原理

> **两气相争，必求通关；通关得位，两美相融。**

例：金克木，若命局金木两旺势均力敌 → 必有战伤，需用**水**来"金→水→木"通关。

#### 通关的三种类型

| 类型 | 冲突 | 通关方式 | 举例 |
|------|------|--------|------|
| **克链式** | A克B | 用B生的五行（食伤） | 木克土→用火来通 |
| **生链式** | A生B但过度 | 用B克的五行（官杀） | 木生火太过→用水来通 |
| **冲合式** | A与B相冲 | 用合化之物来和解 | 子午冲→用金来合解 |

#### 通关用神的判断

**判断标准**：

1. 首先判断**是否真的是两气对立**（不是"三气混杂"）
2. 再判断对立双方**势均力敌**（相差悬殊时不叫"对立"，直接压制）
3. 最后找到能**承上启下**的第三五行

**例子：木土战克**

**八字**：甲寅 甲戌 甲辰 甲戌

- 四个甲、三个土（戌戌辰）
- 木土相争，势均力敌
- **通关用神**：火（丙、丁、巳、午）—— 木生火、火生土，化干戈为玉帛
- 若命中无火，仅此一运来火即大发

#### 通关的力量判断

- 如果通关用神**被克制**，无效
- 如果通关用神**很弱**，作用弱
- 如果通关用神**强有力**，通关成功

### 层级4：顺势法（5%的命用这个）

对于从格命局，用神的选择与普通格完全相反。

#### 从格的用神规则

**核心**：从格中，那个强有力的十神就是用神。

#### 从格用神的判断

**步骤**：
1. 判断是否是从格（见 `special-formats.md`）
2. 确定从的是什么十神
3. 那个十神就是用神
4. 忌神是生扶日主的（印星或比劫）

#### 例子：从杀格的用神

**八字**（示例）：乙未 甲申 戊寅 甲寅

- 日干戊土生申月，金泄土气
- 年月时三甲一乙，木旺克土
- 戊土无根无援 → **从杀格**
- 用神：甲木（七杀）
- 忌神：戊、己、丙、丁（回头帮身）

## 二、用神的进阶判断

### 用神的强弱评分

即使确定了用神，还需要判断用神的力量强弱。

#### 用神力量评分表

| 因素 | 满分 | 占比 |
|------|------|------|
| **是否在天干透出** | 20分 | 最重要 |
| **月令是否得位** | 20分 | 很重要 |
| **是否有根气** | 20分 | 很重要 |
| **是否有生扶** | 15分 | 重要 |
| **是否受克制** | -25分 | 最坏情况 |

**评级**：
- **80分以上** = 🟢 用神很有力，命好
- **60-79分** = 🟡 用神有力，命中等
- **40-59分** = 🟠 用神一般，命平平
- **20-39分** = 🔴 用神无力，命差
- **0-19分** = 🔴🔴 用神很弱，命很差

#### 例子：丙火用神的评分

**八字**：癸亥 甲寅 丙申 戊子

- 日干丙火，生寅月得令（木生火）
- 用神为丙火本身（因身弱）

**评分**：
- 丙火透在日干（+20 天干透出）
- 月支寅中藏丙（+15 有根但非本气）
- 月干甲木生丙（+15 有生扶）
- 日支申金克月支寅根（-15）
- 年支亥、时支子水夹克丙（-15）
- **合计约 20 分**

**结论**：丙火用神虽然自身透出，但根气不稳、周围水多克火，**用神虽在而力弱**，命主一生辛苦，需靠行运补救。

## 三、用神与相神

### 什么是相神？

相神 = 辅助用神的十神，与用神相生相合。

> 用神是格局的主角，相神是让格局"真正落地"的配角。详见 `zipin-zhenquan-sishen.md`。

#### 相神的作用

1. **修补用神的缺陷**：用神无根，相神生之
2. **化解忌神**：忌神克用神，相神通关
3. **使格局成立**：好格局 = 用神有力 + 相神到位

#### 常见的用神-相神组合

| 用神 | 最佳相神 | 关系 | 吉凶 |
|------|---------|------|------|
| 正官 | 正印 | 官印相生 | 🟢 大吉，官印双清 |
| 正财 | 正官 | 财官相生 | 🟢 大吉，财官双美 |
| 食神 | 正财 | 食生财 | 🟢 大吉，食禄丰厚 |
| 正印 | 正官 | 印生官 | 🟢 大吉，贵气十足 |
| 七杀 | 正印 | 印化杀 | 🟢 大吉，杀印相生 |
| 七杀 | 食神 | 食制杀 | 🟢 大吉，食神制杀 |
| 伤官 | 正印 | 印制伤 | 🟢 大吉，伤官佩印 |
| 伤官 | 正财 | 伤官生财 | 🟢 大吉，伤官生财 |

#### 相神的力量判断

- 相神**透干且有根** → 格局最稳
- 相神**仅透干无根** → 相神飘浮，格局偏弱
- 相神**藏而不透** → 相神潜伏，需要岁运引动
- 相神**被克破** → 格局失用，命运起伏大

## 四、忌神与制化

### 什么是忌神？

忌神 = 命局中克破用神的十神/五行。

#### 忌神的判断

**规则**：

1. **直接克用神者** = 忌神（如用神正官，则伤官为忌）
2. **合化掉用神者** = 忌神（如用神正印，大运合化印星为其他五行）
3. **使命局五行失衡者** = 忌神（如五行水太多泛滥）

#### 忌神是否需要制化

| 情况 | 处理 |
|------|------|
| **忌神在天干透出且强有力** | 🔴 必须制化，否则破格 |
| **忌神在地支但无力** | 🟡 最好有制化，但不强制 |
| **忌神完全没有** | 🟢 最好，格局最清纯 |
| **忌神有制化** | 🟢 很好，格局稳定 |

#### 制化的方式

1. **克制法**：用克忌神的五行来直接制伏
   - 例：伤官为忌（克正官）→ 用正印克伤官
2. **合化法**：用合住忌神的五行
   - 例：乙木为忌 → 庚金合乙化金，忌神转化为用神
3. **通关法**：用流通忌神之气的第三方
   - 例：比劫夺财为忌 → 用食伤泄比劫生财，比劫不再夺财

## 五、用神的优先级排序

当命局中有多个可能的用神时，如何选择？

### 优先级规则

```
1. 调候用神优先（《穷通宝典》原则）
   ↓
2. 格局用神次之（《子平真诠》原则）
   ↓
3. 扶抑用神再次（最常用但非最优先）
   ↓
4. 通关用神最后（仅在两气对立时使用）
```

**特例**：
- 从格、化气格、专旺格 → 用"顺势法"，不按以上顺序
- 病药说认为的"有病取药" → 病即忌神、药即用神

### 实际案例

**例子：需要多个用神的命局**

**八字**：庚午 戊寅 戊午 丙辰

- 日干戊土生寅月，本应身弱（木克土）
- 但得年月时三火（午、寅藏丙、丙）帮身
- **综合**：身中和偏旺，寅月春土需丙暖癸润

**三个候选用神**：
1. 调候用神：癸水（润土）
2. 格局用神：月支寅藏甲木为七杀格，取甲为格神，需要丙火化杀或食神（金）制杀
3. 扶抑用神：本局火多土燥，需水润（同调候）

**结论**：癸水为首选用神（调候 + 扶抑一致）；丙火为相神（化寅中甲杀）；格局为"七杀格有印化"。

## 六、常见错误与纠正

### ❌ 错误1：只看扶抑，忽视调候

**错误表现**：

"日主甲木生午月，得月火泄气，身弱用印（水）生身" —— 机械判断

**正确做法**：

先查《穷通宝典》：甲木午月 → 调候首用癸水（降温润木）、次用丁火（泄秀）、辅用庚金（发水源）。**调候和扶抑都指向癸水，癸水是真正用神**。若命中无癸水，行水运必发。

### ❌ 错误2：用神确定后永不变

**错误表现**：

"你命中用神是甲木，所以一辈子都喜欢木" —— 静态思维

**正确做法**：

用神**随岁运动态变化**：
- 命局原本身弱用印，但行运走得身过旺，印就变成忌神了
- 命局原本需要调候用神，但大运气候已改变，调候需求减弱
- 用神是**命局内定的**，但**喜忌随岁运而动**

### ❌ 错误3：混淆喜用神和用神

**区别**：

| 术语 | 定义 | 角色 |
|------|------|------|
| **用神** | 命局中最关键的那一字 | 主角 |
| **相神** | 辅助用神的字 | 配角 |
| **喜神** | 生扶用神的字 | 后勤 |
| **忌神** | 克破用神的字 | 敌人 |

"喜用神"是民间通称（喜神 + 用神），严格来说应分开。见 `zipin-zhenquan-sishen.md`。

### ❌ 错误4：忽视相神的重要性

**错误表现**：

"用神有了，命局就成立了" —— 过于简单

**正确做法**：

- 用神无相神 → 格局孤立，一遇克制立刻破格
- 用神 + 相神 = 格局真正成立
- 很多"中等命"的根本原因是：**用神有、相神缺**

## 七、用神确定的完整流程图

```
Step 1 — 确定格局
  └─ 月令本气透干 → 用该十神定格局
  └─ 月令本气不透 → 取月令藏干中透出者
  └─ 皆不透 → 取月令本气（格局偏弱）

Step 2 — 查调候
  └─ 查《穷通宝典》日干×月令调候用神表
  └─ 判断调候用神是否在命中出现、透干、有根

Step 3 — 判旺衰
  └─ 计算得令、得地、得生、得助、被克得分
  └─ 综合评级：很旺 / 偏旺 / 中和 / 偏弱 / 很弱

Step 4 — 综合选定用神
  └─ 调候用神与扶抑用神一致 → 最佳，用之
  └─ 两者不一致 → 调候优先
  └─ 特殊命局（从格、化气）→ 用顺势法

Step 5 — 找相神
  └─ 按格局找相应相神（查 zipin-zhenquan-sishen.md）
  └─ 评估相神是否到位

Step 6 — 识忌神
  └─ 克用神者为忌
  └─ 评估忌神是否被制化

Step 7 — 综合评级
  └─ 用神有力 + 相神到位 + 忌神有制 = 上命
  └─ 用神有力 + 相神缺 或 忌神横 = 中命
  └─ 用神无力 + 相神缺 + 忌神当道 = 下命
```

## 九、用神确定后的应用

### 应用1：判断格局高低

- **上格**：用神+相神 齐备，忌神有制
- **中格**：用神到位，相神或忌神略有问题
- **下格**：用神无力或被破

### 应用2：判断大运吉凶

- **大运助用神** → 吉运（事业升迁、财富增长、健康良好）
- **大运克用神** → 凶运（挫折、损失、疾病）
- **大运合用神** → 用神被合，作用减弱，看合化结果
- **大运冲用神** → 用神被冲，需评估冲的吉凶

### 应用3：判断流年好坏

- **流年 = 用神** → 用神得气，当年顺利
- **流年 = 忌神** → 忌神得气，当年多阻
- **流年 = 合用神** → 用神被合，当年事多变化
- **流年 = 冲用神** → 用神被冲，当年有大事（好坏需综合判断）

### 应用4：给出调理建议

- **缺什么用什么**：用神五行对应的颜色、方位、数字、职业
- **运动与饮食**：参考 `xu-wuxing-school.md` 的五行调理方案
- **心理建议**：结合十神的心理特征给出成长方向

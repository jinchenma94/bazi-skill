# 十神分析

## 概述

十神是子平八字的核心分析工具，以日主（日干）为参照，推算其余九个天干（以及地支藏干）与日主的生克关系，从而得出十种不同的"神"。十神不仅代表性格特质，更与六亲关系、事业财运、健康等各方面密切相关。

---

## 一、十神定义与基本含义

以日主五行为核心，按"同性/异性 × 生克关系"推算十神：

| 十神 | 与日主关系 | 阴阳 | 关键词 |
|------|----------|------|-------|
| 比肩 | 同五行 | 同性 | 自我、兄弟、竞争 |
| 劫财 | 同五行 | 异性 | 冒险、争夺、合伙 |
| 食神 | 日主所生 | 同性 | 才华、食禄、享受 |
| 伤官 | 日主所生 | 异性 | 个性、才艺、叛逆 |
| 正财 | 日主所克 | 异性 | 稳定财富、妻子（男命） |
| 偏财 | 日主所克 | 同性 | 流动财富、父亲 |
| 正官 | 克日主 | 异性 | 官位、规范、丈夫（女命） |
| 七杀 | 克日主 | 同性 | 权威、压力、武贵 |
| 正印 | 生日主 | 异性 | 母亲、学识、贵人 |
| 偏印 | 生日主 | 同性 | 技艺、偏门、偏印克食 |

> **十神推算口诀**：同我者比劫，我生者食伤，我克者财星，克我者官杀，生我者印星。同性为偏（比肩、食神、偏财、七杀、偏印），异性为正（劫财、伤官、正财、正官、正印）。

## 二、十神在四柱不同位置的含义差异

同一个十神在不同柱位，所代表的人生领域和力量强度不同：

| 柱位 | 代表领域 | 力量说明 |
|------|---------|---------|
| **年柱** | 祖辈、家族背景、早年（0-16岁）环境 | 影响先天根基与出身背景 |
| **月柱** | 父母、兄弟、青壮年（17-30岁）、事业环境 | 最重要！月令得时，力量最强 |
| **日柱** | 日主本身（日干）、配偶（日支） | 日支为配偶宫，反映婚姻关系 |
| **时柱** | 子女、晚年（50岁后）、事业成果 | 反映晚年运势与子孙缘分 |

### 各柱十神含义示例（以正官为例）

| 柱位 | 正官的含义 |
|------|----------|
| 年柱正官 | 祖辈有官职或社会地位，家族背景良好 |
| 月柱正官 | 早年或青年期有官运，事业发展规范稳健 |
| 日柱正官（日支） | 配偶温和有度、有责任感（女命尤显） |
| 时柱正官 | 晚年有官职或社会地位，子女优秀有出息 |

## 三、十神旺衰对性格和命运的影响

### 比肩、劫财（同类）
- **旺**：独立自主、不服管束、自我意识强；兄弟姐妹多，人际竞争激烈。
- **弱**：缺乏自信，依赖他人，兄弟缘薄，孤立感强。
- **过旺**：争财夺妻（男命），固执己见，易树敌。

### 食神、伤官（我生）
- **食神旺**：才华横溢，生活享乐，口才好，适合创作或餐饮行业。
- **伤官旺**：聪明机变，叛逆不羁，创新力强，适合艺术、技术领域；但克官，仕途不宜。
- **过旺**：伤官过旺，与上司关系差（克正官），女命婚姻受影响（伤官克夫星）。

### 正财、偏财（我克）
- **正财旺**：稳健理财，婚姻稳定，责任心强（男命妻子贤惠）。
- **偏财旺**：投机灵活，偏财运好，适合经商；父亲关系活跃。
- **过旺（日主弱）**：财多身弱，富屋穷人，有财无力守。

### 正官、七杀（克我）
- **正官旺**：重视规范，有社会责任感，适合体制内工作；女命感情认真，多正缘。
- **七杀旺**：有压迫感，行事果断，有权威；若无制化，主压力大、是非多。
- **官杀混杂**：两者同见，是非混乱，感情复杂（女命多情感纠纷）。

### 正印、偏印（生我）
- **正印旺**：博学多才，贵人多，思维缜密；依赖心强，行动力偏弱。
- **偏印旺**：技艺专精，偏门才华，直觉力强；偏印克食神，才华受压。
- **过旺**：印多身旺，好逸恶劳，懒于进取，依赖心极强。

## 七、十神分析操作步骤

1. **确定日主**：找出日干，这是十神推算的核心参照。
2. **推算十神**：对其余天干和各地支藏干，逐一与日主比较，推出十神。
3. **判断十神旺衰**：看十神是否在月令得时、在地支有根、是否透干。
4. **分析十神关系**：检查十神之间是否有生克制化（如食神制杀、官印相生等）。
5. **结合柱位**：判断十神所在年月日时柱位，确定影响的人生领域。
6. **对应六亲**：根据男女命，分别对应六亲关系。
7. **综合吉凶**：结合经典断语，给出综合吉凶判断。

## 五、实战计算案例

### 案例1：丙火日，午月（身很旺）

四柱：己卯 丙午 丙午 丁巳

计算：
- 得令：丙火在午月（帝旺）= +4
- 得地：日支午、时支巳都有丙火的根 = +3
- 得势：天干有丁火比劫 = +2
- 得生：天干无印星 = 0
- 被克制：无官杀 = 0

总分 = 4 + 3 + 2 = +9分 → 🟢🟢 很旺

### 案例2：甲木日，亥月（身旺）

四柱：癸亥 甲亥 甲子 丙寅

计算：
- 得令：甲木在亥月（冠带位）= +2
- 得地：日支子、时支寅都有甲木的根 = +2
- 得势：天干有乙木和丙火 = +1
- 得生：天干无印星透出 = +1
- 食伤泄：丙火泄甲 = -1

总分 = 2 + 2 + 1 + 1 - 1 = +5分 → 🟢 旺

### 案例3：癸水日，子月被克（身旺）

四柱：丙午 癸子 癸丑 丁巳

计算：
- 得令：癸水在子月（帝旺）= +4
- 得地：日支丑有癸水根 = +1
- 被克制：天干有丙火克 = -1
- 被财克：天干有丙丁火 = -1

总分 = 4 + 1 - 1 - 1 = +3分 → 🟢 旺

## 六、特殊情况的旺衰判断

### 特殊1：身虽弱但有特殊格局

如果判断出身很弱，但命局中财星特别旺 → 可能是从财格 → 旺衰判断改为：从格，看财星旺衰

### 特殊2：身虽旺但被完全克制

如果得令是+4，但被克制-5 → 总分是-1分，反而变弱 → 最终判断：身适中偏弱

### 特殊3：五行战克的情况

如果木火相克，土水相克 → 需要通过通关来判断 → 旺衰评分可能需要调整

## 八、旺衰判断的常见错误

### ❌ 错误1：只看月令，不看整体

**错误表现**：甲木在寅月（帝旺），就认为很旺，但忽视了其他支都没有根气

**正确做法**：要看得令+得地+得势的综���

### ❌ 错误2：忽视调候和格局特殊性

**错误表现**：算出身旺就直接用克制法，但忽视了可能是从格

**正确做法**：先判断是否特殊格局，再用相应方法

### ❌ 错误3：权重分配不当

**错误表现**：得地和得势权重一样，导致判断偏差

**正确做法**：得令最重要（50%），其他按权重分配

# 应期断事十法

> 大师断命的终极目标不是"此命好不好"，而是**"何年何月发生何事"**——这就是"应期"。
> 本文件汇集传统命理中断定事件发生时间的十种核心技法，涵盖经典派、盲派、港台派的精华。

---

## 总论：什么是"应期"

**应期** = 命局中某个"信息"（吉或凶）在大运流年中**具体兑现的时间点**。

命局是"蓝图"，大运流年是"触发器"：
- 命局有财星 → 不代表马上发财 → 等**应期到了**才发财
- 命局有官杀混杂 → 不代表马上出事 → 等**应期到了**才发生灾祸

**应期的核心逻辑**：命局的"静态信息"需要被大运流年的"动态力量"**激活**。

---

## 第一法：冲动法（最常用）

### 原理
六冲为"动"——冲到哪个宫位/十神，该宫位对应的人事就在该年发生变动。

### 规则

| 被冲位置 | 应事 |
|---------|------|
| 冲日支（夫妻宫） | 婚变、搬家、感情大变 |
| 冲月支（事业宫） | 工作变动、升迁或失业 |
| 冲年支（祖上宫） | 父母/家族大事、迁徙 |
| 冲时支（子女宫） | 子女大事、投资结果 |
| 冲用神 | 该年凶（用神受伤） |
| 冲忌神 | 该年吉（忌神被制） |

### 实战要点
- **旺冲衰**：衰者被拔（大凶/大变）
- **衰冲旺**：旺者发动（反而激活）
- 日支逢冲之年=**必有动象**（不动则凶）

### 案例
命局日支为"午"，流年遇"子"年=子午冲→该年婚姻/住所必有变动。若日支午火为用神→冲则凶（离婚/被迫搬迁）；若午火为忌→冲则吉（脱离不良关系）。

---

## 第二法：合动法

### 原理
合=牵引、拉拢——大运流年的某字"合住"命局中的某字，该字对应的人事被"引动"。

### 规则

| 合的类型 | 效果 |
|---------|------|
| 天干五合（合去） | 被合者力量减弱/性质改变 |
| 天干五合（合来） | 从外面引来新的力量 |
| 地支六合 | 两者纠缠、牵绊、新关系建立 |
| 地支三合局 | 力量大聚合=大事件 |

### 实战要点
- 流年合日主→该年有人际新关系（恋爱/合作）
- 流年合财星→该年有财来找你
- 流年合官星→该年有权贵贵人
- **合去用神→大凶**（用神被绊住无法发挥）
- **合去忌神→大吉**（忌神被牵制）

### 案例
女命日干丁火，流年壬水来→丁壬合木→命主该年有异性缘（壬水正官合日主=恋爱/结婚应期）。

## 第三法：值年太岁法

### 原理
流年干支 = "太岁"。当太岁与命局某柱**完全相同**或**天克地冲**，该年必有大事。

### 规则

| 情况 | 含义 |
|------|------|
| 太岁 = 日柱 | "伏吟"——重复=压力山大/忧愁 |
| 太岁冲日柱 | "反吟"——对抗=剧变 |
| 太岁 = 年柱 | 本命年=自我重审之年 |
| 太岁冲年柱 | 犯太岁=外部压力大 |

### 实战要点
- 伏吟年：痛苦但未必是灾——可能是"跟自己较劲"的一年
- 反吟年：外在变化大——搬家/换工作/分手/大手术
- 本命年（12 年一轮）：每次都是人生阶段的"检视"

## 第四法：墓库收藏法

### 原理
五行入墓库=被"收藏/锁住"；墓库被冲开=释放。

### 四库对应

| 墓库 | 收藏 | 冲开者 |
|------|------|--------|
| 辰（水库） | 癸水入辰 | 戌冲辰 |
| 戌（火库） | 丁火入戌 | 辰冲戌 |
| 丑（金库） | 辛金入丑 | 未冲丑 |
| 未（木库） | 乙木入未 | 丑冲未 |

### 实战要点
- 用神入墓→该步大运事事受阻→直到被冲开之年才解套
- 财星入墓→有钱但拿不出来/被困→墓库冲开年=发财年
- 日主入墓→身体欠佳/事业低迷→冲开年=东山再起

### 案例
命局财星壬水无力且坐辰（水库），第三步大运走戌运→辰戌冲→水库打开→该步大运的具体年份看流年何时再冲或何时透壬→即为发财应期。

## 第五法：长生帝旺法

### 原理
每个天干在十二地支中有"生旺死绝"的循环（长生→沐浴→冠带→临官→帝旺→衰→病→死→墓→绝→胎→养）。大运流年走到用神/忌神的"帝旺地"或"长生地"=该五行力量最强时。

### 实战要点

| 用神走到 | 效果 |
|---------|------|
| 长生 | 用神复苏→好事开始萌芽 |
| 帝旺 | 用神最强→好事达到顶峰 |
| 墓地 | 用神入墓→好事结束/受困 |
| 绝地 | 用神最弱→最凶之时 |

- **断升职**：官星走到帝旺之年
- **断发财**：财星走到长生或帝旺之年
- **断生病**：日主走到病/死/墓/绝之年

### 案例
甲木日主，用神为壬水（偏印）。壬水长生在申，帝旺在子。→ 走申年或子年=学业/贵人运最旺。

## 第六法：天干透出引发法

### 原理
命局地支中"藏而不透"的五行，当大运流年的天干把它"引透"出来时=该五行的事项正式发生。

### 规则
- 地支藏干是"潜在信息"（有但没发挥）
- 天干透出=从潜在变为现实
- **大运天干透出→十年内该事项主题成立**
- **流年天干透出→该年具体兑现**

### 实战要点
- 命局地支藏有偏财但天干不见→走大运天干透偏财之年=发横财
- 命局地支藏有七杀但不透→走大运天干透杀之年=升职（有制）或灾祸（无制）
- "藏"而"透"=从暗到明=事情公开化

### 案例
命局申金中藏壬水（偏印），但四柱天干不见壬。第四步大运天干走壬→该步大运命主进修/拜师/获高学历。具体哪年？看流年地支何时是壬水长生帝旺地（申或子年）。

## 第七法：刑动法

### 原理
三刑为"刑罚/纪律/法律/手术"——大运流年凑齐三刑=该年有官司、手术、牢狱、严重冲突。

### 三刑组合

| 类型 | 组合 | 性质 |
|------|------|------|
| 无恩之刑 | 寅巳申 | 恩将仇报、背叛 |
| 恃势之刑 | 丑戌未 | 仗势欺人、刑罚 |
| 无礼之刑 | 子卯 | 不守规矩、淫乱 |
| 自刑 | 辰辰/午午/酉酉/亥亥 | 自我伤害、抑郁 |

### 实战要点
- 命局已有两个刑→大运/流年补齐第三个=刑动年=出事
- **刑到用神**→该年损失大
- **刑到日支**→该年婚姻/身体出问题
- 刑同时也是"动"——可能是强制性的变动（非自愿搬迁/被动离职）

### 案例
命局有寅和巳，流年走申年→寅巳申三刑齐→该年有官司/手术/背叛事件。如果寅木是用神→损失惨重；如果寅木是忌神→反而是"以刑制凶"=逢凶化吉。

## 第八法：桃花引动法

### 原理
桃花（咸池）被大运流年冲合引动=感情/婚恋/色欲事件。

### 桃花查法
以日支或年支查：
- 申子辰→桃花在酉
- 寅午戌→桃花在卯
- 亥卯未→桃花在子
- 巳酉丑→桃花在午

### 实战要点
- 流年走桃花地支=该年有异性缘
- 桃花被冲=感情变动（分手/新恋情）
- 桃花被合=感情确定（结婚/稳定关系）
- **桃花+驿马同现**=异地恋/旅途邂逅
- **桃花坐空亡**=有缘无份/短暂情缘

### 断结婚应期（综合）
以下条件满足越多，结婚可能性越大：
1. 流年合日支（夫妻宫被合动）
2. 流年冲开配偶星墓库
3. 流年走桃花
4. 大运走正财/正官帝旺地（男看财/女看官）
5. 流年天干透出配偶星

## 第九法：神煞引发法

### 原理
命局中某个神煞（天乙贵人/驿马/华盖/羊刃等）在大运流年被"激活"时，对应的事件发生。

### 常用神煞应期

| 神煞 | 被引动时的应事 |
|------|---------------|
| 驿马 | 出行/搬迁/工作调动/出国 |
| 天乙贵人 | 遇贵人帮助/化险为夷 |
| 羊刃 | 血光之灾/手术/暴力事件/大起大落 |
| 华盖 | 宗教/艺术/独处/研究/孤独 |
| 天医 | 生病或从医/接触医疗 |
| 将星 | 升职/掌权/出头 |

### 实战要点
- 驿马逢冲=必动（冲动驿马是最强的迁移信号）
- 羊刃逢冲=血光/大破大立
- 贵人逢合=贵人来助

## 第十法：岁运并临法

### 原理
大运干支与流年干支**完全相同**（如大运甲子，流年也是甲子）=力量加倍=该年事件极端（大吉或大凶）。

### 规则
- 岁运并临**用神**→该年极吉（双倍好运）
- 岁运并临**忌神**→该年极凶（双倍灾祸）
- 古歌云"岁运并临，不死自己死他人"——虽然夸张但确实是重要年份

### 实战要点
- 60 年一遇（很罕见），但"半并临"（天干同或地支同）10 年会遇一次
- 并临的力量 > 普通年份的 2-3 倍
- 并临年的吉凶取决于所并临的干支是**用神还是忌神**

## 综合应用：断事流程

### 第一步：定"事项"（断什么事）
从命局格局和十神看——命主最可能在什么领域有大事：
- 财星旺→财运事件
- 官杀旺→仕途/压力事件
- 食伤旺→创作/子女事件
- 印星旺→学业/贵人事件

### 第二步：定"大运"（哪个十年）
看哪步大运引动了上述事项——即**大运天干或地支与命局该十神发生冲/合/透/旺的关系**。

### 第三步：定"流年"（哪一年）
在确定的那步大运中，找具体哪年触发：
1. 冲动法：流年冲到相关宫位
2. 合动法：流年合出相关十神
3. 透出法：流年天干透出藏干
4. 帝旺法：流年走到该十神帝旺地
5. 刑动法：流年凑齐三刑
6. 墓库法：流年冲开墓库
7. 桃花法：流年走桃花（感情事）
8. 神煞法：流年引动特定神煞

### 第四步：定"月份"（精确到月，可选）
用**流月**的干支对照上述规则进一步缩小范围（高级用法）。

## 十法优先级排序

| 优先级 | 方法 | 适用场景 |
|--------|------|---------|
| ⭐⭐⭐ | 冲动法 | 所有事件类型（通用性最强） |
| ⭐⭐⭐ | 合动法 | 感情/合作/人际关系 |
| ⭐⭐⭐ | 透出引发法 | 断何时"暗变明"（升职/发财/公开） |
| ⭐⭐ | 墓库收藏法 | 断解困/发财/脱困时间 |
| ⭐⭐ | 长生帝旺法 | 断鼎盛期/低谷期 |
| ⭐⭐ | 值年太岁法 | 断大波动年 |
| ⭐ | 刑动法 | 断官司/手术/刑事 |
| ⭐ | 桃花引动法 | 断感情/婚姻 |
| ⭐ | 神煞引发法 | 断特定事件（出行/贵人等） |
| ⭐ | 岁运并临法 | 断极端年份 |

## 常见错误

| 错误 | 纠正 |
|------|------|
| 只看流年不看大运 | 大运定主题（十年），流年定具体年份——两者必须配合 |
| 冲必凶 | 冲忌神反而是好事；冲用神才凶 |
| 合必吉 | 合去用神是大凶；合去忌神才是吉 |
| 一年只看一个法 | 实战中多法叠加才准确——满足 3 种以上条件才能确定 |
| 精确到日 | 除非用流月流日（高级技法），否则断到年份已算精准 |

## 检查清单

- [ ] 已确定命局的核心"信息"（最可能出事的领域）
- [ ] 已找到哪步大运引动该信息（十年范围）
- [ ] 已用 2-3 种方法交叉定位具体流年
- [ ] 已区分"冲/合"的对象是用神还是忌神（决定吉凶方向）
- [ ] 已综合神煞/桃花等辅助信号做最终判断
- [ ] 未向命主做绝对承诺（"一定会"），而是以"概率较高"表述

# 调候用神完整表（《穷通宝典》120 条）

## 一、总论

《穷通宝典》（又名《栏江网》《造化元钥》，清代余春台编定）是论调候的最重要典籍。其核心观点：

> **"论命先论调候，调候得宜，格局自成。"**

调候，就是根据**日干**与**出生月令**形成的寒暖燥湿倾向，选定命局最需要的那个五行来"调节气候"。调候用神的地位高于扶抑用神——即使日主中和、格局清纯，若调候失衡，人生仍多阻滞。

### 调候优先规则

1. **先看月令气候**：冬寒、夏热、春湿、秋燥
2. **再看日干特性**：十干在十二月各有喜忌
3. **选定调候用神**：通常是一至两字（如"丙癸并用"）
4. **配合扶抑判断**：调候用神与扶抑用神一致则大吉；矛盾时**调候优先**，扶抑次之

### 使用本表的方法

- 定位出生月令（按节气，不按农历初一）
- 查对应日干的调候用神条目
- 观察命局中该用神**是否出现、是否透干、是否有根、是否被克**
- 综合判断调候"得用"还是"失用"

## 二、甲木日主十二月调候

### 甲木生寅月（立春—惊蛰）
- **用神**：丙火为主，癸水为辅
- **理路**：初春余寒未尽，木嫩阳弱，先取丙火暖局，后用癸水滋润木根
- **成格**：丙癸两透、不相冲克 → 富贵双全
- **破格**：丙癸俱无 → 一生平庸；见庚辛克甲无丙制 → 伤灾

### 甲木生卯月（惊蛰—清明）
- **用神**：庚金为主，丙、丁、戊为辅
- **理路**：仲春木旺，宜用庚金劈甲以成栋梁；丙火泄秀，戊土为财
- **成格**：庚金得用、透丁制之（庚金劈甲引丁）→ 大贵之命
- **破格**：庚金无丁制 → 伤身；木多火塞 → 愚钝

### 甲木生辰月（清明—立夏）
- **用神**：庚金为主，壬、丁为辅
- **理路**：季春土旺，木气将退，取庚金制木，壬水润土养木，丁火取暖
- **成格**：庚透壬辅 → 富贵可期
- **破格**：土厚无木疏 → 劳碌一生

### 甲木生巳月（立夏—芒种）
- **用神**：癸水为主，庚、丁为辅
- **理路**：初夏火旺木焚，急需癸水润泽；庚金发水源，丁火虽泄但不宜过
- **成格**：癸水透干有根 → 清贵之命
- **破格**：癸水枯竭 → 病灾、伤眼

### 甲木生午月（芒种—小暑）
- **用神**：癸水为主，丁、庚为辅
- **理路**：仲夏火炎土燥，木性焦枯，非癸水不活；庚金发水源最妙
- **成格**：癸庚两透 → 富贵显达
- **破格**：无水调候 → 贫苦夭折、多灾

### 甲木生未月（小暑—立秋）
- **用神**：癸水为主，丁、庚为辅
- **理路**：季夏土燥，木根焦枯，仍以癸水为急；丁火伤官可用
- **成格**：癸水有力、不受冲克 → 富贵兼全
- **破格**：癸水干枯 → 身体多病

### 甲木生申月（立秋—白露）
- **用神**：庚金为主，丁火为辅
- **理路**：初秋金旺木衰，虽有杀克身，但取庚金成器、丁火制杀化杀为权
- **成格**：庚丁两透、位置得宜 → 武贵或技艺成名
- **破格**：庚金无制 → 伤灾、克父

### 甲木生酉月（白露—寒露）
- **用神**：丁火为主，丙、庚为辅
- **理路**：仲秋金旺极，木气凋零，取丁火制杀为最，丙火暖木，庚为劈甲
- **成格**：丁透有根 → 贵显
- **破格**：无丁制杀 → 一生受压、事业多折

### 甲木生戌月（寒露—立冬）
- **用神**：庚金为主，甲、丁、壬、癸为辅
- **理路**：季秋土旺金强，木气衰极，取庚金劈甲、丁火暖之、壬癸润之
- **成格**：庚丁壬齐备 → 上命
- **破格**：干燥无水 → 短寿、多病

### 甲木生亥月（立冬—大雪）
- **用神**：庚金为主，丁、戊、丙为辅
- **理路**：初冬水旺木浮，用戊土止水，庚金劈甲，丁丙取暖
- **成格**：戊庚丁三全 → 富贵双美
- **破格**：水多木浮、无戊土 → 漂泊之命

### 甲木生子月（大雪—小寒）
- **用神**：丁火为主，庚、丙为辅
- **理路**：仲冬水旺木冻，必须丁火解冻暖身，庚金为根
- **成格**：丁透庚辅 → 富贵
- **破格**：冬木无火 → 贫寒孤苦

### 甲木生丑月（小寒—立春）
- **用神**：丁火为主，庚、丙为辅
- **理路**：季冬寒气极盛，非火不暖；丁火优于丙，丙为外暖，丁为内暖
- **成格**：丁火有根、不受水克 → 上命
- **破格**：寒湿无火 → 手足冻损、脾胃病

## 三、乙木日主十二月调候

- **用神**：癸水为主
- **理路**：乙木喜阴喜润，夏月尤甚，癸水一点而足
- **成格**：癸水有根 → 清秀富贵
- **破格**：无水 → 皮肤病、眼疾

### 乙木生午月
- **用神**：癸水为主，丙火为辅
- **理路**：火炎木焚，非癸莫救；丙火调候亦不可少

### 乙木生未月
- **用神**：癸水为主，丙、辛、甲为辅
- **理路**：土旺木枯，癸水润之，辛金发水源
- **成格**：癸辛并透 → 福寿双全

### 乙木生申月
- **用神**：丙火为主，己、癸为辅
- **理路**：初秋金旺，乙木遇金须丙火制之；己土为培根，癸水泄金生木
- **成格**：丙己癸齐 → 贵命

### 乙木生酉月
- **用神**：癸水为主，丙、丁为辅
- **理路**：仲秋金极旺，乙木极弱，须癸水化杀为印；丙丁取暖辅之
- **成格**：癸水化杀 → 贵命
- **破格**：金旺无制、无水化 → 身体多灾

### 乙木生戌月
- **用神**：癸水为主，辛、甲为辅
- **理路**：季秋土燥金旺，癸水为急，辛金生癸水

### 乙木生亥月
- **用神**：丙火为主，戊土为辅
- **理路**：初冬水多，乙木浮根；戊土止水，丙火暖身
- **成格**：丙戊并透 → 富贵

### 乙木生子月
- **用神**：丙火为主
- **理路**：仲冬水冻木枯，急需丙火解冻；忌癸水出干冻丙
- **成格**：丙火有根、无癸制 → 上命

### 乙木生丑月
- **用神**：丙火为主
- **理路**：与子月同，寒气更甚，丙火不可缺

## 四、丙火日主十二月调候

### 丙火生寅月
- **用神**：壬水为主，庚金为辅
- **理路**：初春丙火新生尚寒，但旺气在后；壬水为制火之用，庚金发水源
- **成格**：壬庚并透 → 大贵

- **用神**：壬水为主，己土为辅
- **理路**：仲春木旺生火，火得木炎而渐盛，壬水制之为用
- **成格**：壬水通根 → 贵显

### 丙火生辰月
- **用神**：壬水为主，甲木为辅
- **理路**：季春土旺泄火气，壬水调候，甲木疏土
- **成格**：壬甲并透 → 文贵

### 丙火生巳月
- **用神**：壬水为主，庚、癸为辅
- **理路**：初夏丙火得禄，火焰高炽，非壬莫制；庚金发源
- **成格**：壬庚两透 → 大富大贵

### 丙火生午月
- **用神**：壬水为主，庚为辅
- **理路**：仲夏火旺到极致，调候用壬水、庚金最急
- **成格**：壬庚齐出、水有根 → 富贵双全
- **破格**：无水调候 → 眼疾、心火旺、脾气暴

### 丙火生未月
- **用神**：壬水为主，庚为辅
- **理路**：季夏土旺晦火，但余热未消，仍以壬水为急

### 丙火生申月
- **用神**：壬水为主，戊土为辅
- **理路**：初秋金旺生水，壬水有源，丙需壬水辉映；戊土制水留情
- **成格**：壬戊齐透 → 功名显达

### 丙火生酉月
- **用神**：壬水为主，癸为辅
- **理路**：仲秋金旺，丙火衰于酉，壬癸水能辉映丙火
- **成格**：壬透丙映 → 江辉映日格，大贵

### 丙火生戌月
- **用神**：甲木为主，壬为辅
- **理路**：季秋土旺晦光，甲木疏土、壬水润之
- **成格**：甲壬两透 → 文贵

### 丙火生亥月
- **用神**：甲木为主，戊、庚、壬为辅
- **理路**：初冬水旺火灭，急需甲木泄水生火；戊土止水护火
- **成格**：甲木有力、戊土得位 → 贵命
- **破格**：水多火灭、无木救 → 短寿

### 丙火生子月
- **用神**：壬水为主，戊、己为辅
- **理路**：仲冬水极旺，丙火几灭，反用壬水为官星，戊土制壬以留火
- **成格**：壬戊相制 → 贵格
- **破格**：无戊制壬 → 火被水灭

### 丙火生丑月
- **用神**：壬水为主，甲为辅
- **理路**：季冬丑土湿重，丙火晦而不明，取甲木疏土生火；调候仍看壬

### 使用说明

- **粗体字**：首选调候用神（最关键，决定命之贵贱）
- 其后字符：辅助用神（配合使用可成格）
- 若首选用神**透干有根**，调候成立；若**不透或无根**，调候失用
- 若首选用神被**冲、克、合化**，调候受损
- 调候用神在**大运流年**中出现，往往是人生重大转折

## 十三、调候应用实例

### 例1：甲木生午月（丙午年、甲午月、甲午日、甲子时）

- **调候用神**：癸水（首要）、丁火、庚金
- **分析**：日柱甲午，时支子水为癸水之根，癸水得用；丁午之丁未透；庚金无根
- **结论**：调候半成，用神癸水有力，适合文职、清贵；若走庚运补源，大发

### 例2：丙火生子月（丙子年、庚子月、丙午日、戊戌时）

- **调候用神**：壬水（首要）、戊土、己土
- **分析**：月支子水为壬水根，壬未透；戊土透干制水护火
- **结论**：调候以戊制壬为用，格局成立，为贵命；忌甲木运破戊

### 例3：庚金生午月（戊午年、戊午月、庚寅日、丙戌时）

- **调候用神**：壬水（首要）、癸水
- **分析**：命局无壬水、无癸水，火气过炎，庚金熔化
- **结论**：调候失用，一生多病、事业多折；若走壬癸大运，方有转机

## 十四、调候与扶抑的协调

### 调候优先的场景

1. **夏生无水、冬生无火**：调候失用的严重程度高于扶抑
2. **命局气候明显失衡**：全火、全水、全燥、全湿

### 扶抑优先的场景

1. **日干极弱或极强**：必先定日主，再议调候
2. **格局已成**：正官、七杀等格局当先，调候辅之

### 两者兼顾

最上命格是**调候与扶抑同用一字**的命局：

- 甲木生午月，身弱需印——癸水既调候又生身
- 丙火生子月，身弱需比劫——甲木既生丙又暖水
- 庚金生酉月，身强需泄——丁火既炼金又调候

## 十五、调候的大运流年启示

- **首选调候用神到来之年**：事业跃升、身体转好、婚姻顺遂
- **首选调候用神被冲合之年**：易病、易灾、事业受阻
- **命局原有调候失用 + 大运补入**：此大运十年为人生黄金期
- **命局原有调候齐备 + 大运克破**：此大运十年为人生低谷

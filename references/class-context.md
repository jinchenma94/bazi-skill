# 阶级语境与资源场定位

## 家庭与阶层推断边界

不要用八字反推用户的家庭总资产、父母职业、父辈资源、原生家庭稳定性、家庭现金流、继承/分配结构或本人可调用家庭资源。阶层语境只能来自用户已经提供的现实事实，例如职业、经营项目、资产、城市、现金流压力、合作对象和当前问题。

如果用户没有提供家庭事实，输出时只说“家庭事实未校准，不作判断”。如果用户明确询问家庭财富或原生资源，必须先请求或列出需要校准的现实事实，不能用年柱、月柱、财星、印星、财库等直接下结论。

本文件用于落实一个前置原则：现实语境决定问题含义。八字分析不能只看命局符号，还要把用户放回其已提供的职业、经营、资产量级、现金流压力和社会关系网络中解释。同一个十神、同一个流年事件，在不同语境中对应的现实问题完全不同。

## 核心原则

- 看命之前，先定位用户已提供的现实语境和资源场；未定位前，不要直接给事业、婚恋、财富建议，更不要推断家庭。
- 阶级定位不是道德评价，而是现实语境校准：资产多个 0，风险、选择、焦虑、自由度、关系议题都会变化。
- 若用户已经提供明确资产、居住、职业或家庭背景事实，以事实为锚；八字负责解释其结构和影响，不要反向否认事实。
- 若用户未提供阶级信息，只能输出假设区间，并提出校准问题。不要把普通中产语境默认套给所有人。
- 区分“客观阶级位置”和“主观心理体感”：高净值个体也可能缺少自由感、安全感和掌控感。

## 阶级定位四要素

| 维度 | 需要判断什么 | 常见校准问题 |
|---|---|---|
| 用户已提供资产 | 本人或经营主体已明确的现金流、股权、不动产、金融资产、项目投入 | 只记录用户已经提供的资产事实，不从八字反推家庭资产 |
| 资产流动性 | 钱是否容易调用，现金流是否宽松 | 资产主要是现金流、房产、股权、公司账面，还是不可轻易变现？ |
| 用户可支配权 | 用户本人能否自由调动资源 | 重要财务决定是否需要他人、合伙人、资方或制度同意？是否有分配、控制问题？ |
| 阶级心理 | 用户如何感受财富和风险 | 是觉得自由，还是觉得被期待、被控制、有压力、怕失去？ |

## 资产量级与问题语义

以下不是固定阶层表，而是分析语境参考。实际判断以用户现实事实为准。

| 资产/资源场 | 典型关注点 | 同一事件的含义 |
|---|---|---|
| 生存/负债压力 | 稳定收入、偿债、基本安全、突发支出 | 失业=生存风险；感情=共同承担现实；投资=风险不可承受 |
| 小康/普通中产 | 房贷、教育、职业稳定、抗风险能力 | 换工作=现金流压力；婚恋=生活质量与共同规划 |
| 中上中产/专业精英 | 职业天花板、资产配置、城市选择、子女教育 | 换工作=阶层跃迁或职业身份；感情=价值观与资源匹配 |
| 高净值 | 资产保值、税务法务、股权/房产、圈层、人脉 | 工作=身份与资源入口；婚恋=边界与风险管理 |
| 企业/资本语境 | 控制权、经营主体、声誉、信托、跨周期资源 | 工作=自我证明或组织位置；婚恋=联盟、边界、风险隔离；财富=治理问题 |

## 同一命理信号的阶级化解释

| 命理信号 | 普通中产语境 | 高净值/超高净值语境 |
|---|---|---|
| 财星旺 | 收入能力、赚钱机会、消费压力 | 资本配置、经营资源、项目收益、资源调用权 |
| 财星受劫 | 破财、合伙损耗、现金流流失 | 分配争议、股权稀释、资源被锁定 |
| 七杀重 | 上级压力、考试竞争、职场规训 | 权力结构、法律合规、企业治理压力 |
| 印星强 | 学历、证书、贵人、系统支持 | 资源背书、名校圈层、制度通道 |
| 食伤旺 | 技术表达、副业、创作 | 个人品牌、自主创业、对既有规则的反叛 |
| 辰戌丑未库动 | 房产、储蓄、稳定资产变化 | 大额不动产、资产重组、信托/股权结构 |
| 冲夫妻宫 | 感情分合、伴侣冲突 | 婚配风险、财产隔离、关系与资产边界 |

## 分析流程

1. 先收集现实语境：用户职业、经营项目、资产类型、现金流压力、可支配权、主观安全感。
2. 再看命局：财星/财库看本人资源动作和现金流压力，官杀看规则压力，印星看资质与系统背书，比劫看竞争和合伙分配。年柱/月柱不得用来反推家族根基。
3. 把用户问题翻译到阶级语境：
   - 事业问题：是生存收入、职业身份、组织位置，还是自我证明？
   - 感情问题：是生活匹配、阶层跃迁、边界管理，还是资产边界？
   - 财富问题：是赚钱、守钱、现金流、投资、继承，还是治理？
   - 健康问题：是劳损、生存压力、情绪控制，还是高压责任与长期消耗？
4. 输出时必须说明“这个判断是在什么阶级语境下成立”。
5. 如果用户反馈阶级事实与推断不同，立刻修正阶级锚点，再重算问题含义。

## 输出模板

```text
阶级语境：
- 现实资产/资源场：……
- 资产流动性：……
- 用户可支配权：……
- 主观财富安全感：……

问题翻译：
- 在这个现实语境里，用户问的“事业/感情/财富”实际更接近……

八字解释：
- ……

现实建议：
- ……
```

## 财富四层输出合同

当用户问“家庭财富阶级、家里有没有钱、原生资源、我能不能用家里资源”时，不得按八字直接输出结论；先说明家庭事实未校准，并请求现实事实。只有用户提供事实后，才可解释这些事实如何影响其当前问题。

| 层级 | 必答问题 | 命局抓手 | 现实校准 |
|---|---|---|---|
| 用户已提供资产事实 | 用户已经说明的本人/经营主体资产和现金流 | 现实事实优先，八字只作解释 | 房产、企业、股权、土地、金融资产、项目现金流等由用户提供 |
| 本人现金流与资产流动性 | 本人或项目的钱是活钱、固定资产、股权账面，还是周期性现金流 | 财星透藏、食伤生财、财库开合、岁运冲库 | 可随时调用现金、资产变现难度、企业现金流、债务压力 |
| 用户本人可调用资源 | 用户本人能否自由使用已知资源 | 印星保护、官杀规则、比劫分夺、日主承载力 | 大额支出是否需合伙人/资方/制度同意、分配/控制权、成员竞争 |
| 用户主观财富安全感 | 用户是否觉得自由、安全、可控 | 财杀压身、劫财、冲刑、身弱财旺、当前运年压力 | 焦虑、被期待、被控制、怕失去、现金流安全感 |

推荐短答格式：

```text
铁口：……
四层判断：
- 用户已提供资产事实：……（依据：用户事实；置信度：A/B/C）
- 资产流动性：……（依据：……；置信度：A/B/C）
- 本人可调用资源：……（依据：……；置信度：A/B/C）
- 主观安全感：……（依据：……；置信度：A/B/C）
校准：……
```

高净值/企业资本分支只能在用户提供现实资产事实时保留。不得因年月财星、财库、官印、食伤生财或所谓家族宫位强，就直接推断高资产；这些信号只能解释为“资源动作、规则压力、现金流周期或资产治理议题”。

## 禁止事项

- 禁止默认把所有人放进普通中产叙事。
- 禁止把“财富压力大”解释成“财富不高”。
- 禁止把“用户焦虑”解释成“客观资源不足”。
- 禁止在已知用户是高净值/超高净值时，还用普通职场、普通婚恋、普通理财语境套话。
- 禁止忽视资产量级对风险偏好、关系边界和人生选择的根本影响。

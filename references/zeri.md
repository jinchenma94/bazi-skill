# 择日学完整指南

## 一、总论

**择日**（又称"选择学""日课"）是中国传统术数中与**风水、命理**并列的三大实用术数之一。它的目的是：

> **选择一个"天时地利人和"都对命主有利的时间，来做人生的重大事情。**

### 择日的典型应用

- **婚嫁**：结婚登记、订婚、迎娶日
- **开张**：开业、开工、公司成立
- **动土**：盖房、装修、动工
- **搬家**：乔迁、入宅
- **祭祀**：上坟、祭祖
- **出行**：长途旅行、出国
- **手术**：重大医疗手术
- **签约**：重要合同签署
- **求职 / 面试**：重要职场场合
- **开光 / 奠基**：宗教仪式

### 择日的理论基础

择日学综合了以下理论：

1. **四柱命理**（本 Skill 的核心）——要配合命主用神
2. **天星择日**（配合二十八宿、紫白飞星）
3. **建除十二神**（建、除、满、平、定、执、破、危、成、收、开、闭）
4. **黄道黑道**（十二神对应吉凶）
5. **神煞系统**（岁破、月破、天德、月德、天赦等）
6. **奇门遁甲**（高级择日使用）

本指南聚焦于**与四柱八字相结合的择日法**，这是最实用的方法。

## 二、择日的基本原则

### 原则1：配合命主用神

> **择日的最高原则：所选时间的五行，必须与命主的用神一致。**

例：
- 命主用神为**水** → 选亥子月、亥子日、亥子时
- 命主用神为**木** → 选寅卯月、寅卯日、寅卯时
- 命主用神为**火** → 选巳午月、巳午日、巳午时

### 原则2：避免冲克命主

**四忌**：
1. **冲日柱**：所选日不与命主日柱相冲（天克地冲）
2. **冲年柱**：所选日不与命主年柱相冲（俗称"犯太岁"）
3. **克用神**：所选日的干支不克命主用神
4. **助忌神**：所选日不助长命主的忌神

### 原则3：选择吉神在位

传统择日会选**吉神当日**：
- **天德、月德、天赦、天愿、天恩**（最吉）
- **三合、六合、黄道日**（吉）
- **天乙贵人、文昌、天喜、红鸾**（次吉）

### 原则4：避开凶煞

必须避开的**大凶日**：
- **岁破日**（与流年太岁相冲）
- **月破日**（与当月月建相冲）
- **四离日**（春分、秋分、夏至、冬至前一日）
- **四绝日**（立春、立秋、立夏、立冬前一日）
- **三丧日、杨公忌日、红沙日**（民间大忌）

### 原则5：事类不同，忌讳不同

| 事类 | 特别需要 | 特别避免 |
|------|---------|---------|
| 婚嫁 | 三合、六合、天喜、红鸾 | 孤辰寡宿、岁破、月破、三丧 |
| 开张 | 财星吉日、天乙贵人、禄马 | 破财日、劫煞、败日 |
| 动土 | 黄道日、建开日 | 土府日、土瘟日、杀师日 |
| 搬家 | 成、开、满日；驿马 | 破、平、收日；岁破 |
| 出行 | 驿马日、开日 | 往亡日、归忌日 |
| 手术 | 天医、除日 | 血刃日、血忌日 |
| 签约 | 开日、定日、成日 | 破日、平日、闭日 |
| 祭祀 | 天德、月德 | 正冲日 |

## 三、建除十二神

建除十二神是择日的基本工具，以日支与当月月建（节气所在月）的关系判断：

### 十二神速查

| 日支相对月建 | 神名 | 吉凶 | 适宜 | 忌讳 |
|------------|------|------|------|------|
| 同月建 | **建** | 吉（主事） | 开张、上任、求财、立契 | 动土、乘船 |
| 月建后1位 | **除** | 吉（除旧） | 求医、除服、驱邪、祭祀 | 远行、赴任 |
| 月建后2位 | **满** | 吉（圆满） | 结婚、开市、移徙、求财 | 葬事、动土 |
| 月建后3位 | **平** | 中（平平） | 铺路、治道、扫舍 | 祭祀、婚嫁、诉讼 |
| 月建后4位 | **定** | 吉（定局） | 结婚、立契、签约、赴任 | 诉讼、出行、动土 |
| 月建后5位 | **执** | 吉（执事） | 造作、稳固、捕捉 | 开市、移徙、结婚 |
| 月建后6位 | **破** | 大凶（破坏） | 破屋坏垣、破旧立新 | **万事皆忌**，除非破旧 |
| 月建后7位 | **危** | 凶（危险） | 祭祀、祈福 | 登高、乘船、冒险 |
| 月建后8位 | **成** | 大吉（成事） | 几乎万事皆宜 | 诉讼 |
| 月建后9位 | **收** | 中（收敛） | 收藏、纳财、结婚、学艺 | 开张、动土、出行 |
| 月建后10位 | **开** | 吉（开通） | 开市、入学、求医、移徙 | 破土、葬事 |
| 月建后11位 | **闭** | 凶（闭塞） | 填穴、筑堤、葬事 | 开张、出行、婚嫁 |

### 速查举例

若**月建为寅**（正月）：
- 寅日 = 建
- 卯日 = 除
- 辰日 = 满
- 巳日 = 平
- 午日 = 定
- 未日 = 执
- 申日 = **破**（与寅相冲）
- 酉日 = 危
- 戌日 = 成
- 亥日 = 收
- 子日 = 开
- 丑日 = 闭

### 建除十二神的应用总结

**最吉四神**：成、开、满、定
**次吉四神**：建、除、执、收
**凶神**：破（极凶）、闭、危
**中性**：平

## 四、黄道黑道

黄道黑道是另一套择日工具，以**日支**配合月建判断。

### 十二神对应表（以寅月为例）

| 日支 | 神名 | 吉凶 |
|------|------|------|
| 子 | 青龙（黄道） | 🟢 大吉 |
| 丑 | 明堂（黄道） | 🟢 吉 |
| 寅 | 天刑（黑道） | 🔴 凶 |
| 卯 | 朱雀（黑道） | 🔴 凶 |
| 辰 | 金匮（黄道） | 🟢 吉 |
| 巳 | 天德（黄道） | 🟢 大吉 |
| 午 | 白虎（黑道） | 🔴 凶 |
| 未 | 玉堂（黄道） | 🟢 吉 |
| 申 | 天牢（黑道） | 🔴 凶 |
| 酉 | 玄武（黑道） | 🔴 凶 |
| 戌 | 司命（黄道） | 🟢 吉 |
| 亥 | 勾陈（黑道） | 🔴 凶 |

**口诀**：
> 子午临申地，丑未戌上寻；
> 寅申居子位，卯酉却加寅；
> 辰戌龙位上，巳亥午中停。

（意思是月建不同，起点不同。实际使用时需要根据月建起算）

### 六黄道 vs 六黑道

**六黄道**（吉神，诸事可用）：
- **青龙**（大吉）
- **明堂**（贵人相助）
- **金匮**（财喜）
- **天德**（化解灾难）
- **玉堂**（文书吉）
- **司命**（护佑）

**六黑道**（凶神，诸事避之）：
- **天刑**（刑罚）
- **朱雀**（口舌）
- **白虎**（血光）
- **天牢**（牢狱）
- **玄武**（偷盗）
- **勾陈**（纠缠）

## 五、神煞择日

### 五大吉神（最重要）

#### 1. 天德、月德
- **天德**：按月查，如正月丁、二月申……（《协纪辨方书》表）
- **月德**：正月丙、二月甲、三月壬、四月庚、五月丙……（五行三合局的旺气）
- **应用**：万事皆宜，尤其化凶解厄、祭祀祈福

#### 2. 天赦日
- **查法**：
  - 春（寅卯辰月）→ 戊寅日
  - 夏（巳午未月）→ 甲午日
  - 秋（申酉戌月）→ 戊申日
  - 冬（亥子丑月）→ 甲子日
- **应用**：万事大吉，可解百凶

#### 3. 天愿日
- **查法**：特定的日期（需查万年历）
- **应用**：开张、婚嫁、祈福

#### 4. 天医日
- **查法**：按月支查，如正月丑、二月寅……
- **应用**：治病、求医、手术

#### 5. 母仓日
- **查法**：按月支查（特定组合）
- **应用**：种植、养殖、求子

### 五大凶神（最需避开）

#### 1. 岁破日
- **定义**：与流年太岁（年支）相冲的日子
- 2026年丙午年，午为太岁 → **子日为岁破**
- **忌**：万事大忌，尤其婚嫁、开张

#### 2. 月破日
- **定义**：与当月月建相冲的日子
- 如寅月 → 申日为月破
- **忌**：与岁破同等凶

#### 3. 四离日、四绝日
- **四离**：春分、秋分、夏至、冬至**前一日**
- **四绝**：立春、立秋、立夏、立冬**前一日**
- **忌**：季节转换之际气场不稳，不宜重要事

#### 4. 三丧日
- **查法**：特定组合（民间有表可查）
- **忌**：婚嫁、开张、搬家（三者连犯）

#### 5. 杨公忌日
- **十三个固定日期**：正月十三、二月十一、三月九、四月七、五月五、六月三、七月初一、七月二十九、八月二十七、九月二十五、十月二十三、十一月二十一、十二月十九
- **忌**：万事不宜（民间传说杨救贫忌此日）

## 六、择日的标准流程

### 第一步：明确择日目的

- 什么事？（婚嫁/开张/搬家/手术……）
- 命主是谁？（收集完整八字）
- 时间范围？（一个月内/三个月内/一年内）
- 有无附带条件？（必须工作日、避开特定日期等）

### 第二步：确定命主用神与忌神

- 排出命主四柱
- 确定用神、忌神
- 确定当前大运

### 第三步：列出候选日期范围

- 根据时间范围列出所有候选日
- 排除命主不能选的日子（本命日、冲日柱、冲年柱）

### 第四步：按四层过滤

**第一层（去大凶）**：
- 去除**岁破日、月破日、三丧日、杨公忌日**
- 去除**四离日、四绝日**

**第二层（去事类忌讳）**：
- 按事类去除特别忌讳的日子（如婚嫁去除孤辰寡宿日）

**第三层（求吉神）**：
- 筛选**天德、月德、天赦、成开满定**四神的日子
- 优先选**吉神重叠**的日子

**第四层（配命主用神）**：
- 最后从候选中选**五行与命主用神一致**的日子

### 第五步：选时辰

同理：
- 时辰不冲命主日柱
- 时辰天干地支对命主有利
- 时辰之五行助用神

### 第六步：综合报告

给命主：
- **首选日期**（3 个，按优先级排序）
- **次选日期**（2 个，作为备选）
- **明确不宜的日期**（若命主提出想用的日子）
- **时辰推荐**

## 七、典型择日案例

### 案例1：婚嫁择日

**情境**：
- 新郎命盘：戊辰 丁巳 乙酉 辛巳（用神水、木）
- 新娘命盘：庚午 丁亥 壬子 壬寅（用神土、火）
- 想在 2026 年上半年结婚

**过滤过程**：

**第一层**：排除 2026 年的岁破日（子日，若有则去除）

**第二层**：排除孤辰寡宿日、三丧日

**第三层**：筛选天德、月德、天赦、成开满定日

**第四层**：从剩余中挑五行对双方都有利的日子
- 需要一个"水气微旺（新郎用神）+ 火气不过（新娘用神部分）"的日子
- 同时避免冲双方日柱（乙酉、壬子）

**首选推荐**：2026 年某月戊辰日、癸未日、丙子日（需查具体日历）

### 案例2：开张择日

**情境**：
- 老板命盘：甲寅 丙寅 甲寅 甲子（用神金、土）
- 想 2026 年 3 月开店

**过滤过程**：

**第一层**：排除岁破日（2026 丙午年，排除子日——本命也需避）

**第二层**：排除破日、闭日、劫煞日

**第三层**：筛选天德、月德日

**第四层**：选五行与用神土金一致的日子
- 推荐戊辰日、己巳日、庚午日、辛未日、庚申日、辛酉日
- 其中**庚申日 + 庚辰时**最佳（金气最旺）

**首选日**：2026 年 3 月某个戊辰或庚申日

### 案例3：手术择日

**情境**：
- 患者命盘：辛卯 辛卯 甲午 戊辰
- 准备做手术，医生给了三个时间选项

**医生建议的三个日期**：
- 选项 A：甲戌日
- 选项 B：丙子日
- 选项 C：庚申日

**分析**：
- 选项 A 甲戌：甲木助身，戌土合卯（日柱），手术风险小
- 选项 B 丙子：丙火泄身气，子水冲午火（月令），不佳
- 选项 C 庚申：庚克甲（日主），申冲寅（但命中无寅），风险较大

**建议**：**选项 A 甲戌日最佳**

## 八、择日的常见误区

### ❌ 误区 1：只看黄历

**错误表现**：
> "黄历说今天是黄道吉日，一定好。"

**正确理解**：
黄历是通用择日，未考虑命主个人八字。**真正的择日必须结合个人命盘**。

### ❌ 误区 2：迷信"黄道吉日"

**错误表现**：
> "只要是黄道日就可以。"

**正确理解**：
黄道日是避免"黑道凶煞"的最低标准，但不代表"对命主有利"。两者是不同维度。

### ❌ 误区 3：忽视时辰

**错误表现**：
> "日子选好就行，时辰无所谓。"

**正确理解**：
时辰是"日中之日"，同样重要。如手术，时辰比日期更关键。

### ❌ 误区 4：相信"无所不能的吉日"

**错误表现**：
> "这是某某大师算的顶级吉日，做什么都行。"

**正确理解**：
**没有任何一天是对所有人、所有事都"顶级吉"的**。不同的人、不同的事，适合的日子不同。

### ❌ 误区 5：过度择日

**错误表现**：
> "我连吃饭都要挑吉时。"

**正确理解**：
择日是**为重大事件**。日常琐事不需要择日，过度择日反而会制造焦虑、贻误时机。

## 九、择日的伦理边界

### 不做的事

1. **不承诺"择日必成"**：择日只是提高概率，不保证结果
2. **不推销昂贵日课**：不因"这是黄金吉日"就收取离谱费用
3. **不制造恐慌**：不因"某日大凶"就要求命主做各种补救、购买特殊物品
4. **不排他性**：不因命主选了其他日子就诅咒其命运

### 应做的事

1. **客观分析**：给出几个合理的备选日期
2. **解释原理**：让命主理解为什么这日子好
3. **尊重选择**：若命主因现实原因必须选某日，尽力分析化解方案
4. **提醒风险**：明确告知日子的优缺点

## 十、择日与八字命理的关系

### 择日是"外加的吉时"

- 八字命理看的是"**天生的命**"
- 大运流年看的是"**随岁月流动的运**"
- 择日看的是"**人为选择的时机**"

三者关系：
> **好命 + 好运 + 好日 = 事半功倍**
> **差命 + 差运 + 好日 = 尽量补救**
> **好命 + 好运 + 差日 = 可惜但无碍**
> **差命 + 差运 + 差日 = 最好推迟**

### 择日的极限

- 择日是"锦上添花"，不是"雪中送炭"
- 不能把一个凶事变成大吉，只能让凶减轻、吉更吉
- 重大决策的核心仍是**命主自身的准备、能力、努力**

## 十一、常见择日 FAQ

### Q1：黄历上的吉日和我自己八字的吉日不一致，听谁的？
A：**听自己八字的**。黄历是通用的，你的命盘是专属的。

### Q2：结婚一定要挑"很好"的日子吗？
A：建议至少避开"大凶日"（岁破、月破、三丧、杨公忌）。在此基础上，能选到"用神配合"的日子当然更好。

### Q3：如果吉日是工作日无法请假怎么办？
A：**两个方案**：
- 方案 1：在最近的周末选一个"次吉"日
- 方案 2：在工作日登记注册（法律层面）、周末补办仪式

法律生效时间以登记日为准，仪式日可以另择。

### Q4：两人合婚的吉日应该以谁为主？
A：**双方八字同时参考**。婚嫁之日应该是"对双方都有利"的日子，或至少"对双方都不害"。若无法两全，传统上以**女方**八字为主（女方是入嫁方）。

### Q5：某些师傅给的"大凶日"，真的那么严重吗？
A：不要过度恐慌。"凶日"是概率增高，不是绝对。即使是"三丧日"，也有很多人平安度过。保持理性，重要事避开即可。

### Q6：网上免费择日软件可靠吗？
A：**只能参考**。免费软件多数只做黄历+建除+简单神煞，**不结合命主八字**。真正好的择日必须结合个人命盘。

- 《协纪辨方书》（清·允禄等，择日经典）
- 《玉匣记》（传统择日手册）
- 《钦定协纪辨方》（清代官修）
- 梁湘润《择日实用全书》
- 白鹤鸣《择日正宗》
- 李居明《现代择日学》

> **重要提醒**：择日是传统文化的一部分，有其文化价值。现代使用时应当：
> - **保留**：配合命主用神、避大凶、选吉神的理性方法
> - **改造**：把迷信色彩浓的神煞重新定位为"概率参考"
> - **摒弃**：神秘化、恐吓式、商业化的择日套路
>
> 择日的终极目的是**为命主的重大决策提供时间维度的优化**，不是替天做主，更不是制造恐慌。

# 六亲精断完整指南

> 大师级断命的核心技能之一：不只断"命主好不好"，更要断"父母/配偶/子女各自的吉凶"。
> 本文件系统整理看六亲的完整方法链，涵盖经典派、盲派、港台派的精华。

## 二、看父亲

### 定位
- **星**：偏财（男女命通用）
- **宫**：年柱（年干为父星的天然位置）

### 断父吉凶规则

| 条件 | 断语 |
|------|------|
| 偏财有力且不受克 | 父亲有能力、家境好 |
| 偏财坐年柱得令 | 父亲事业有成 |
| 偏财被比劫克夺 | 父亲财运差/早年丧父/父子关系差 |
| 偏财入墓（辰戌丑未） | 父亲健康欠佳/寿限 |
| 年柱逢冲 | 幼年家庭变动/父母离异 |
| 偏财空亡 | 与父缘薄/父亲不在身边 |
| 年干被月干克 | 父亲被家庭（兄弟宫）所累 |

### 断父寿限
- 偏财星逢大运流年**墓绝**之地 = 父亲健康关口
- 偏财被冲克之年 = 父亲有灾之年
- 比劫旺运克偏财 = 经济损失（可能与父有关）

### 盲派看父
- 年干为父位：年干旺相=父有能力；年干休囚=父平凡
- 年干坐下地支（年支）生年干=父得家庭之助
- 年干坐下地支克年干=父受家庭之困

## 三、看母亲

### 定位
- **星**：正印（男女命通用）
- **宫**：年柱（年支为母星的天然位置）

### 断母吉凶规则

| 条件 | 断语 |
|------|------|
| 正印有力且不受克 | 母亲贤惠、有学识 |
| 正印贴身相生日主 | 母亲对命主帮助大 |
| 正印被财星克破 | 母亲辛苦/婆媳关系差/母早亡 |
| 正印太多 | 母亲过度保护/命主依赖性强 |
| 正印空亡 | 与母缘薄/幼年离母 |
| 年支被冲 | 母亲早年不安/迁移 |
| 印星入墓 | 母亲寿限信号 |

### 断母寿限
- 印星逢大运流年**绝地**或被**财星大运**克制 = 母亲健康关口
- 财旺克印之年 = 母亲有灾

### 父母关系
- 偏财（父）与正印（母）的关系 = 父母婚姻状态
- 偏财克正印 = 父亲管束母亲/母亲受委屈
- 偏财生正印（通过某五行） = 父母和谐
- 偏财正印相冲 = 父母不和/离异

## 四、看配偶（最重要）

### 定位
- **星**：男看正财（妻），女看正官（夫）
- **宫**：日支（夫妻宫）——**比星更重要**

### 4.1 夫妻宫（日支）断法

| 日支状态 | 断语 |
|---------|------|
| 日支为喜用神 | 配偶对自己帮助大、婚姻美满 |
| 日支为忌神 | 配偶拖累自己/婚姻不顺 |
| 日支逢冲（大运或流年） | 该运/年婚姻有变（离婚/分居/搬家） |
| 日支逢合（大运或流年） | 该运/年有人来合=新感情/结婚 |
| 日支被刑 | 婚姻中有争吵/法律纠纷 |
| 日支空亡 | 配偶缘薄/晚婚/婚后聚少离多 |
| 日支坐桃花 | 配偶漂亮/风流/异性缘好 |

### 4.2 配偶星断法

**男命看正财**：

| 条件 | 断语 |
|------|------|
| 正财有力且不被劫 | 妻子贤惠能干 |
| 正财被比劫克夺 | 妻子有人争/婚姻被第三者介入 |
| 正财多（2个以上） | 多次恋爱/二婚倾向 |
| 偏财旺于正财 | 有外遇倾向/风流 |
| 正财合他干（非日干） | 妻子与他人有暧昧 |
| 无正财 | 晚婚/妻缘薄/以偏财代正财 |

**女命看正官**：

| 条件 | 断语 |
|------|------|
| 正官有力且不被伤 | 丈夫有地位能力 |
| 伤官见官 | 婚姻大忌——克夫/离婚/丈夫有灾 |
| 官杀混杂 | 感情混乱/多次恋爱/难以专一 |
| 正官合他干 | 丈夫心不在家 |
| 无正官只有七杀 | 嫁非正式对象/同居/晚婚 |
| 官星入墓 | 丈夫事业受困/健康不佳 |

### 4.3 结婚应期（综合判断）

满足以下条件越多，越可能是结婚年：
1. 流年合日支（夫妻宫被合动）
2. 流年冲开配偶星墓库
3. 配偶星在大运中走长生/帝旺
4. 流年走桃花地支
5. 流年天干透出配偶星

### 4.4 离婚应期

满足以下条件越多，越可能是离婚年：
1. 流年冲日支（夫妻宫被冲散）
2. 大运比劫旺克正财（男命）或伤官旺克正官（女命）
3. 配偶星走死墓绝地
4. 日支逢刑
5. 桃花被冲动（新的感情出现取代旧的）

## 五、看子女

### 定位
- **星**：男命看七杀（子）正官（女）；女命看食神（子）伤官（女）
- **宫**：时柱（时干为子女星天然位置，时支为子女宫）

### 5.1 有无子女

| 条件 | 断语 |
|------|------|
| 子女星有力且时柱不受克 | 有子女、子女健康 |
| 子女星被克绝 | 难生育/子女少 |
| 时柱全是忌神 | 子女不省心/老来受累 |
| 时柱空亡 | 子女缘薄/与子女分离 |
| 食伤太旺（女命） | 多子女但消耗母体 |
| 印星太旺克食伤（女命） | 不易怀孕/小产 |
| 七杀无制（男命） | 儿子叛逆/管不住 |

### 5.2 子女数量（传统估算）

传统方法（现代仅参考）：
- 时支藏干中有几个子女星 ≈ 子女数
- 子女星在四柱中出现次数（有根的才算）
- 现代社会已不完全适用（计划生育/丁克等影响）

### 5.3 子女优秀与否

| 条件 | 断语 |
|------|------|
| 时柱坐喜用神 | 子女有出息/晚年享福 |
| 时干为正官/正印 | 子女有官位/有学问 |
| 时干为食神（不被枭） | 子女有才华、孝顺 |
| 时干为伤官 | 子女聪明但叛逆 |
| 时干为七杀有制 | 子女有魄力、能闯事业 |
| 时干为比劫 | 子女多/竞争多/与子女关系平淡 |

### 5.4 生育应期

- 子女星在大运走长生/帝旺之年
- 流年透出子女星或合出子女星
- 流年走桃花（有"人"来的象）
- 食伤（女命）或官杀（男命）走旺地之年

## 六、看兄弟姐妹

### 定位
- **星**：比肩（同性兄弟/姐妹）、劫财（异性兄弟/姐妹）
- **宫**：月柱

### 断法

| 条件 | 断语 |
|------|------|
| 比劫多且旺 | 兄弟姐妹多/竞争激烈 |
| 比劫有力帮身 | 得兄弟姐妹之助 |
| 比劫为忌 | 兄弟姐妹争财/拖累 |
| 月柱被冲 | 与兄弟姐妹关系不稳/分离 |
| 比劫空亡 | 兄弟姐妹缘薄/少来往 |
| 劫财夺正财 | 兄弟朋友争自己的钱/妻 |

## 七、六亲看法的三层结构

大师看六亲遵循"三层验证"：

### 第一层：看星（十神）
该六亲对应的十神在四柱中是否存在、是否有力、是否被克。

### 第二层：看宫（柱位）
该六亲对应的宫位（年/月/日支/时）状态如何——是喜是忌、有无冲合刑害。

### 第三层：看运（大运流年引动）
该六亲的星或宫在何时被大运流年引动——引动时即为该六亲发生大事之年。

> **三层都指向同一结论**时=高确定性断语；只有一层支持=低确定性，需谨慎。

## 八、六亲断事应期速查

| 事件 | 看什么 | 应期信号 |
|------|--------|---------|
| 父亡 | 偏财 | 偏财入墓绝 + 年柱被冲 + 比劫大运 |
| 母亡 | 正印 | 印星入墓绝 + 财旺克印年 |
| 结婚 | 日支+配偶星 | 合日支 + 配偶星旺 + 桃花 |
| 离婚 | 日支 | 冲日支 + 比劫/伤官旺 |
| 得子 | 时柱+子女星 | 子女星走旺地 + 食伤年（女）/官杀年（男） |
| 子女有灾 | 时柱 | 时柱被冲刑 + 子女星入墓绝 |
| 兄弟有灾 | 月柱+比劫 | 月柱被冲 + 官杀克比劫年 |

## 九、常见错误

| 错误 | 纠正 |
|------|------|
| 只看星不看宫 | 星是"谁"，宫是"位置"——两者必须合参 |
| 男女命用同一套六亲表 | 男看财（妻）女看官（夫），子女星也不同 |
| 父母只看年柱不看星 | 年柱是宫位，偏财/正印是星——都要看 |
| 配偶只看日支 | 日支是宫，正财/正官是星——星宫合参 |
| 忽视大运引动 | 静态命局只是"信息"，大运流年才是"触发" |
| 子女星等于子女数 | 现代社会子女数受社会因素影响大于命理 |

## 十、检查清单

- [ ] 是否区分了"星"和"宫"两个维度
- [ ] 是否按照男命/女命分别使用了正确的六亲表
- [ ] 配偶分析是否同时看了日支（宫）和财/官（星）
- [ ] 断六亲吉凶是否结合了大运流年（而非只看命局）
- [ ] 是否用了"三层验证"（星+宫+运都指向同一结论）
- [ ] 对命主表述时是否保持了尊重（不直言"你爸要死"之类）

# 真太阳时校正

## 概述

真太阳时（True Solar Time）是以太阳实际位置为基准的时间，与我们日常使用的北京标准时间（东经120°）存在差异。由于中国幅员辽阔，不同出生地的经度不同，实际的太阳时与标准时间可能相差数十分钟。专业命理师排盘时，**必须将北京标准时间换算为真太阳时**，否则时柱可能出错，影响整个命盘的准确性。

---

## 一、真太阳时的概念与重要性

### 什么是真太阳时？
- 以当地经度上太阳中天（正午）为正午12:00的计时方式。
- 每隔经度1°，时间相差4分钟。
- 中国标准时间以**东经120°**为基准（北京时间）。

### 为什么重要？
- 时柱的误差可能导致分析完全不同的时辰，进而改变十神关系、命宫推算、神煞定位。
- 在时辰交界处出生（如接近23点子时，或接近某时辰分界前后）时，真太阳时校正尤为关键。
- 专业命理大师（邵伟华、裴翁等）均强调使用真太阳时排盘。

---

## 二、真太阳时换算方法

### 换算公式

```
真太阳时 = 北京标准时间 + 经度时差 ± 均时差（可选精确使用）
经度时差（分钟）= （出生地经度 - 120）× 4
```

- 出生地经度 **大于** 120°（东部）→ 经度时差为**正数**，需**加**上时差
- 出生地经度 **小于** 120°（西部）→ 经度时差为**负数**，需**减**去时差

### 简化换算步骤

1. 查出出生城市的大约经度。
2. 计算与东经120°的经度差。
3. 每差1°经度 = 差4分钟。
4. 东边（经度>120°）加时间，西边（经度<120°）减时间。
5. 得出真太阳时，再对照时辰表确定时柱。

## 四、中国夏令时历史年份说明

中国历史上曾实行夏令时（将时钟拨快1小时），实行期间出生者，须将记录时间**减去1小时**后再进行真太阳时换算。

| 年份 | 夏令时实行期间 |
|------|-------------|
| 1986年 | 4月12日02:00 → 9月14日02:00 |
| 1987年 | 4月12日02:00 → 9月13日02:00 |
| 1988年 | 4月10日02:00 → 9月11日02:00 |
| 1989年 | 4月16日02:00 → 9月17日02:00 |
| 1990年 | 4月15日02:00 → 9月16日02:00 |
| 1991年 | 4月14日02:00 → 9月15日02:00 |

> **1992年起中国不再实行夏令时。**

**判断是否适用夏令时**：
1. 出生年份在1986-1991年之间。
2. 出生日期在当年夏令时实行期间内。
3. 若符合，将出生时间**减1小时**，得到真正的标准时间，再换算真太阳时。

## 五、时辰交界处的处理原则

时辰交界处（如23:00子时、01:00丑时、03:00寅时……）前后各15分钟是"危险区"，处理原则：

1. **先完成真太阳时换算**，得到真实出生时间。
2. 若换算后时间**仍在原时辰内**，则时柱不变。
3. 若换算后时间**跨越时辰分界**，则时柱改变，需重新判断。
4. **若无法确认**（出生记录模糊），可排两个盘（前后时辰各一）对比分析，结合历史事件校准确定正确时辰。

## 六、实际校正计算示例

### 示例一：广州出生
**出生信息**：1990年8月15日，广州，北京时间 22:45

1. **夏令时检查**：1990年8月15日在夏令时期间（4月15日-9月16日）→ 减1小时 → 实际标准时间 21:45
2. **经度时差**：广州经度约113.3°E，差值 = 113.3 - 120 = -6.7°，时差 = -6.7 × 4 = **-27分钟**
3. **真太阳时** = 21:45 - 27分 = **21:18**
4. **时辰判断**：21:18 属 21:00-22:59 亥时 ✓（若记录为22:45，换算前为亥时，换算后仍亥时，无变化）

### 示例二：成都出生，时辰交界处
**出生信息**：2000年3月15日，成都，北京时间 23:10

1. **夏令时检查**：2000年，无夏令时 → 不调整
2. **经度时差**：成都经度约104.1°E，差值 = 104.1 - 120 = -15.9°，时差 = -15.9 × 4 = **-64分钟**
3. **真太阳时** = 23:10 - 64分 = **22:06**
4. **时辰判断**：22:06 属 21:00-22:59 **亥时**（而非北京时间的子时！）
5. **结论**：该命主时柱应为**亥时**，而非子时，须重新排盘。
